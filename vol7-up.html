卷七

上升账

如果你还想再搏一次

最后一卷，给还想往上走的人。用的是同一套算法：先算清哪些努力值得，再看懂升迁的真实规则。

7.1哪些努力值得

前面六卷都在讲"少消耗"。

这一卷反过来，讲"多投入"——但不是所有的投入都值得。

体制内最残酷的一个真相是：很多人不是不努力，是把力气花在了不产生回报的地方。

这一节讲怎么分辨。

7.1.1

值得押的三种努力：能带走的、能积累的、能换轨的

● 必做可靠 乙代价 无
代价
要放弃一些"看起来很努力"的事。
一句话
判断标准只有一个——离开这个单位，它还在不在。
怎么做
能带走的
写作、表达、专业能力、证书、人脉（真朋友那种）。
能积累的
资历、项目经验、行业口碑、可查的作品。
能换轨的
学历、职业资格、跨领域的技能。
为什么
体制内的很多努力是"位置绑定的"——你在这个位置上才有价值，位置一换就清零。而上面这三类，跟着你走。
失效条件
短期内要争一个具体位置，那该按那个位置的规则努力。
翻车
有人在单位做了十年"内部协调"，协调能力极强。调走后发现，这个能力离开了具体的人和事，一文不值。
可靠度
乙
备注
这一条是全卷的地基：先分清哪些是你的，哪些是位置的。
7.1.2

不值得押的三种：评比、口号、领导的情绪

● 必做可靠 乙代价 无
代价
要忍住"被认可"的渴望。
一句话
这三样都不可控，且有效期极短。
怎么做
评比参加但不执着；口号喊但不信；领导的情绪看但不入心。
为什么
评比是平衡工具，口号是组织语言，情绪是即时反应——它们都不产生积累。你为它们投入的情绪和时间，第二年就归零。
失效条件
评比在提拔时确有加分，该重视还得重视。
翻车
有人为了一个"先进个人"，连续三个月每天加班到十点。拿到奖状那天很开心，第二年发现，除了那张纸，什么都没变。
可靠度
乙
备注
这一条不是让你消极。是让你把情绪从"不可控的事"上撤回来。
7.1.3

写材料这件事：适可而止，别成为"那支笔"

◎ 建议可靠 乙代价 无
代价
要放弃"笔杆子"的光环。
一句话
单位需要一支笔，但不需要一个笔杆子当领导。
怎么做
能写是优势，但要控制在"能写"而不是"只能写"。主动争取一些"要露脸、要协调"的活，别让自己被固定在电脑前。
为什么
写材料的人往往最了解情况、最辛苦、最被依赖，但也最难提拔——因为领导离不开他。这个位置的价值在"笔"上，不在"位"上。
失效条件
政策研究室、办公室等以文辅政的岗位，写材料本身就是上升通道。
翻车
有人在办公室写了八年材料，全单位都说他"水平高"，但三次提拔都没他，因为"他走了谁写"。
可靠度
乙
备注
这一条很反常识，但在很多单位是事实。
7.1.4

不可替代，是体制内最危险的处境

● 必做可靠 乙代价 无
代价
要主动培养接手的人。
一句话
你越不可替代，越走不开；越走不开，越上不去。
怎么做
把手上的活整理成流程，教会至少一个人。让自己"可替代但难替代"——别人能接，但接得不如你熟。
为什么
提拔的前提是"你走了，这块有人接"。你把自己做成唯一节点，等于把自己钉死在原地。而"可替代"反而给了你自由。
失效条件
核心技术岗、涉密岗位，客观上就是不可替代，那要另找路径。
翻车
有人是科室里唯一会某项业务的人，十年没动过位置。领导说得很直白："你走了，这块就塌了。"
可靠度
乙
备注
这一条和 4.3.3 是一对：一个讲"别被消耗"，一个讲"别被钉死"。
7.1.5

把活干得漂亮，但别让领导觉得你只能干这个

● 必做可靠 乙代价 无
代价
要主动争取"不像你"的活。
一句话
标签一旦贴上，就很难撕下来。
怎么做
在做好本职的前提下，主动接一两件"跨类型"的事——写材料的去跑一次协调，搞业务的去做一次汇报。让领导看到你的另一面。
为什么
组织对人的认知是"标签化"的：他是写材料的、他是跑腿的、他是搞技术的。标签决定了机会，而机会决定了你能不能突破。
失效条件
专业分工极细的单位，跨类型反而不专业，那要深耕。
翻车
有人被贴上"会务专家"的标签，十年里所有大会都是他办，一次业务岗的机会都没有。
可靠度
乙
备注
这一条的关键是"一次"，不用多，让人看见就行。
7.1.6

值得押的还有一样：身体

● 必做可靠 乙代价 无
代价
每天半小时。
一句话
所有努力的前提，是你还活着、还能干。
怎么做
每周三次、每次三十分钟的运动，比任何"职场技巧"都更能延长你的职业生涯。
为什么
体制内是一场长跑，跑赢的人不是跑得快的，是没退赛的。而四十岁以后的竞争力，很大程度取决于身体。
失效条件
无。
翻车
有人三十五岁做到科室负责人，三十八岁查出重病，之后所有的规划都作废了。
可靠度
乙
备注
这一条放在"努力"这一节，是想说：身体也是一种投资，而且回报率最高。

本节小结

这一节六条，讲的是一件事：努力要挑地方。

能带走的、能积累的、能换轨的，值得押。评比、口号、领导的情绪，不值得。而身体，是所有努力的地基。

下一节讲最后一件事：升迁的真实规则。

7.2升迁的真实规则

最后一节，讲一件很多人一辈子没搞明白的事：升迁到底是怎么发生的。

不是论资排辈，也不是论功行赏。

它是一把手用位置换忠诚的一笔交易——你不是在争取一个岗位，你是在争取被纳入某个人的班底。

这一节讲清楚三件事：名单在会前怎么形成，一把手拿什么挑人，以及几个普遍的误判。

7.2.1

常委会是呈现结果的地方，不是产生结果的地方

● 必做可靠 乙代价 无
代价
要接受"程序"和"结果"是两件事。
一句话
会议只是把已经定好的事念一遍，真正的决定早在会议室外面做完了。
怎么做
关心一件事，不要只看它上没上会，要看它上会之前有没有人替你"说话"。会上说什么都是记录，会前说什么才是决定。
为什么
常委会是集体决策的形式载体，功能是确认共识，不是制造共识。共识在小范围沟通里达成，会上只是走完程序。
失效条件
重大否决、争议极大的议题，会上确实可能翻盘，因为小范围没谈拢。
翻车
某人以为会上发言出彩就能推动方案，讲得头头是道。散会后没人接话——因为这事三天前就定了。
可靠度
乙
备注
程序是真的，记录是真的，责任是真的。只是"决定"发生在别处。
7.2.2

酝酿不是讨论，是交换

● 必做可靠 乙代价 无
代价
要重新理解这个词。
一句话
酝酿包含试探、还价和互相兜底。
怎么做
听到"还在酝酿"，就该知道两件事——方向没定；能影响方向的人正在一个个谈。这时候要做的不是催，是让你的名字出现在那些谈话里。
为什么
干部任免涉及人事、纪律、稳定的交叉，不可能在一次会议上从零开始。必须先在小范围把分歧磨平。会议是结果，酝酿是过程。
失效条件
程序性、事务性事项，不需要酝酿。
翻车
某人在酝酿阶段到处打听"我有没有戏"，问了七八个人。最后所有人都知道他很想上——而"很想上"本身就是减分项。
可靠度
乙
备注
这一条最容易被误用。它不是教你钻营，是告诉你别用"等通知"的心态对付一件需要提前三个月布局的事。
7.2.3

提拔的本质：搭班底，不是评先进

● 必做可靠 乙代价 无
代价
要接受"我很优秀"和"我想用你"是两回事。
一句话
领导提拔一个人，是在给自己搭一套可靠的班子。
怎么做
把自己从"好员工"切换到"可信的人"。好员工看业绩，可信的人看三件事——听话、好用、不添乱。
为什么
位置是领导手里最硬的资源，给出去换回来的必须是他能调动的力量。聪明但不受控的人，对领导是风险，不是资产。
失效条件
纯技术岗位、职称序列，能力权重远高于忠诚权重。
翻车
某人业务最强、证书最多，但开会经常提不同意见。连续两次都没他，评语是"能力有，就是不太成熟"。
可靠度
乙
备注
站队是选边，搭班底是被选。你控制不了被不被选，但能控制自己像不像一个"能被用"的人。
7.2.4

好用的排序：听话 > 能扛 > 聪明

◎ 建议可靠 丙代价 无
代价
要接受聪明不是优势。
一句话
人事决策里最不值钱的是聪明，最值钱的是可控。
怎么做
把自己能被用的场景想清楚——会写、会跑、会协调、会陪，占哪一样？至少占一样，并且让该知道的人知道。
为什么
领导面对的不是"选人才"，是"用资源"。他算的是"给你位置，你能替我解决什么问题"。聪明排在"能不能被指挥"后面。
失效条件
业务攻坚型单位，能力可以压倒其他一切。
翻车
某人在多个场合表现出比领导更懂行，让领导下不来台。后来领导宁可用一个能力平平但"说什么听什么"的人。
可靠度
丙（观察性结论，随领导风格波动很大）
备注
不是让你装傻，是别把"显得聪明"当成核心竞争力。
7.2.5

到点就提，是最危险的幻想

● 必做可靠 乙代价 无
代价
要放弃"熬够年头就该我"的确定性。
一句话
人事调整不是按时间表来的，是按空缺、按变动、按风向来的。
怎么做
把"我够资历了"换成"机会来的时候我准备好了吗"。
为什么
一次提拔要同时满足：有位置、有人推、风向对、没人反对。四个里三个不在你手里。
失效条件
职级并行中按年限自然晋级的部分，确实到点就提。
翻车
某人按时按点等，眼看排在他后面的人都动了，他还在等。别人劝他找领导谈一次，他说"该是我的跑不了"。
可靠度
乙
备注
这一条残酷但有用。它至少能让你少生三天气。
7.2.6

借调、遴选、挂职，哪些是机会哪些是坑

◎ 建议可靠 丙代价 无
代价
要判断。
一句话
看它给不给你"身份"和"编制"，不给的就是借劳力。
怎么做
借调
多数是免费劳动力，但如果能留下（有编制空缺），就是唯一绕开考试的通道。
挂职
有明确的挂职期限和岗位，是镀金；没有期限、只干活，是借调。
遴选
面向体制内的公开考试，是相对最公平的换轨通道。
为什么
这三者的共同点是"暂时离开原单位"，区别在于有没有明确的落点。有落点的叫机会，没落点的叫消耗。
失效条件
无。
翻车
有人借调三年，活干了、人累垮了，最后因为"没有编制"被打回原单位，原单位的位置也没了。
可靠度
丙（各单位差异极大）
备注
接受任何"暂时离开"的安排之前，问一句"什么时候、以什么身份回来"。答不上来，就别去。
7.2.7

五人小组：人事权到底在谁手里

◎ 建议可靠 丙代价 无
代价
要承认你的直属领导帮不上太多忙。
一句话
决定你升迁的那几个人，对你的直属领导同样是保密的。
怎么做
把直属领导当信息源和推荐人，不要当决策者。他能做的是在合适的场合提你一句，不能做的是拍板。
为什么
干部人事的决策权集中在一个很小的圈子里。以地市一级为例，通常包括党委书记、两位副书记、纪委书记和组织部长，俗称"五人小组"。组织部门出方案，最终取舍在这个小范围里反复酝酿完成。
失效条件
科室内部的组长、班组负责人任命，直属领导确实有话语权。层级越低，这话越不成立。
翻车
某人和直属领导关系极好，以为十拿九稳。调整方案下来，名单里没有他。领导私下说"我推荐了，没通过"。
可靠度
丙（组织结构公开可查，但具体运作各单位差异很大）
备注
不同级别、不同类型单位差别很大。这一条给的是"量级感"，不是操作手册。
7.2.8

竞争上岗：流程是真的，内定也是真的

◎ 建议可靠 丙代价 无
代价
要接受自己参加的是一场"有答案的考试"。
一句话
程序的真实性和结果的决定权，是可以同时存在的。
怎么做
该报名报名，该考试考试。别因为知道答案就弃权——弃权等于放弃下一次入场券。
为什么
选拔程序设计出来是为了控制风险和程序完整，不是为了发现人才。当某个岗位需要特定人选时，流程会被用来为这个结论服务。这不等于流程是假的，只等于流程不是决定项。
失效条件
面向社会公开的遴选、公招，决定性环节的独立性高得多。
翻车
某人看透了"都是内定"，拒绝参加竞争上岗。半年后机会来了，他却因为没有连续参加的记录，连报名资格都不够。
可靠度
丙
备注
看透和弃权是两件事。前者让你平静，后者让你出局。

本节小结

这一节六条，讲的是升迁的真相。

它不是对过去的结算，是对未来的投资。领导投资的是他自己的安全感和执行力，你只是他选中的一支股票。

明白这一点，你至少能做三件事：提前布局而不是到时抱怨，让自己"可用"而不是只"优秀"，把期待放在有成本的信号上而不是漂亮的话上。

但也要记住：这一卷是全书最后一卷，也是最短的一卷。

因为对多数人来说，前面六卷比这一卷重要得多。

全书完。

七卷三十节，讲的其实是一件事：

单位是拿钱的地方，不是卖命的地方。

你把八小时给它，把剩下的时间、身体、情绪和家人，留给自己。

7.3借调、挂职、遴选：哪些是机会，哪些是坑

体制内换轨的三条主要通道：借调、挂职、遴选。

它们看起来都是"往上走的机会"，但性质完全不同——一个是试用，一个是镀金，一个是考试。

这一节讲怎么分清。

7.3.1

借调：免费劳动力陷阱，也是唯一的"留用"通道

◎ 建议可靠 丙代价 无
代价
可能要白干两三年。
一句话
借调不给你身份，只给你"被看见"的机会。
怎么做
接受前问清三件事——借调期限多长？有没有留用的可能？原单位的位置保不保？三个答案含糊，就别去。
为什么
借调的人事关系还在原单位，工资原单位发，干活新单位用。多数借调最后是"用完退回"，但如果新单位有编制空缺且领导认可，就是唯一能绕开考试的通道。
失效条件
上级机关"以借代调"的情况，留用概率会高一些。
翻车
有人借调三年，活干了、人累垮了，最后因为"没有编制"被打回原单位，原单位的位置也没了。
可靠度
丙（各单位差异极大）
备注
这一条的核心是"问清期限和可能"。
7.3.2

挂职：有期限、有岗位、有文件的，才叫挂职

● 必做可靠 乙代价 无
代价
要离开熟悉的环境。
一句话
挂职是"带着任命去的"，不是"去帮忙的"。
怎么做
看有没有正式的挂职文件、明确的职务、确定的期限。三者齐全，是镀金；缺一样，就是借调的变种。
为什么
挂职是干部培养制度的一部分，有文件、有职务、有考核，回来通常有安排。而"没有文件的挂职"，本质上就是借调。
失效条件
无。
翻车
有人被"挂职"了两年，没有任命文件，回来时原岗位已经有人了。
可靠度
乙
备注
这一条的判断标准很硬：看文件。
7.3.3

遴选：相对最公平的一条路

● 必做可靠 乙代价 无
代价
要考试。
一句话
遴选是面向体制内的公开考试，比"找人"靠谱得多。
怎么做
关注本地组织部门发布的遴选公告，看清报名条件（工作年限、身份、专业）。提前半年准备，笔试考的是政策理论、公文写作、案例分析。
为什么
遴选有明确的程序和分数线，虽然也有"萝卜岗"，但整体透明度高于其他通道。而且它是"换单位"最正当的方式。
失效条件
极少数岗位确实为特定人设置，那要提前打听。
翻车
有人笔试第一，面试被刷，后来才知道那个岗位早就有人了。
可靠度
乙
备注
这一条值得投入：它是普通人最可能走通的路。
7.3.4

调动：商调函怎么走，卡在哪一步

◎ 建议可靠 乙代价 无
代价
要跑手续。
一句话
调动的关键不是"接收单位要不要"，是"原单位放不放"。
怎么做
流程是——接收单位发商调函、原单位同意、组织部门审批、办理调动手续。卡点通常在"原单位不放"和"编制空缺"。
为什么
体制内调动需要"出"和"进"两头都同意。而原单位往往不愿意放走能干的人，这是最常见的卡点。
失效条件
上级机关直接下调令的，不在此列。
翻车
有人接收单位都找好了，原单位一句"我们人手紧"，拖了两年。
可靠度
乙
备注
这一条要提前做原单位的工作，别等商调函发出去才发现不放人。
7.3.5

跨省调动：最难的一条路

○ 可选可靠 丙代价 无
代价
时间、精力、关系。
一句话
跨省调动涉及两地编制、两地审批，难度是省内的数倍。
怎么做
先确认接收地有没有"人才引进"政策（这是跨省最现实的通道），再走商调。没有政策支撑的纯商调，成功率极低。
为什么
跨省调动要经过两地组织部门、编办，任何一环卡住都办不成。而"人才引进"有专门通道，程序简单得多。
失效条件
夫妻两地分居、照顾老人等特殊情况，部分地区有照顾政策。
翻车
有人为跨省调动跑了四年，最后放弃。
可靠度
丙
备注
这一条要有心理准备：能办成是少数。
7.3.6

接受任何"暂时离开"之前，问一句"什么时候、以什么身份回来"

● 必做可靠 乙代价 无
代价
可能显得不够积极。
一句话
这句话能替你筛掉八成的坑。
怎么做
不管是借调、挂职、还是"先去帮忙一段时间"，都问这一句。对方答得清楚，是机会；答得含糊，是消耗。
为什么
所有的"暂时"都有代价——你的位置、你的关系、你的时间。而组织对"暂时"的定义，往往比你想的长。
失效条件
无。
翻车
有人"先去帮忙三个月"，帮了三年。
可靠度
乙
备注
这一条是整卷的收尾：机会和坑的区别，就在这句话的答案里。

本节小结

这一节六条，讲的是三条通道的区别：

借调是试用，可能留用，也可能白干；挂职是镀金，看文件；遴选是考试，最公平。

而所有"暂时离开"的安排，都要先问一句：什么时候、以什么身份回来。

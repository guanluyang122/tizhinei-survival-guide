# 体制内生存指南

**用最少的自我消耗，换回编制里的时间、健康和一个不被打扰的生活。**

七卷 · 三十七节 · 237 条。

---

## 这是什么

这不是一本教你升官的书，是一本**教你低成本地活着**的书。

体制内的老油条，本质上是一群**会算账的人**。他们不是懒，是把每一笔付出都放到秤上称过：这件事值不值得我用健康、情绪、陪家人的时间去换。称完了，多一分不出。

所以这本书不按"职场技能"分类，按**账本**分类。

**总公式：你拿出去的 − 你收回来的 = 你的净值。**

多数人的问题，是拿出去太多、收回来太少，还以为这是本分。这本书做的，只是把这个减法重新算一遍。

## 每一条的写法

| 字段 | 说明 |
|---|---|
| **代价** | 钱 / 时间 / 心理 / 人情，四个维度 |
| **一句话** | 这条的核心判断 |
| **怎么做** | 具体到说哪句话 |
| **为什么** | 机制。讲不清机制的一律不收 |
| **失效条件** | 什么情况下这条不成立 |
| **翻车** | 脱敏过的真实案例 |
| **可靠度** | 甲（可查制度）/ 乙（普遍共识）/ 丙（局部经验）/ 丁（传闻） |
| **推荐度** | ● 必做 / ◎ 建议 / ○ 可选 / ▲ 慎用 / × 别做 |

**丁级不是耻辱，是诚实。** 

---

## 这本书不写什么

- 不写具体的违纪操作方法
- 不写行贿受贿的技巧
- 不写对抗组织审查的办法
- 不写可识别的真实单位、真实人名
- 不写涉密信息

**界线只有一条：教你少踩坑可以写，教你钻空子不能写。**

书里出现的红线，只写"线在哪"，不写"怎么绕"。每条都对应公开通报里的真实案例。

## 适合谁

- 没打算当官、也不打算辞职的人
- 已经看清"努力不一定被看见"的人
- 想在编制里换一个**体面但不累**的活法的人

不适合还想再搏一次的人——他们去看别的书更划算。

## 最后一句

**单位是拿钱的地方，不是卖命的地方。**

你把八小时给它，把剩下的时间、身体、情绪和家人，留给自己。

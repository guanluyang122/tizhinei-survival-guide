卷一

时间账

八小时里面，有几小时是你的

体制内最大的隐性福利不是稳定，是你拥有对时间的部分处置权。多数人把它浪费在了表演忙碌上。

1.1八小时里面，有几小时是你的

多数人从来没数过：一天八小时里，真正属于你的有几小时。

这一节把它算出来。结论比你想象的多——接水、上厕所、开会、学习、午休、散步，全都在工资里。

1.1.1

在单位把尿喝黄

● 必做可靠 乙代价 时间少 · 心理低
代价
桌上常备一个杯子，仅此而已。
一句话
一天喝够两升水，离开工位就名正言顺。
怎么做
桌上放一个看得见的大杯子，早上倒满，上午两杯下午两杯。水喝得多，厕所去得就勤，每次五分钟起步，不犯法、不违纪、不用汇报。
为什么
单位最贵的资源不是工位，是你上厕所那几分钟。久坐的人靠这五分钟救腰，犯困的人靠站起来那一下救命。而且喝水多有第二个好处——它让你在工位上的每一分钟都更清醒，干活的效率反而高。
失效条件
窗口岗位、服务岗位、有明确坐班要求的岗位，这条不适用。
翻车
没有翻车案例。这是全书性价比最高的一条，风险接近于零。
可靠度
乙
备注
别笑。二十年后还在单位、身体还没垮的人，多数都有自己一套类似的土办法。
1.1.2

开会、学习、抄笔记，全部按带薪休息处理

● 必做可靠 乙代价 无
代价
要装得像在听。
一句话
单位安排的那些"必须到场"的活动，本质是它买你的时间，你的身体归你自己。
怎么做
带上自己的笔记本（不是会议发的），想听的部分听，不想听的部分发呆、练字、在心里过一遍周末安排。睡觉可以，别打呼噜。玩手机可以，屏幕压低。
为什么
这些场合对你的评价几乎没有影响——没人会记住你在党会上有没有认真记笔记，但所有人都会记住你为什么总在下午三点打哈欠。既然结果是零，不如把这段时间当成免费的发呆额度。
失效条件
有签到、有点名、有领导眼神交流的场合，该演的还得演。
翻车
有人在学习会上睡得太沉，被点名谈感想。他站起来说了三分钟，居然过了——因为领导自己也困。
可靠度
乙
备注
这一条不是教你混，是教你别在这些场合"用力过猛"。真正该用力的是下班后的时间。
1.1.3

午休是单位发的，不用白不用

● 必做可靠 乙代价 时间中 · 心理低
代价
需要一点遮挡——一件外套、一个 U 型枕。
一句话
午休那一个小时，是全年无休的免费恢复窗口。
怎么做
饭后别立刻趴下，走十分钟再睡。睡二十分钟比睡一小时管用。定个闹钟，醒了过来洗把脸，下午的效率能翻一倍。
为什么
人的注意力在午后有一个自然低谷，这是生理节律，不是懒。用二十分钟把它补回来，比喝两杯咖啡划算，也没有心悸副作用。
失效条件
有的单位中午有人来往、没法安静，那就戴耳机听白噪音，也能恢复一半。
翻车
有人中午不睡，下午三点开会打瞌睡，被记了三年"精神状态不佳"。
可靠度
乙
备注
这一条和"把尿喝黄"是配套的：上午多喝水、中午能睡着、下午不犯困。三件事加起来，是一整套低成本养生法。

二、节奏篇

1.1.4

工位散步：每小时起身五分钟，不犯法

● 必做可靠 乙代价 无
代价
要看起来像去办事。
一句话
去接水、去厕所、去别的科室送个文件——每小时离开工位一次。
怎么做
设个 hourly 的闹钟，震动，响了就起身。去三趟厕所、两趟茶水间、一趟楼梯间，一天的运动量就够了。下楼绕一圈更好。
为什么
久坐对腰、颈、血管、代谢的伤害，比熬夜更隐蔽也更严重。而它的解法极其便宜——只需要你每小时站起来五分钟。单位给你付工资让你散步，这是全天下最划算的健身卡。
失效条件
体力劳动岗位、外勤岗位本来就一直在动，这条不适用。
翻车
有人十年工龄，腰肌劳损加颈椎曲度变直，一年理疗花的钱够再买十年咖啡。
可靠度
乙
备注
最好的搭配是楼梯：一天上下两趟，一年下来心肺功能吊打同办公室所有人。

三、分寸篇

1.1.5

接水、上厕所、送文件，一天的运动量就够了

● 必做可靠 乙代价 无
代价
要看起来像去办事。
一句话
每小时离开工位一次，不用去健身房。
怎么做
定一个每小时的震动闹钟，响了就起身。去三趟厕所、两趟茶水间、一趟隔壁科室。下楼绕一圈更好，走楼梯不坐电梯。
为什么
久坐对腰、颈、血管、代谢的伤害比熬夜更隐蔽。解法只贵在起身那一下——单位给你付工资让你活动，这是全天下最划算的健身卡。
失效条件
窗口岗位、外勤岗位本来就一直在动，这条不适用。
翻车
有人十年工龄，腰肌劳损加颈椎曲度变直，一年理疗的钱够再买十年咖啡。
可靠度
乙
备注
这一条和“把尿喝黄”是一套的：水喝够了，厕所上得才勤；厕所上得勤，工位才离得开。
1.1.6

摸鱼的三个硬件：屏幕角度、耳机颜色、文件夹名字

◎ 建议可靠 乙代价 钱少 · 心理低
代价
花几十块钱买一副不起眼的耳机。
一句话
清闲的人不需要演技，需要的是环境设置。
怎么做
屏幕侧放三十度，不正面朝向门口；耳机用最普通的黑色，不用显眼的颜色；私人文件夹别起“复习资料”这种名字，起“临时”。摸鱼用的东西收在包里，别摊在桌上。
为什么
人对“同事在偷懒”的判断，七成来自视觉线索而不是实际工作产出。你把这些线索清掉，别人对你的默认印象就是“在忙正事”。
失效条件
领导座位在你正背后，这条全部作废。
翻车
有人屏保全是很明显的视频，耳机是亮粉色，桌面上一个命名为“刑法考试”的文件夹。全科室都知道他今年要考证。
可靠度
乙
备注
这一条听起来像小事，但在办公室里，可见度就是一切。

1.2单位的忙，是有周期的

单位的忙不是平均分布的。它像潮水：月底、年底、检查前、领导换届前，涌上来；其余时间是平的。

大多数人踩的坑，是在平潮期把力气用光，等浪来了反而没劲了。

这一节讲怎么读潮汐表。核心一句话：你不用一直忙，你只要在对的时间忙。

1.2.1

月底、年底、检查前才是战场

● 必做可靠 乙代价 无
代价
要忍住”现在多做点表现一下”的冲动。
一句话
一年十二个月，真正决定别人怎么看你的是那三四周。
怎么做
拿一张纸，把去年单位”最紧张”的几周标出来——季度末、年终考核前、上级检查前、民主生活会前。剩下的日子，正常干，别加码。
为什么
体制内的评价节点是集中的。评优、考核、提拔、检查，全挤在固定时段。你的表现只有在这些时点才会被计算，平时干得再多，也只是把素材堆在那里，没人翻。
失效条件
服务性岗位、窗口岗位，忙是随人流走的，不按日历。那种岗位要看自己的月度曲线。
翻车
有人全年紧绷，年底那两周反而累垮了，最后考察谈话时状态极差。
可靠度
乙
备注
这一条能替你省下一年里最虚耗的那几个月。
1.2.2

领导的急不是你的急

● 必做可靠 乙代价 无
代价
可能会被说”不够主动”。
一句话
天塌下来，也先吃完饭。他真的急，会自己来推。
怎么做
领导催一件事，先问一句”什么时候要”。他说明天，你就明天给；他说”尽快”，你就问”今天下班前行吗”。有了明确时间，你就不用陪他焦虑。
为什么
领导的急大部分来自上头给他的压力，他需要下属分担情绪。但事情的物理 deadline 只有一个——你真的做到那个点，事不会崩。提前三天做完，收益接近于零；把自己的节奏打乱，代价立刻兑现。
失效条件
他真的追到你面前、盯着你干，那就是真急。这时候别讲方法，先动。
翻车
有人接到任务当天干到凌晨两点，第二天交上去，领导说”这个月底才要”。
可靠度
乙
备注
分辨真假急事的标准很简单：看 deadlines 说没说清楚。说不清的，多半不急。
1.2.3

慢是一种能力：多数急事，晚一天不会死

可靠 乙代价 时间少 · 心理中
代价
要顶住”你怎么还不急”的眼神。
一句话
单位里九成”急事”，放二十四小时会自动降级。
怎么做
接到急事，不要立刻进入冲锋状态。先做一件最简单的事——把要求复述一遍，跟对方确认 deadline。然后在纸上写下真实的时间点，按那个点排。
为什么
行政系统有自我纠错能力：真会出人命、真会被通报的事，早就不等你表态、直接压下来了。剩下的”急”，多数是传递过程中的焦虑放大。你跟着急，只是替别人的情绪买单。
失效条件
涉及安全、上访、突发舆情、以及你自己牵头的事，不能慢。
翻车
有人被一句”下午就要”追了一整天，晚饭没吃。晚上九点对方说”不急了，明天上午给我就行”。
可靠度
乙
备注
这一条练的不是拖延，是把”别人的急”和”我的急”分开。
1.2.4

别做第一个交活的，也别做最后一个

● 必做可靠 乙代价 无
代价
要忍一会儿，别抢功。
一句话
第一个交的人，设定标准；最后一个交的人，承担风险。中间最好。
怎么做
看同组其他人什么时候交。如果大家都周五交，你周四交就是在抬高水位，以后所有人都得这个点交。拖到周五下班前一点交，既不掉队，也不当出头鸟。
为什么
交活的顺序，本质是在团队里设定预期。你交得越早，后面的人越难做，也会被默认为”你可以更快”。这是典型的自设约束被当成硬约束的过程。
失效条件
你的活要靠别人的输出才能推进，或者会卡住下游，那就必须早交。
翻车
有人每次都是第一个交，领导从此把他的 deadline 默认为全组最早。他一年比别人多熬了无数个夜，考核并没有因此好看。
可靠度
乙
备注
这一条不是教你偷工，是别用自己的余量，去抬高所有人的水位。
1.2.5

看起来很忙和真的很忙，是两种活法

● 必做可靠 乙代价 无
代价
要装，心里有点别扭。
一句话
真正决定你处境的是看起来忙，不是真的很忙。
怎么做
走路快半步、手里拿一叠纸、进门先叹气再坐下、桌上摊着文件。这些都是零成本的信号，而且不骗人——你只是把状态外化出来了。
为什么
领导对下属的判断，用的是可见信号，不是真实产出。这不是他昏，是他一天看二十个人，只能靠状态筛选。你看起来很忙，他就不会再多派活；你看上去很闲，就算真有产出，他也觉得你还能再加一件。
失效条件
领导只看数字、只看结果的岗位，这条无效。
翻车
有人全年真忙，因为总闷头干活不吭声，年底被评价”工作量不饱和”。另一个只做了三件事但每次都四处同步的，被评为”挑大梁”。
可靠度
乙
备注
这一条听起来很坏。但你换个角度：它只是提醒你，真实产出和可见产出之间，有个必须自己补的 translation 环节。
1.2.6

检查前两周冲，其余时间养

● 必做可靠 乙代价 无
代价
要在该松的时候真的松。
一句话
把一年当成两个季节：检查季和非检查季。
怎么做
非检查季，正常干、别出头、别创新，把身体和情绪养着。检查季，把库存的东西补好、把台账捋顺、把亮点整理成材料。其余时间加的班，检查时全用不上。
为什么
上级检查看的是”有没有留痕、有没有制度、有没有整改”，不是”你这个团队平时多拼命”。检查前突击，效率反而是全年最高的——因为目标极度清晰。
失效条件
窗口单位、检查常年化的单位，这条要改成”检查前一周冲，其余时间养”。
翻车
有人提前半年开始准备检查材料，做了八十页台账。检查当天领导拿了三页核心的，剩下的没人翻。
可靠度
乙
备注
这一条和 1.2.1 是同一个算法的两种说法：读周期，不要在平潮期透支。
1.2.7

加班到二十一点的会，能推就推

◎ 建议可靠 乙代价 时间中 · 心理中 · 人情欠一个
代价
需要理由，而且不能用太多次。
一句话
晚上九点还在单位开会，多半是因为白天被浪费了，不是因为这活多重要。
怎么做
提前说”今晚家里有事”，比坐到一半再走体面。推不掉就带本书、带个水杯，把自己降到最低功耗，人在场而已。
为什么
夜里开会的信息密度极低，多数时候是领导在表达焦虑。你在场的作用是”在场”，不是”贡献”。而夜里那三小时的损耗，第二天要一整天补，并且没有任何补偿。
失效条件
突发应急、抢险、以及明确点名你必须到场的会，没得推。
翻车
有人一年陪了几十场夜会，身体先垮，后来医生说”你再这么熬，四十岁就要来看我”。
可靠度
乙
备注

这一节所有条目合起来是一句话：单位的忙是周期性的，你的力气要按周期花，不能按日历花。

1.3活儿干完，人不见

时间算出来了，还得会守住。

1.4.1

本节小结

十二条，合起来只有一个原则：在单位，做一个不讨厌、但也不拼命的人。

不讨厌，是因为你把分内事干完了，没人找得到你的茬。不拼命，是因为你算清了这笔账——编制给你的是八小时的工资，你给它八小时的活，剩下的都归你自己。

卷二

身体账

编制买的是你的八小时，不是你的命

老油条最心疼的，是看见年轻人拿命换一句表扬。这一卷算的是：你为这份工作，往身体里贴进去了多少。

2.1情绪劳动，也是劳动

单位里最累的活，不在手上，在脸上。

撑着笑、撑着听、撑着不急、撑着做一个"情绪稳定"的人。这种累没有加班费，没有调休，但它比搬一天东西还伤人。

社会学家霍克希尔德研究空乘人员时给这种劳动起了个名字：情绪劳动。它的特点是——你真实的感觉和你必须表演的感觉，是两回事；这两件事之间的落差，就是你付出的成本。

这一节讲怎么把这个成本降下来。

2.1.1

开完会像被打了一顿，那不是累，是耗

● 必做可靠 甲代价 无
代价
要承认自己不是"扛得住"，是"一直在扛"。
一句话
体力累，睡一觉就好；情绪累，睡十觉也缓不过来。
怎么做
认三个信号——不想说话、看谁都不顺眼、回家只想刷手机到深夜。出现两个，说明这一周你的情绪账户已经透支了，接下来要主动做减法。
为什么
情绪劳动消耗的是同一份"自我控制资源"，和忍住不吃、忍住不发火是同一个池子。你在会上笑了一上午，下午就没有力气再对家人有耐心——不是你变坏了，是那份资源用完了。
失效条件
短期高强度（比如迎检、办大会）属于集中支出，之后必须有一次补偿性休息，否则会累积成耗竭。
翻车
有人在单位永远是"脾气最好的那个"，回家对老婆孩子一点就着。他自己也觉得奇怪，其实不是性格问题，是账算错了地方。
可靠度
甲（情绪劳动是组织行为学的成熟概念，有大量实证研究）
备注
这一条是全卷的地基。承认"情绪也是劳动"，后面几条才成立。
2.1.2

下班不聊工作，周末不看工作群

● 必做可靠 乙代价 时间少 · 心理中
代价

为什么
工作群的信息 90% 是"通知"和"收到"，不需要你即时响应。而它每一次弹出，都在把你从"生活状态"拽回"工作状态"——这个切换的成本，比你处理那条消息的成本高得多。

翻车

2.1.3

2.1.4

● 必做可靠 乙代价 时间中 · 心理中
代价
那两天要真的做到。
一句话
不是"尽量不带"，是"这两天绝对不带"。
怎么做

"尽量"等于"没有"。人对模糊的承诺没有执行力，只有明确的规则才有。而连续两天完全不碰工作，是让神经系统完成一次完整降级的最低时长——一天的休息只够缓过来，不够恢复。
失效条件

翻车

可靠度

备注

2.1.5

把"我今天已经做完了"当成一个必须完成的任务

2.1.6

别在单位当情绪垃圾桶

◎ 建议可靠 乙代价 时间少 · 心理中 · 人情欠一个
代价
可能被说"不合群"。
一句话
听人吐槽是有成本的，而且这个成本不会有人替你付。
怎么做
同事开始长篇抱怨时，用"嗯""是吗""确实"三句话应付，不给建议、不接话茬、不跟着骂。想脱身就说"我先去趟厕所"。
为什么
情绪是会传染的（情绪 contagion 是有实证的）。你听半小时抱怨，自己的情绪基线会被拉低，而且这种拉低是无意识的。单位里最消耗人的往往不是领导，是那个每天中午都要跟你吐槽的同事。
失效条件
对方真的遇到大事（家里出事、被处分），该听还得听。那是人情，不是垃圾桶。
翻车
有人当了五年"知心大姐"，全单位都来找她倾诉。她后来得了失眠，医生说"你这是替太多人操心了"。
可靠度
乙
备注
这一条不是教你冷漠。是提醒你：共情是有限资源，要花在值得的人身上。

本节小结

这一节只有一句话：单位不只买你的时间，还想买你的情绪。前者有工资，后者没有。

认清了这一点，你就知道哪些情绪该给、哪些不该给。给出去的那些，要算进成本；不该给的那些，一个眼神都不必多费。

下一节讲更实在的：怎么把单位的时间，用在养自己的身体上。

2.2把单位的时间，用在养身体上

上班八小时，你至少有六小时是坐着的。

这六小时，有人用来把身体坐坏，有人用来把身体养回来。差别不在有没有健身房，在几个非常土的习惯。

这一节讲的就是这些土办法。它们都不高级，但都便宜、都有效、都不需要跟谁请假。

2.2.1

单位食堂的正确用法：早去、吃完就走

● 必做可靠 乙代价 无
代价
少听几句饭桌上的闲话。
一句话
食堂是吃饭的地方，不是社交场。你早去十五分钟，能省掉后面一小时。
怎么做
十一点半就去，吃完直接走。别在食堂坐着聊天——那是单位里最容易耗时间、最容易吃多、最容易说错话的地方。
为什么
食堂同时是三个陷阱：吃得太多（自助式最容易过量）、坐得太久（饭后闲聊半小时起）、说得太多（饭桌是流言的集散地）。这三个都是纯损耗，收益为零。
失效条件
新人期需要混脸熟，那就去，但要控制时间。
翻车
有人每天中午在食堂坐到一点半，三年胖了二十斤，还成了几个派系都"认识"的人。
可靠度
乙
备注
真要社交，一顿正式的饭比三十顿食堂闲聊有用得多。
2.2.2

那顿免费体检，别浪费

● 必做可靠 甲代价 无
代价
要花半天时间。
一句话
单位掏钱的那次体检，是你一年里最便宜的一次"提前发现"。
怎么做
别只做基础套餐。四十岁以上加胃肠镜（或至少便潜血）、低剂量胸部 CT；女性加乳腺和宫颈筛查；有家族史的，针对性加项。加项自己花钱，几百到一两千，比事后治疗便宜一百倍。
为什么
多数重大疾病的早期没有症状，只能靠筛查发现。而单位体检的基础套餐，覆盖的项目很有限——它更像是"合规动作"，不是"健康评估"。
失效条件
已经确诊慢性病的，按专科医生的复查计划走，不用重复做。
翻车
有人连续八年只做基础套餐，第九年查出问题时已经是中期。
可靠度
甲（癌症筛查的有效性有大量循证依据）
备注
这一条是全书少数"救命"级别的建议，别嫌麻烦。
2.2.3

久坐的解法不是站起来办公，是每小时走五分钟

● 必做可靠 甲代价 无
代价
一个闹钟。
一句话
站着办公救不了久坐，动起来才行。
怎么做
每小时起身走五分钟，去接水、去厕所、走楼梯。一天六到八次，加起来就是四十分钟的活动量。
为什么
久坐的危害主要来自"长时间保持同一姿势"，而不是"坐着"本身。站着不动，问题一样存在。真正有效的是打断——每小时一次的活动，能显著改善血糖、血脂和腰椎负荷。
失效条件
行动不便的岗位，改成坐姿的拉伸和抬腿也有效。
翻车
有人买了升降桌，站了一天，腰更疼了——因为他站着也不动。
可靠度
甲
备注
这一条和 1.1.5 是同一件事的两种说法：一个是"怎么离开工位"，一个是"离开工位干什么"。
2.2.4

值夜班之后的恢复，比夜班本身更伤身

● 必做可靠 乙代价 无
代价
要占用一个白天。
一句话
夜班伤一次，恢复不当伤三次。
怎么做
下夜班回家路上戴墨镜（减少光照对生物钟的干扰）；回家先睡四小时，不要睡一整天；起床后正常吃一顿，下午晒二十分钟太阳；当天晚上按正常时间睡。
为什么
生物钟的重置靠光照和进食信号，不靠"补觉时长"。你睡十小时，生物钟还是乱的；你按点吃、按点晒、按点睡，两天就能回正。而长期倒班的人，代谢病、心血管病的风险都显著升高。
失效条件
连续多日夜班的岗位，单次恢复法不适用，要靠排班周期整体调整。
翻车
有人下夜班睡到下午五点，晚上睡不着，第二天又困，一周都在颠倒。
可靠度
乙
备注
这一条对医生、护士、公安、应急岗位的人尤其重要。
2.2.5

别在单位吃太多——很多人的工伤是胖出来的

● 必做可靠 乙代价 无
代价
要忍住下午那顿零食。
一句话
体制内最常见的职业病不是腰椎间盘，是代谢综合征。
怎么做
食堂打饭用小盘；下午饿了吃坚果或水果，别吃饼干糕点；单位发的零食礼盒，转手送人；应酬的饭吃到七分就放筷子。
为什么
久坐加食堂加应酬，是三重叠加。而体重上去之后，血压、血糖、血脂、尿酸会一起上来，这些都不是"注意一下"能解决的。四十岁以后的体检报告，基本是三十岁那几年吃出来的。
失效条件
体力岗位、外勤岗位消耗大，不适用。
翻车
有人三十五岁查出脂肪肝，四十岁查出糖尿病前期，医生第一句话是"你这个工作，是不是天天坐着还老吃饭局"。
可靠度
乙
备注
这一条不好听，但它比前面所有条目都更能决定你晚年的生活质量。
2.2.6

眼睛的账，四十岁以后一起还

◎ 建议可靠 乙代价 钱少
代价
一副合适的眼镜，或者一次眼科检查。
一句话
一天看八小时屏幕的人，四十岁以后的视力账，都是年轻时欠的。
怎么做
每二十分钟看二十英尺外二十秒（20-20-20 法则）；屏幕亮度跟环境光接近，别在暗处看亮屏；每年查一次眼底，尤其近视度数高的。
为什么
长时间近距离用眼会让睫状肌持续紧张，干眼、视疲劳、近视加深都是这么来的。而眼底问题（尤其高度近视者的视网膜病变）早期没感觉，只能靠查。
失效条件
无。
翻车
有人四十五岁开始老花，同时干眼严重到下午没法看电脑，只能靠滴眼药水撑着。
可靠度
乙
备注
这一条的成本极低，收益极高，属于"知道就该做"的那类。

本节小结

这一节六条，成本加起来不到一千块，占用时间不到一天。

但它们决定的是：你五十岁的时候，是还能爬山、还能陪孩子跑，还是每天吃四种药、上楼要歇两次。

身体这笔账，是唯一不能透支的账。

下一节讲应酬——体制内最难拒绝的那顿饭。

2.3应酬的身体账

体制内最伤身体的事，不是加班，是不得不喝的那顿酒。

这顿饭的特点：你不去不行，去了不喝不行，喝了不醉不行，醉了第二天还得正常上班。

这一节不讲"怎么在酒桌上赢"，讲的是怎么把损耗降到最低，怎么少去，以及怎么不伤面子地不喝。

2.3.1

"我开车来的"，是最好用的一句话

● 必做可靠 乙代价 无
代价
可能要真的开车。
一句话
这句话的好处是，它把"我不喝"变成了"我不能喝"，责任不在你。
怎么做
提前想好理由，最好是物理性的——开车、吃药、明天体检、哺乳期。别用"我不想喝"这种主观理由，那是在挑战对方。
为什么
酒桌上的劝酒，本质是一场服从性测试。你用"不想"来拒绝，测试就不通过；你用"不能"来拒绝，测试的对象就转移到了客观条件上，对方有台阶下。
失效条件
对方明确说"叫代驾"或者"喝完住这"，这个理由就失效了，得换。
翻车
有人每次都硬扛，喝到胃出血住院。领导来看他，第一句话是"下次别这样了"——但下次还是叫他。
可靠度
乙
备注
这一条的核心不是话术，是提前设防。临时找理由，谁都不信。
2.3.2

喝酒前半小时吃什么，能少受三成罪

● 必做可靠 乙代价 钱少
代价
要提前准备。
一句话
空腹喝酒，等于把胃黏膜直接泡在酒精里。
怎么做
赴宴前半小时，喝一杯牛奶或酸奶，吃两片面包或几块饼干。桌上先吃主食和油脂类（不是凉菜），再动酒。
为什么
食物能延缓酒精吸收速度，降低血液酒精浓度的峰值。这不能让你"千杯不醉"，但能显著减轻恶心、头痛和第二天的宿醉。
失效条件
无。这条适用于所有需要喝酒的场合。
翻车
有人空腹喝了两杯白酒，半小时后当场吐在桌上，之后十年都被当笑话讲。
可靠度
乙
备注
这一条是所有应酬建议里性价比最高的：成本几块钱，收益是半条命。
2.3.3

喝多之后的第二天，怎么把损耗降到最低

◎ 建议可靠 乙代价 无
代价
第二天状态还是差。
一句话
宿醉没有解药，只有"少受罪"的办法。
怎么做
睡前喝一大杯水（加一点盐）；第二天早上继续补水，吃碳水（粥、面），别喝浓茶和咖啡；能睡就再睡一会；不要"以酒解酒"。
为什么
宿醉主要是脱水和代谢产物堆积造成的。补水和补糖能缓解大部分症状，而咖啡因会加重脱水，"回魂酒"只是把问题推迟到下一次。
失效条件
出现剧烈呕吐、意识模糊，那是急性酒精中毒，要去医院。
翻车
有人第二天靠浓咖啡硬撑，结果心悸加头痛，一整天什么都干不了。
可靠度
乙
备注
最好的办法永远是前一天少喝。这一条只是补救。
2.3.4

关系不到位的饭局，你在桌上只是凑数

● 必做可靠 乙代价 无
代价
可能被说"不给面子"。
一句话
你不在那个圈子里，去了也只是背景板，还得陪笑到十点。
怎么做
判断标准很简单——这顿饭上，有没有人会主动跟你说话？如果全程只有你敬别人、没人问你，那这顿饭对你毫无价值。
为什么
饭局的价值来自信息交换和关系推进，而这两件事都需要"对等"。你级别不够、资源不够、信息不够，坐在那里就是个陪衬。陪衬的成本是整晚的时间和一场宿醉，收益是零。
失效条件
新人期需要露脸、或者这顿饭有你想认识的人，那值得去。
翻车
有人一年陪了四十多场饭局，喝坏了胃，一个真朋友没交到。
可靠度
乙
备注
这一条和 1.1.10 是一回事：不是所有饭都值得吃。
2.3.5

真正伤身体的不是酒，是"不得不喝"的那口气

● 必做可靠 乙代价 无
代价
要接受自己"不合群"。
一句话
同样是三两酒，你愿意喝和被迫喝，身体的反应完全不一样。
怎么做
把"我必须喝"改成"我选择喝这一杯"。哪怕只是心理上换个说法，压力激素的水平都会不一样。
为什么
被迫的状态会持续激活应激反应（皮质醇、心率、血压），而自愿的状态不会。这就是为什么有些人喝一斤没事，有些人喝二两就难受——差别不只在酒量，也在心理状态。
失效条件
这条不能当挡箭牌。真不想喝，还是要用 2.3.1 的办法拒绝。
翻车
有人每次喝酒前都在心里骂，喝完必吐，吐完必失眠。同一桌另一个人喝得一样多，全程乐呵呵，什么事没有。
可靠度
丙（机制成立，个体差异大）
备注
这一条真正想说的是：能拒绝的场合就拒绝，拒绝不了的就换个心态。两头都不占，最亏。
2.3.6

拒酒的三层话术，从软到硬

◎ 建议可靠 乙代价 无
代价
要练，而且第一层可能不管用。
一句话
拒绝要一层一层加码，别一上来就把话说死。
怎么做

1. 软拒："我今天真不行，以茶代酒，我敬您。"

2. 硬拒："医生说了，我这胃再喝就得住院。"（有具体病名，可信度高）

3. 终拒：端起杯子但不喝，"这杯我记着，改天我单独请您。"

为什么
酒桌上的拒绝，本质是给对方留面子。你一层一层加码，对方也有台阶一层一层下。直接掀桌子的拒绝，赢了道理，输了关系。
失效条件
遇到强行灌酒的，别讲策略，直接走人。那不是应酬，是欺负人。
翻车
有人第一次就用了终拒，当场把气氛搞僵，之后三年没被叫过任何饭局——包括该去的。
可靠度
乙
备注
第三层是最后的体面。用了它，等于告诉对方"我不是不给你面子，我是不给自己机会"。

本节小结

这一节没有一条教你"怎么喝赢"。

因为酒桌上没有赢家——喝多的伤身，喝少的伤关系，陪笑的伤自尊。真正的赢法是：少去、少喝、去之前先吃点东西。

下一节是整卷的出口：下班就是下班。

2.4下班就是下班

前面三节算的是你自己的账：情绪、身体、应酬。

这一节算最后一笔，也是最贵的一笔：你家里人替你付了多少。

单位离了谁都转，你家离了你转不动。这句话听起来像鸡汤，但它是这本账里唯一不能打折的一条。

2.4.1

家属问"单位累不累"，标准答案是"还行"

● 必做可靠 乙代价 无
代价
要忍住倒苦水的冲动。
一句话
"还行"不是撒谎，是不把单位的账转给家里。
怎么做
回家第一句话别说单位的糟心事。想说就等吃完饭、等孩子睡了，用十分钟说完，别复盘、别逐条分析。
为什么
你倒一次苦水，家人要担心一整晚，而你第二天就忘了。这种"情绪转移"的代价，是家人替你承担了你本该自己消化掉的东西。而且说多了，家人对单位的印象会变差，最终变成"你别干了"——那是另一场战争。
失效条件
真的遇到大事（被处分、被调岗、想辞职），必须说，而且要好好说。
翻车
有人每天回家都要讲一遍单位的破事，讲了五年。后来妻子说："我发现你只有在骂单位的时候话最多。"
可靠度
乙
备注
这一条不是让你憋着。是让你分清"消化"和"转移"。
2.4.2

陪孩子的优先级，高于一切"紧急但不重要"的群消息

● 必做可靠 乙代价 无
代价
可能晚回半小时消息。
一句话
孩子只在你身边这几年，工作群会一直在。
怎么做
陪孩子的时候，手机放另一个房间。真的怕误事，就设一个"只响重要联系人"的模式。
为什么
孩子对"你在不在"的判断，不是看你人在不在家，是看你眼睛在不在他身上。你坐在旁边刷手机，他感受到的是"爸爸在，但爸爸不想理我"。这种感受累积起来，就是青春期的沉默。
失效条件
突发应急、必须在线值班的时段，另说，但要跟孩子说明白。
翻车
有人孩子上初中后基本不跟他说话，他以为是叛逆。妻子说："你从他五岁起就一直在看手机。"
可靠度
乙
备注
这一条的回报要等十年才看得见，所以最容易被牺牲。
2.4.3

周末的家庭日，比任何会议都不可侵占

● 必做可靠 乙代价 无
代价
要拒绝一些周末的"顺便来一下"。
一句话
周末被侵占一次，就会有第二次；守住一次，对方下次就不叫你了。
怎么做
周六或周日固定一天，全家出门或在家做饭，不安排任何工作。有人叫你，就说"这天家里有安排"，不解释具体是什么。
为什么
单位对"你什么时候有空"的判断，来自你的历史行为。你周末随叫随到三次，第四次不叫你就怪了。你守住一次，对方会自动把你排除在"周末可用名单"之外——这正是你要的。
失效条件
集中攻坚、突发任务，该去还得去，但要有次数上限。
翻车
有人连续两年周末随时待命，后来孩子已经习惯"爸爸周末要上班"，不再问他能不能一起去公园。
可靠度
乙
备注
这一条和 1.1.4（17:30 之后是另一个宇宙）是同一个逻辑，只是时间单位从"天"变成了"周"。
2.4.4

别把单位受的气，撒给最亲的人

● 必做可靠 乙代价 无
代价
要在门口停三分钟。
一句话
这是全书最贵的一笔转移支付——你付的是家人的情绪。
怎么做
进门前在车里或楼道里坐三分钟，什么都不想，或者深呼吸十次。进门先问一句家里的事，别先讲单位的。
为什么
人在单位受了气，攻击性会积压，而最安全的发泄对象就是家人——因为他们不会反击。这就是为什么很多"单位里的老好人"，回家是暴君。这笔账的荒谬之处在于：你为了在外面维持形象，把成本全转给了最不该承担的人。
失效条件
无。这一条没有例外。
翻车
有人因为单位一件事心情差，回家摔了一个碗。三年后离婚，妻子说："不是因为那个碗，是因为那三年。"
可靠度
乙
备注
这一条是全书最不该省的一条。省下它，前面所有条目都白算。
2.4.5

你为工作熬的每个夜，最后都是家人在替你买单

● 必做可靠 乙代价 无
代价
要重新算一遍加班的账。

加班费是你的，代价是全家分摊的。

加班的成本从来不是"你少睡了几小时"，而是"这个家少了一个人"。而且这笔成本是复利的：缺席的次数多了，关系会变淡，变淡之后要花十倍的时间补回来，多数时候补不回来。

2.4.6

家里的气氛，比单位的一句表扬值钱

◎ 建议可靠 乙代价 无
代价
要放弃一点"被认可"的渴望。

每周至少有一次全家一起吃饭不看手机；每个月有一次全家出门；每年有一次全家旅行（不用远，本市也行）。

失效条件
无。
翻车
有人拿了一摞奖状，退休那天全扔了。他说："这些纸，没有一张能换回我儿子的童年。"

本节小结

这一节六条，讲的其实是同一件事：把单位和你自己切开。

不是不爱工作，是不把整个人生都押在上面。单位需要的是一个能干活的人，家里需要的是一个完整的人。这两个角色不冲突，但需要你主动划一条线。

线划好了，两边都能过好。

2.5睡眠：体制内最缺的一样东西

体制内有一种奇怪的攀比：比谁睡得少。

"昨晚改材料到两点""值班一宿没睡"——说出来像勋章。

但睡眠不是可以省的支出，它是所有支出的本金。你少睡的那两小时，第二天要用四小时的效率去补，而且补不回来。

这一节讲怎么把睡眠守住。

2.5.1

睡眠是唯一不能省的健康投资

● 必做可靠 甲代价 无
代价
要放弃"我很拼"的人设。
一句话
少睡两小时，第二天多犯三个错，这笔账怎么算都亏。
怎么做
把睡眠当成硬约束，写进日程——几点必须上床，像会议一样不可取消。工作没做完，明天做；材料没改完，明天改。
为什么
睡眠不足会直接损伤前额叶功能，也就是判断力、自控力和情绪调节。你不是"困一点"，是"变笨一点、脾气差一点"。而这三个恰恰是体制内最需要的能力。
失效条件
极少数真正的应急（抢险、突发），可以透支一两天，但之后必须补。
翻车
有人连续一个月加班到凌晨，材料是交上去了，但中间出了三个低级错误，被领导批"不细致"。
可靠度
甲（睡眠剥夺对认知功能的影响有大量实证研究）
备注
这一条和 1.2.7"加班到九点的会能推就推"是配套的。
2.5.2

值班之后的补觉，不能靠"周末缓一缓"

● 必做可靠 乙代价 无
代价
要占用一个白天。
一句话
睡眠债不是存款，不能攒着一起还。
怎么做
值完夜班，当天回家先睡四小时，不要睡一整天；下午起来晒二十分钟太阳，正常吃一顿；晚上按正常时间睡。
为什么
生物钟靠光照和进食信号重置，不靠"睡够总时长"。你睡十小时，钟还是乱的；按点吃、按点晒、按点睡，两天就能回正。
失效条件
连续多日夜班的岗位，单次恢复不适用，要靠排班周期整体调整。
翻车
有人下夜班睡到下午五点，晚上睡不着，第二天更困，一周都在颠倒。
可靠度
乙
备注
这一条和 2.2.4 是一对：一个讲恢复，一个讲补救。
2.5.3

睡前不看工作群，是最便宜的一味安眠药

● 必做可靠 乙代价 无
代价
可能错过消息。
一句话
睡前看到的那条消息，会让你多醒两个小时。
怎么做
睡前一小时把手机放到另一个房间，或者开飞行模式。真有急事，会有人打电话。
为什么
睡前接收的信息会进入"睡前反刍"——大脑在入睡前会反复处理未解决的事。一条"明天要交"的消息，足够让你在床上演一小时的灾难片。
失效条件
值班、待命状态，另说。
翻车
有人睡前刷到一条批评他的消息，一夜没睡好，第二天顶着黑眼圈去解释，反而显得心虚。
可靠度
乙
备注
这一条的成本是零，收益是第二天一整天。
2.5.4

失眠别硬扛，先分清是哪一种

◎ 建议可靠 乙代价 无
代价
要面对自己。
一句话
睡不着分两种——脑子停不下来，和身体不肯睡。
怎么做
脑子停不下来（焦虑型）：睡前把明天的事写在纸上，写完就"交出去"；身体不肯睡（节律型）：固定起床时间，白天多晒太阳，别补觉。
为什么
两种失眠的成因不同，处理方式相反。焦虑型需要"卸载"，节律型需要"校准"。用错方法，越努力越睡不着。
失效条件
连续一个月以上、且影响白天功能，那是需要就医的失眠障碍，不是自我调节能解决的。
翻车
有人为了睡着提前两小时上床，结果在床上躺了两小时更焦虑，形成了"床=焦虑"的条件反射。
可靠度
乙
备注
这一条的关键是"别硬扛"，也别自己乱吃药。
2.5.5

午睡超过三十分钟，下午会更困

◎ 建议可靠 乙代价 无
代价
要设闹钟。
一句话
午睡的最佳长度是二十到三十分钟，超过就进入深睡眠，醒来更难受。
怎么做
定二十五分钟的闹钟，睡不着也闭眼躺着。醒来洗把脸，走两步。
为什么
睡眠有周期，进入深睡眠后被叫醒，会产生"睡眠惯性"——头晕、迟钝、情绪差，持续半小时以上。而二十分钟的小睡只停留在浅睡眠，醒来是清醒的。
失效条件
周末、休息日，想睡多久睡多久。
翻车
有人午睡一小时，醒来头重脚轻，下午开会一直在走神。
可靠度
乙
备注
这一条和 1.1.3 配套：午休是单位发的，但要会睡。
2.5.6

什么时候该去看医生，而不是继续"调整作息"

● 必做可靠 甲代价 钱少
代价
要承认这不是"意志力问题"。
一句话
连续一个月睡不好，就不是作息问题了。
怎么做
出现以下任一情况，去睡眠门诊或精神心理科——入睡困难超过 30 分钟且持续一个月、夜间频繁醒、早醒且无法再入睡、白天功能明显受损、打鼾伴憋气。
为什么
慢性失眠、睡眠呼吸暂停、焦虑抑郁都会表现为"睡不好"，而这三类的处理方式完全不同。自己调整作息，对前两类基本无效，还会耽误时间。
失效条件
短期的、有明确诱因的（比如赶材料），调整几天就好，不必就医。
翻车
有人打鼾十年，一直以为"睡得香"，后来查出重度睡眠呼吸暂停，血压已经高了。
可靠度
甲
备注
这一条不丢人。体制内看睡眠门诊的人，比你想的多。

本节小结

这一节六条，讲的是：睡眠不是可以牺牲的变量，是所有其他变量的前提。

你省下的每一个小时睡眠，都会以判断力、脾气和健康的形式还回去。

而这三样，恰恰是你在单位最需要的东西。

2.6体检报告怎么看

单位每年发一份体检报告。

多数人翻两页，看到"未见明显异常"就收起来；看到几个箭头，心里咯噔一下，然后放回抽屉，第二年再说。

这份报告其实是你一年里最便宜的一次"身体审计"。这一节讲怎么读它。

2.6.1

先看结论页，别急着看箭头

● 必做可靠 乙代价 无
代价
要花十分钟。
一句话
报告的价值在"建议"那几行，不在箭头。
怎么做
先看总检结论和建议，再看具体指标。结论里写"建议复查""建议专科就诊"的，优先处理。
为什么
体检报告有几百项，多数轻微异常没有临床意义。而总检医生已经帮你筛过一轮了——他写的建议，是这份报告里信息密度最高的部分。
失效条件
无。
翻车
有人盯着一个偏高的箭头焦虑了半年，却忽略了结论页写的"建议胃肠镜复查"。
可靠度
乙
备注
这一条能让你少走很多弯路。
2.6.2

四个必须追下去的指标

● 必做可靠 甲代价 无
代价
可能要复查、要花钱。
一句话
血压、血糖、血脂、尿酸——这四项异常，十年后基本都会变成病。
怎么做
这四项只要有箭头，就认真对待。轻度异常先改生活方式，三个月后复查；持续异常去专科。
为什么
这四项是代谢综合征的核心指标，它们异常时人没有感觉，但会持续损伤血管和器官。等到有感觉，通常已经是并发症阶段。
失效条件
单次轻度异常可能是应激、饮食影响，复查确认即可。
翻车
有人连续五年血糖偏高，一直"注意饮食"，第六年查出糖尿病，已经有了视网膜病变。
可靠度
甲
备注
这四项加起来，构成了中国人最常见的慢病基础。
2.6.3

结节、囊肿、息肉：多数不用怕，但要跟

● 必做可靠 甲代价 无
代价
要每年复查。
一句话
报告上出现这些词，第一反应应该是"多久复查"，不是"是不是癌"。
怎么做
看报告里的分级和描述——甲状腺结节看 TI-RADS 分级，乳腺看 BI-RADS，肺结节看大小和密度，肠息肉看病理类型。分级低的，按医生说的周期复查；分级高的，进一步检查。
为什么
绝大多数结节是良性的，但"良性"不等于"不用管"。它们需要的是"随访"，不是"治疗"，也不是"忽略"。
失效条件
无。
翻车
有人查出肺结节后吓了半年，做了三次 CT。其实医生说的是"一年后复查"。
可靠度
甲
备注
这一条的目的是让你既不恐慌，也不忽略。
2.6.4

体检的盲区：它查不出什么

◎ 建议可靠 乙代价 无
代价
要知道自己还没查什么。
一句话
常规体检是"筛查"，不是"全面检查"。
怎么做

为什么

失效条件
无。
翻车
有人年年体检"正常"，第一次做胃肠镜就发现了进展期肿瘤。
可靠度
乙
备注
这一条不是让你把所有检查都做一遍，是让你知道边界在哪。
2.6.5

四十岁以后，加三项

● 必做可靠 甲代价 钱中

几百到两千块。

四十岁是身体的分水岭，也是加项的最佳时点。

为什么
这三项对应的是中国人死亡率最高的几类癌症和心脑血管事件，而它们都有明确的筛查手段和早期干预价值。
失效条件
无。
翻车

可靠度
甲
备注
这一条是全书少数"可能救命"的建议之一。
2.6.6

把报告存起来，做成一条曲线

◎ 建议可靠 乙代价 无
代价
要整理。
一句话
单次体检看的是"有没有超标"，连续几年看的是"往哪走"。

本节小结

这一节六条，讲的是一件事：体检报告不是一张成绩单，是一份预警。

看懂它，你就能在"还没生病"的时候做点什么。而这件事的价值，远远超过你在单位多干的那点活。

卷三

人情账

单位最累的不是活，是关系

解法不是会来事，是不入戏。这一卷讲怎么在关系里保持一个刚刚好的温度：不冷到没人配合，不热到交出软肋。

3.0权力的形状：单位里真正说了算的，往往不是一把手

你以为单位是一棵树，一把手在顶上，一级压一级。

不是。单位是一张网，每个节点上挂着一把锁。一把手能锁住所有门，但他打不开任何一扇门——开门要钥匙，钥匙在别人手里。

这一节讲的就是这张网：锁在哪，钥匙在谁那，以及你怎么在不碰任何一条红线的前提下，把事办成。

一、先把权力看对

3.0.1

权力不是"谁能命令谁"，是"谁能卡住谁"

● 必做可靠 乙代价 时间少 · 心理低
代价
看完这一条，你对单位的理解会变，且回不去。
一句话
命令是假的，否决是真的。一个人对你有没有权力，不看他能不能让你干，看他能不能让你干不成。
怎么做
拿一张纸，把最近三个月"卡住过你"的事列出来，写下每次是谁卡住的。写完你会发现，卡你的不是领导，是几个你想都没想到的人。
为什么
组织给每个人的授权，本质是"否决权"而非"决定权"。科员可以说"材料不全，退回"，财务可以说"票据不合规，不报"，档案员可以说"这个不能查"。他们谁都决定不了什么，但谁都能让一件事停在原地。权力 = 对不可绕过节点的控制。
失效条件
涉及"三重一大"的事项，最终决定权确实集中在班子，不在节点手上。但即便如此，节点仍然决定"什么时候上会、以什么版本上会"。
翻车
某人为了一个批文跑了半年，一直找领导，领导每次都签"同意"。最后卡在经办人那里，理由是"附件少一份"。他从来没问过经办人要什么。
可靠度
乙
备注
这一条是整节的地基。想不通这条，后面十四条你都用不上。
3.0.2

一把手的权力，在"否决"不在"决定"

● 必做可靠 乙代价 时间少 · 心理低
代价
要放弃"找大领导就能解决"的幻想。
一句话
一把手能推动的事很少，能拦下的事很多。所以求他，不要求"支持"，要避免"反对"。
怎么做
找他之前先想清楚——这件事他会不会有顾虑？顾虑是什么？把顾虑在材料里提前化解掉，比当面说服他有效十倍。
为什么
一把手的时间被切碎，注意力是稀缺资源。他没有精力去推动每一件事，但他对"风险"极度敏感。任何一件可能出事的事，他一句"再看看"就能让它无限期搁置。所以他的真实权力，是一票否决权。
失效条件
一把手亲自抓的中心工作、上级点名要办的事，他会主动推动，这时他的"决定权"是真的。
翻车
某人绕过分管领导，直接找一把手汇报，一把手当场说"很好，支持"。回去之后，分管领导一句"这个事再研究研究"，事情就没了。一把手的"支持"没有落地路径，等于没说。
可靠度
乙
备注
一把手说"支持"，你要追问一句"那我按什么程序走"。这句话能把口头支持变成路径。
3.0.3

"三重一大"上会，不是麻烦，是唯一合法的责任分摊通道

● 必做可靠 甲代价 时间中 · 心理低
代价
要走流程，慢。
一句话
一件事只要上了会、有纪要，出事时责任就是分摊的；没上会，责任就是经办人一个人的。
怎么做
凡涉及重大决策、重要人事、重大项目、大额资金，主动要求上会，并且要求纪要写清"会议同意"和"风险提示"。别嫌慢，慢是在给你上保险。
为什么
集体决策的合法性来自程序，追责时也要看程序。程序走全了，责任就在集体；程序没走，个人承担。这是硬约束，写在制度里，不是潜规则。
失效条件
紧急情况下的应急处置，允许事后补程序，但补的时候要如实写清"因紧急情况先行处置"。
翻车
某项目为赶进度，由分管领导口头拍板就干了，没上会。出问题后，追责链条上只有经办人一个名字——因为会议记录里没有这件事。
可靠度
甲（"三重一大"决策制度是党内法规和各单位制度的明确要求）
备注
这一条是整本书里最"正"的一条，也是最好用的一条。它不需要你搞关系，只需要你按程序走。
3.0.4

决定你日常的，是分管领导，不是一把手

● 必做可靠 乙代价 时间少 · 心理低
代价
要把注意力从"最大的领导"移到"管你的领导"。
一句话
一把手管"要不要"，分管领导管"怎么办"。而你的日子，全在"怎么办"里。
怎么做
把分管领导的关注点摸清楚——他今年最怕出什么事、最想做出什么成绩。你所有的工作汇报，都往这两件事上靠。
为什么
一把手的信息来自分管领导的转述。分管领导说你行，你就行；分管领导不提你，一把手永远不会知道你是谁。这是一条信息漏斗，漏斗的口在分管领导手里。
失效条件
单位很小、层级很扁，一把手直接管到每个人，这时漏斗不存在。
翻车
某人在一把手面前表现积极，被分管领导视为"越位"。此后所有能露脸的机会，都没他的份。
可靠度
乙
备注
这不是让你讨好分管领导，是让你明白：你的工作成果，必须经过他的嘴才能被看见。

二、七个节点，七把钥匙

3.0.5

管章的人，比管钱的人硬

● 必做可靠 甲代价 时间少 · 心理低 · 人情欠一个
代价
多跑一趟，多说一句好话。
一句话
钱可以走别的账，章只有一个。全单位所有的"正式"，最后都要经过那一个动作。
怎么做
盖章前先问"这个章该谁批"，不要问"能不能盖"。前一句是尊重流程，后一句是让他为难。
为什么
印章是法人意志的唯一物理载体。没有章的文件，在外部世界里等于不存在。管章的人职位不高，但他守着全单位唯一的"出口"。
失效条件
电子印章、OA 审批普及之后，物理章的重要性在下降，但"谁有权发起用印流程"这个节点仍然存在。
翻车
某人拿着领导签字的文件去盖章，管章的人说"这个事没上会，我不能盖"。他以为领导签了就行，其实流程还差一步。
可靠度
甲（印章管理制度普遍规定用印审批权限）
备注
不要试图"通融"。管章的人一旦通融，出事时第一个被追责的就是他——他不会为你冒这个险。
3.0.6

办公室主任管的不是杂事，是"议程"

● 必做可靠 乙代价 时间少 · 心理低 · 人情欠一个
代价
要花时间维护一段不显眼的关系。
一句话
主任决定不了事情怎么办，但他决定"哪些事能上领导的桌子"。
怎么做
材料报上去之前，先问主任一句"这个事最近上会合适吗"。他如果说"再等等"，你就等——他比你清楚领导这周的心情和日程。
为什么
议程设置权大于决策权。一件事进不了议程，就永远不会有决定；一件事被排进议程，就算没通过，也留下了记录。主任手里握着"排序"这支笔。
失效条件
单位有明确的议题申报制度和时限，主任只是执行者，没有自由裁量空间。
翻车
某人把材料直接送到领导手上，跳过了主任。领导随口说"放这吧"，材料在桌上躺了一个月。主任后来提起这事，只说了一句"他没走流程"。
可靠度
乙
备注
跟主任打交道，最好的姿态是"请教"，不是"请求"。
3.0.7

司机是单位里信息密度最高的人，但你不能碰

▲ 慎用可靠 丙代价 时间少 · 心理低
代价
知道了也不能用，得憋着。
一句话
领导在办公室不说话，在车上打电话。所以司机知道的，比秘书多。
怎么做
点头、递烟（如果对方抽）、逢年过节一句问候，到此为止。不打听、不送礼、不托他传话。 这三条是红线，碰一条，你就从"懂事"变成"危险"。
为什么
司机处在"非正式信息空间"的中心，但他同时也是最没有自保能力的人。你跟他走得近，他会紧张；你托他办事，他要么拒绝你，要么违规，两条路都是死。
失效条件
公车改革之后，很多单位已经没有专职司机，这条的适用面在缩小。
翻车
某人跟司机混得很熟，托他"顺便问问领导对我什么看法"。司机转头就告诉了办公室主任，办公室主任又告诉了领导。此人此后三年没被安排过任何重要工作。
可靠度
丙（不同单位差异极大，且涉及敏感地带）
备注
这一条的价值不在"用"，在"别踩"。知道这个信息枢纽存在，就够了。
3.0.8

财务是最后一道闸，也是唯一敢说"不"的部门

● 必做可靠 甲代价 时间少 · 心理低 · 人情欠一个
代价
报销、采购会比以前慢。
一句话
领导签字是"同意办"，财务签字是"钱能出"。前一个可以口头，后一个必须合规。
怎么做
事前问，不要事后补。拿着方案去问财务"这个怎么走账最合规"，比你办完了再想办法凑票，省十倍力气。
为什么
财务受《会计法》和审计约束，不是受领导个人意志约束。领导让你办，财务可以拒付；出了事，财务有"我已经提示过"的记录。所以财务是单位里唯一有制度性底气说"不"的岗位。
失效条件
主要领导强推、且有完整会议记录和书面批示的事项，财务通常会执行，但会把风险写进备注。
翻车
某人为一场活动垫了钱，事后报销被卡。财务说"这个科目没有预算"。他去找领导，领导说"我当时是同意办，没说走哪个科目"。
可靠度
甲（《会计法》第十四条等对原始凭证和审核责任有明确规定）
备注
跟财务打交道的秘诀只有四个字：事前问清。

三、怎么把事办成

3.0.9

找人办事的顺序：先问经办人要什么，再找领导批

● 必做可靠 乙代价 时间少 · 心理低
代价
要放下面子，先去问一个"级别比你低"的人。
一句话
领导批了但材料不全，经办人有权退回。所以先问经办人，再找领导，顺序反了就是白跑。
怎么做
拿到一件事，第一步不是找领导，是找到"最后经手的那个人"，问三句：要哪些材料？什么格式？有没有时限？
为什么
审批是"逐级确认"，但退回是"单点否决"。任何一个环节都能让你重来，而他们不会主动告诉你缺什么——因为告诉他们"你要什么"是他们的权力。
失效条件
事情本身需要领导先定方向，方向不明时问了也白问。
翻车
某人拿着领导批示去办，跑了三趟，每次都被退。第三次他才问："到底要什么？"对方说："第一次就该问。"
可靠度
乙
备注
这一条能省掉你 80% 的返工。
3.0.10

请示不要给问答题，要给三选一

● 必做可靠 乙代价 时间中 · 心理低
代价
要多想两个方案。
一句话
你问"怎么办"，是把难题递上去；你给三个方案，是把选择权递上去。前者让人烦，后者让人舒服。
怎么做
A 方案快但要多花钱，B 方案稳但要等，C 方案折中但要协调。明确推荐一个，并说清推荐理由。最后加一句"如无异议，我按 A 办"。
为什么
领导的核心稀缺资源是"决策精力"。开放式问题消耗他的精力，封闭式选择节省他的精力。而且"如无异议我按 A 办"，把"批准"变成了"默认"，效率高一个量级。
失效条件
涉及重大风险、重大金额、可能引发舆情的事，必须明确请示，不能用"默认"。
翻车
某人每次请示都问"领导您看怎么办"，半年后领导在会上说"有些同志，把问题往上交，自己不思考"。
可靠度
乙
备注
"如无异议我按 A 办"这句话有边界：只能用在你有把握、且后果可控的事上。
3.0.11

汇报的黄金 30 秒：结论、依据、请求

● 必做可靠 乙代价 时间少 · 心理低
代价
要改掉"从头讲起"的习惯。
一句话
领导听汇报的耐心大约是 30 秒。30 秒内没听到结论，他就开始想别的事了。
怎么做
第一句说结果（"事办成了，但多花了三万"），第二句说依据（"因为原方案的材料涨价"），第三句说请求（"需要您补签一张变更单"）。
为什么
领导的注意力是分段分配的，他同时在处理十几件事。你不给他结论，他就没法把你的话归档，只能先放着。放着就是忘了。
失效条件
专门的工作汇报会，有固定时长，可以按背景、进展、问题的顺序展开。
翻车
某人汇报从"上周我去了一趟市里"开始讲，讲到第五分钟，领导接了个电话，回来问"你刚才说到哪了"。
可靠度
乙
备注
书面材料同理。第一段就是结论，别写"现将有关情况汇报如下"。
3.0.12

"顺便"是最强的请求方式

● 必做可靠 乙代价 时间少 · 心理低 · 人情欠一个
代价
要找准时机。
一句话
专门跑一趟的事，对方要掂量成本；"顺便"的事，对方不好意思拒绝。
怎么做
"您下周去市里开会，能不能顺便帮我把这份材料带了？"——把"帮忙"降级成"顺手"，对方答应的概率高得多。
为什么
人拒绝的不是"帮忙"，是"为这件事专门付出成本"。你把成本降到接近于零，拒绝就变得不划算——因为拒绝一个举手之劳，显得自己不近人情。
失效条件
事情本身有风险、有责任，再"顺便"也没人接。
翻车
某人把一件需要签字担责的事包装成"顺便带一下"，对方当场答应，事后发现要签字，关系反而僵了。
可靠度
乙
备注
"顺便"只能用在小事上。用在大事上，是骗人，一次就废。
3.0.13

让领导"顺水推舟"，别让他"逆流而上"

● 必做可靠 乙代价 时间中 · 心理低
代价
要多做前期功课。
一句话
你想推的事，要包装成"本来就要做的事"。
怎么做
找一个已经立项、已经有预算、领导已经点过头的由头，把你的诉求挂上去。别说"我想做 X"，要说"X 是 Y 的一部分，Y 您上个月已经定了"。
为什么
领导推动一件新事，要付出协调成本、承担失败风险。推动一件"已经在做的事"，只是顺延。人性天然选择阻力小的路径。
失效条件
你的诉求和已有项目方向不一致，硬挂会显得牵强。
翻车
某人硬把一个小项目塞进一个大专项里，被审计发现"超范围实施"，两个项目一起被查。
可靠度
乙
备注
挂靠要真挂靠，不能假挂靠。前者是整合资源，后者是套取资金。

四、两条边界

3.0.14

别把"认识"当"关系"

● 必做可靠 乙代价 时间少 · 心理中
代价
要承认有些人你其实不认识。
一句话
能叫出名字、能一起吃饭、能在群里互相点赞，都不叫关系。关系的唯一检验标准是：你开口求一件"有点麻烦"的事，对方的第一反应。
怎么做
别急着测。先问自己：我为对方做过什么"他记不住但确实受益"的事？没有的话，那就不叫关系。
为什么
关系的本质是"可预期的互助"。没有互惠记录，只有社交礼仪。礼仪在关键时刻不产生行动。
失效条件
血缘、同学、战友这类"原生关系"，不需要互惠记录也成立。
翻车
某人自认为跟某科长"很熟"，真到办事时，对方说"这个我真帮不上"，然后就没有然后了。
可靠度
乙
备注
这一条不是让你变得功利，是让你别在关键时刻把希望押在错觉上。
3.0.15

押注位置，不要押注人

● 必做可靠 乙代价 时间中 · 心理低
代价
要克制"跟对人"的冲动。
一句话
人调走了，关系就断了；位置还在，关系就还在。
怎么做
维护关系时，想的是"这个岗位需要什么"，不是"这个人喜欢什么"。岗位需求是稳定的，个人喜好会随人走。
为什么
体制内人员流动是常态，三年一轮岗。你花三年经营的一段私人关系，可能因为一纸调令归零；而你对"办公室怎么运转""财务怎么审"的理解，会跟着你一辈子。
失效条件
极少数长期稳定的搭档关系，人和位置高度绑定，这时可以押人。
翻车
某人把宝全押在一位提拔在望的领导身上，结果对方调去了外地。新领导到任，他成了"上一朝的人"。
可靠度
乙
备注
这一条和"跟对人"不矛盾。跟人是策略，押位置是底线。策略可以变，底线不能丢。

本节小结

这一节讲的不是"怎么往上爬"，是"怎么把事办成"。

看懂权力结构的人，不会到处求人，也不会到处碰壁。他知道一件事卡在哪，知道该找谁，也知道哪些门根本不该敲。

最后一句话：单位里没有"万能的人"，只有"万能的路径"。 你要记的不是人名，是路径。

下一节讲关系网的另一种用法：怎么让一个跟你毫无交情的人，愿意帮你一次。

3.1领导是客户，不是家长

你对领导最大的误解，是把他当家长。

家长会为你的人生负责，领导不会。他只对你的产出负责。

把他当客户，你就不会失望：客户会挑、会换、会讲价，也会突然不合作。这些你都能接受，因为你一开始就没指望他爱你。

这一节讲怎么跟这个"客户"打交道——不卑不亢，不远不近。

3.1.1

画饼的识别：看他给不给有成本的东西

● 必做可靠 乙代价 无
代价
要承认有些"看好"只是客气。
一句话
口头许诺零成本，资源分配才有成本。
怎么做
拿三样去对——有没有给你露脸的机会（让你汇报、带你开会）？有没有给你好干的活（能出成绩、能被看见）？有没有替你挡过事？三样一样都没有，"看好"就是社交辞令。
为什么
领导的注意力是稀缺资源。他愿意把注意力分给你，说明你在他心里的优先级靠前；只给口头鼓励、从不投入成本，那是管理学上的"低成本激励"——目的是让你继续出力，不是让你上去。
失效条件
领导本人也受限制（他在等位置、等资源），给不出不是不想给。
翻车
有人被"下次一定考虑你"安慰了四年，每年都更努力一点。第五年领导调走了，交接时对新领导提都没提他。
可靠度
乙
备注
这一条能替你省下很多年。不是让你怀疑一切，是把期待建立在有成本的信号上。
3.1.2

批评不入心：对事的那半句听，对人的那半句忘

● 必做可靠 乙代价 无
代价
要当场分辨，很难。
一句话
领导骂你，七成是在处理他自己的情绪，三成才是你的事。
怎么做
把他的话拆成两半——"这个材料逻辑不清楚"是事，记下来改；"你怎么老是这么粗心"是人，别接。接了就变成自我评价。
为什么
人在压力下会扩大攻击范围，从"这件事做得不好"滑到"你这个人不行"。这不是他深思熟虑的判断，是情绪的溢出。你把这句当判决书，等于用他三秒钟的气话，给自己定了三年的罪。
失效条件
如果同一个人、在不同场合、反复指出你同一个问题，那就不是情绪，是事实，得认。
翻车
有人被一句"你根本不适合干这个"记了五年，五年后换了领导，新领导说他"是科室里最细致的"。
可靠度
乙
备注
这一条练的是"分离"的能力：把评价和事实分开，把情绪和判断分开。
3.1.3

别和领导走太近：能聊私事，就等于把把柄递过去

◎ 建议可靠 乙代价 无
代价
会失去一些"内部消息"。
一句话
距离产生安全，也产生体面。
怎么做
工作上多汇报，私事上少交底。家里的事、对同事的看法、对单位的不满，一律不进这个通道。他问起，就说"都挺好的"。
为什么
领导知道你的私事，短期是亲近，长期是筹码。而"亲近"这件事，在他调走、你调岗、或者出现利益冲突时，会瞬间变成"他知道我太多"。反过来说，你也会不自觉地被绑上他的船。
失效条件
已经形成多年、彼此高度信任的关系，不适用。但那种关系极少，且多数人误判了自己处在哪一种。
翻车
有人跟领导无话不谈，包括对某个副职的看法。领导调走后，这些话原封不动传到了那位副职耳朵里。
可靠度
乙
备注
这一条不是让你冷冰冰。是提醒你：亲近有价格，而且价格不写在明面上。
3.1.4

他说"把你当自己人"的时候，通常是要用人

可靠 乙代价 无
代价
可能会有点失落。
一句话
这句话是动员令，不是承诺书。
怎么做
听到这句话，先别激动，问一句"那我具体做点什么"。把情绪话翻译成任务，你就知道这是机会还是白干。
为什么
"自己人"在体制内是有具体含义的——意味着可以让你多担、可以让你先上、也可以让你背。它是一个关系标签，不是一份保障。真正把你当自己人的领导，不会说这句话，他会直接给你东西。
失效条件
说这话的同时给了资源、给了位置、给了机会，那就是真的。
翻车
有人听完这句话，主动接了三个没人愿意接的活。年底评优没有他，领导说"你是自己人，先让让别人"。
可靠度
乙
备注
这句话本身没有恶意。它只是被过度解读了太多次。
3.1.5

领导调走那天，你会知道你们是什么关系

● 必做可靠 乙代价 无
代价
要接受一个可能不太好受的答案。
一句话
他走的时候带不带你、走之后还联不联系，就是这段关系的真实成色。
怎么做
不用试探，也不用表白。他走的时候，你正常送、正常交接。三个月后看他有没有主动联系过你一次。没有，就到此为止。
为什么
在位时的亲近，有职务加成；离位之后的联系，才是私人情分。多数"关系很好"，其实只是"工作配合顺畅"。认清这一点不伤人，反而让你以后不会押错注。
失效条件
他调去的地方和你没有交集，客观上没必要联系，那不算。
翻车
有人为一个领导鞍前马后五年，领导调走后一次没联系过他。他后来才知道，领导在新单位用的是另一批人。
可靠度
乙
备注
这一条和 3.0 的"押位置不押人"是同一个道理，只是换了个检验方法。
3.1.6

领导发火的时候，别解释，先记

● 必做可靠 乙代价 无
代价
要压住"我不是这样"的冲动。
一句话
他发火的时候，你说什么都是顶嘴；你低头写字，两个人都能下台。
怎么做
掏本子，记他提的要求。他说的每一条都记，包括不合理的。等他停下来，复述一遍："您刚才说的三点，我记的是……您看对不对。"这时候火基本就灭了。
为什么
发火的人需要的是"被听见"，不是"被反驳"。你一解释，他会觉得你在推责，火更大。你记录，他得到了回应，攻击性自然下降。而记录这个动作，还顺便把情绪化的指责变成了可执行的要求。
失效条件
涉及处分、追责、诬陷的场合，不能只记，要当场说明并留下书面材料。
翻车
有人在会上被批评，当场逐条反驳，条条在理。领导说了一句"行，你厉害"，之后再没给过他重要的事。
可靠度
乙
备注
这不是忍气吞声。是把一场情绪对抗，转成一次工作交接。

本节小结

这一节六条，讲的是同一件事：把领导放回他该在的位置——一个你需要服务、但不必交付人生的客户。

客户会不满意，会换供应商，也会突然给你一个大单。你都可以应对，因为你从一开始就知道：这是生意，不是亲情。

下一节讲更难的一层：同事。

3.2同事不是朋友，也不是敌人

单位里跟你待在一起时间最长的人，是同事。

一天八小时，比配偶还长。但这段关系有一个奇怪的设定：你们既不能太近，也不能太远。

太近，你说的每句话都会变成日后的把柄；太远，你需要配合的时候没人接。老油条的解法不是"会来事"，是保持一个刚刚好的温度。

3.2.1

不深交、不结怨、不传话

● 必做可靠 乙代价 无
代价
可能显得"不够热情"。
一句话
这三条是同事关系的全部技术。
怎么做
不深交——不交底、不借钱、不聊家事。不结怨——有分歧只谈事，不评价人。不传话——听到什么，到你这儿为止。
为什么
同事关系是"长期重复博弈"：你要跟这批人待十年、二十年，跑不掉。在这种关系里，任何一次深交都可能变成日后的软肋，任何一次结怨都会持续复利。而传话是最快的自毁方式——你说的话一定会传回去，而且会变形。
失效条件
极少数真的投缘、且没有利益冲突的同事，可以例外。但要用三年以上的时间验证。
翻车
有人跟同事吐槽了一句"咱们科长水平不行"，半年后这话原样出现在科长耳朵里，还加了三个形容词。
可靠度
乙
备注
这一条听起来冷漠。但它保护的不只是你，也包括对方。
3.2.2

有人跟你说第三个人的坏话，标准答案是"是吗"

● 必做可靠 乙代价 无
代价
会被认为"没劲"。
一句话
接话就是入伙，入伙就要站队。
怎么做
只回三个字——"是吗""这样啊""没听说"。不追问、不评价、不补充。对方说两句就没趣了。
为什么
来跟你说别人坏话的人，一定也会去跟别人说你的坏话。他需要的是"同盟确认"，你一接话，就等于签了投名状。而这个投名状会在他下一次传话时被一起传出去。
失效条件
对方是你在核实一件必须核实的事（比如有人被举报），那要正式了解，不走这个渠道。
翻车
有人顺着同事的话说了句"我也觉得他有点过分"，一个月后这话被复述成"他说 XX 特别过分"。
可靠度
乙
备注
"是吗"这两个字，是体制内性价比最高的回应。
3.2.3

别在单位找情绪垃圾桶——你说的话都会长出腿

● 必做可靠 乙代价 无
代价
要自己消化。
一句话
单位的墙比你以为的薄，人的嘴比你以为的快。
怎么做
抱怨留给家人和朋友，单位里只说事。真要吐槽，找一个不在同单位的人，或者写在纸上撕掉。
为什么
单位是封闭系统，信息在里面循环的速度极快。你今天说的"这活没法干"，明天会变成"他对工作有情绪"；后天会变成"他可能想走"。
失效条件
无。
翻车
有人跟"最好的同事"说了句"我想考走"，三个月后全单位都知道了。领导找他谈话，第一句是"听说你不太安心"。
可靠度
乙
备注
这一条和 3.2.1 的"不深交"是同一件事的两面。
3.2.4

突然对你特别好的人，多半有事要求你

可靠 乙代价 无
代价
要忍住"终于有人喜欢我"的错觉。
一句话
关系是渐进的。突然升温，一定有原因。
怎么做
对方突然热情，先别急着回应，观察一周。如果他开口提要求，你就知道答案了；如果他没提，可能是真的投缘，也可能是在铺垫。
为什么
成年人的关系不会无缘无故地跳级。平时点头之交的人突然请你吃饭、给你带东西、主动帮你干活，多半是有一件他自己办不成、需要你配合的事。
失效条件
新人期、或者你刚帮过他一个大忙，那属于正常回礼。
翻车
有人被突然的热情感动，稀里糊涂签了一份"帮忙证明一下"的材料。后来才知道，那是个责任很大的事。
可靠度
乙
备注
不是让你疑神疑鬼。是提醒你：热度异常时，先问一句"他想要什么"。
3.2.5

编制内的人际关系，是长期重复博弈，别翻脸

● 必做可靠 乙代价 无
代价
要吞下一些气。
一句话
在企业，翻脸可以离职；在体制内，翻脸要一起待到退休。
怎么做
有分歧就事论事，别上升到人。真的被冒犯，也要留一句余地——"这个事我可能理解得不对，咱们再对一下"。
为什么
博弈论里，重复博弈的最优策略是"以牙还牙但留有余地"：对方合作你就合作，对方背叛你就反击，但对方回头你也要能接住。因为你们还要继续玩下去。一次性博弈才适合撕破脸。
失效条件
涉及原则问题（被诬陷、被侵害），该撕就撕，但要按程序撕。
翻车
有人跟同事大吵一架，从此不相往来。十年后那个人成了他的分管领导。
可靠度
乙
备注
这一条不是软弱。是算清了"以后还要见"这笔账。
3.2.6

离职之后还能联系的一个都没有，所以不必刻意维护

◎ 建议可靠 丙代价 无
代价
要接受"同事就是同事"。
一句话
你花在维护同事关系上的时间，八成会在你调走那天清零。
怎么做
维持基本礼貌和配合就够了。把经营关系的精力，留给家人、老友和自己。
为什么
同事关系的粘合剂是"共同的工作场景"，场景一消失，关系自然衰减。这不是人情冷暖，是结构决定的。真正能留下的，是那些在场景之外还有交集的人——而那种人，一两个就够。
失效条件
同一个系统内长期共事、且互相有资源依赖的人，关系会延续。
翻车
有人花大量时间经营"人脉"，调走之后发现，能打电话的只有两个。
可靠度
丙（个体差异大，有人确实交到了一辈子的朋友）
备注
这一条有点冷。但它能让你少花很多力气在无效社交上。

本节小结

这一节六条，核心是温度控制：

不冷到没人配合，不热到交出软肋。用"是吗"应付八卦，用"就事论事"处理冲突，用"不深交"保护自己。

同事是队友，不是家人。队友之间要配合，但不必交心。

下一节讲饭局——体制内最消耗时间、也最容易被高估的场合。

3.3多数饭局，吃的只是时间

体制内的饭局，有个奇怪的定价：吃的人觉得贵，请的人觉得值，被请的人觉得累。

而真相是：九成的饭局，吃完除了饱，什么都没得到。

这一节不教你"怎么在饭局上如鱼得水"，讲的是怎么判断哪些饭值得去，以及去了怎么少受罪。

3.3.1

能推的局，有几种推法，都不伤面子

● 必做可靠 乙代价 无
代价
要用对理由，用错会得罪人。
一句话
拒绝的理由要"客观"，不要"主观"。
怎么做
四句话够用——"今晚家里有事"（最通用）、"我开车来的"（有物理约束）、"最近在吃药"（有医学理由）、"明天一早要出差"（有时间冲突）。
为什么
主观理由（"我不想去"）是在评价这场饭；客观理由是在陈述一个事实。前者是拒绝人，后者是拒绝时间。对方能接受后者，接受不了前者。
失效条件
对方是主要领导、且是明确点名要你到的局，推不掉。
翻车
有人用"我不太会喝酒"推了三次，第四次领导直接说"不用你喝，人来就行"，从此再推不掉。
可靠度
乙
备注
这一条的关键是"提前说"。饭局当天下午才推，谁都知道你在找借口。
3.3.2

坐哪、说什么、什么时候走，一次讲清

● 必做可靠 乙代价 无
代价
要记一下规矩。
一句话
座位是权力图，说话是安全区，走人是技术活。
怎么做
坐
等安排，别自己挑。主位对面、门口位是最容易被叫起来服务的两个位置，尽量避开。
说
只聊天气、菜、孩子、健康。不聊人事、不聊待遇、不聊别的单位。
走
等主宾和主位的人起身，你再动。提前走要说一句"我先去把车开过来"。
为什么
饭局是一个微型的权力场，每个动作都在被解读。你不懂规矩不致命，但主动破坏规矩会被人记住。
失效条件
熟人小聚，这些都不必讲究。
翻车
有人抢了主位旁边的位置，全程被当成"不懂事"，其实他只是来得早。
可靠度
乙
备注
这一条不教你钻营。它只是让你别在无意识中冒犯人。
3.3.3

敬酒的顺序，是权力次序，不是感情深浅

可靠 乙代价 无
代价
要记住谁是主谁是次。
一句话
先敬谁后敬谁，桌上所有人都看得懂。
怎么做
按职务从高到低，同级按年龄或资历。跳过某个人去敬更远的人，是明显的失礼。
为什么
饭局的敬酒顺序，是权力结构在餐桌上的复现。你按顺序来，说明你懂规矩；你打乱顺序，说明你要么不懂，要么不认。
失效条件
非正式聚会、朋友局，随意即可。
翻车
有人先敬了分管领导，跳过了在场的正职，虽然只差一位，但被记了很久。
可靠度
乙
备注
这一条不是让你谄媚。是让你知道：这不是感情问题，是秩序问题。
3.3.4

谁组织的局最该去：能给你信息、能替你说话的人

● 必做可靠 乙代价 无
一句话
判断标准只有两条——这顿饭能让你知道什么，或者能让谁记住你。
怎么做
收到邀请先问自己两个问题：桌上有没有你想认识的人？有没有人能替你说一句话？两个都没有，就不去。
为什么
饭局的价值来自信息差和关系推进，这两样都需要"对的人在场"。一堆熟人凑在一起，说的都是已经知道的事，那只是把时间从一个地方挪到另一个地方。
失效条件
纯联络感情的部门聚餐，该去，那是团队维护。
翻车
有人一年赴了六十多场局，胃喝坏了，信息一点没多，因为他去的都是"熟人局"。
可靠度
乙
备注
这一条能替你筛掉八成无效饭局。
3.3.5

别在桌上表态——每句醉话都会被复述三遍

● 必做可靠 乙代价 无
代价
要管住嘴。
一句话
酒桌上的话，第二天会以"他当时说"开头，传遍整个单位。
怎么做
涉及人事、评价、承诺的话，一律不说。别人问起，就说"这个我真不清楚""我级别不够，不知道"。
为什么
酒精会降低表达的门槛，但不会降低传播的速度。而"醉话"这个身份，会让听的人自动放大它的真实性——因为大家默认"喝多了才说真话"。
失效条件
无。
翻车
有人在酒桌上说了句"某某这次提拔我服气，但另一个人我不服"，第二天这话传成了"他说这次提拔有猫腻"。
可靠度
乙
备注
这一条是所有饭局建议里最重要的一条。喝多了失态是小事，说错话是大事。
3.3.6

鸡肋局去了干什么：吃饭、听消息、看人

◎ 建议可靠 乙代价 无
代价
要坐满那两个小时。
一句话
推不掉的局，就当一次免费的信息采集。
怎么做
吃好、少喝、多听。观察三件事——谁跟谁坐得近、谁说话时别人在听、谁被反复敬酒。这三样比任何八卦都准。
为什么
饭局是单位里少有的"非正式信息场"。正式场合大家都在演，饭桌上人会松一点。你不需要参与，只需要观察。
失效条件
纯粹的家庭聚会、朋友聚会，别用这套，那太累了。
翻车
有人整晚在刷手机，错过了桌上唯一一次提到"要成立新科室"的信息。
可靠度
乙
备注
这一条把"白去"变成"不白去"。既然推不掉，就收点东西回来。

本节小结

这一节六条，讲的是一件事：饭局是有价格的，你要先看清价格再决定买不买。

价格包括：一晚上的时间、一场宿醉、几句说错的话。而收益，多数时候只是"在场"。

真正值得去的局不多。把省下的那些晚上，还给家人和自己。

下一节讲最后一个场合：群和朋友圈。

3.4群和朋友圈，都是半公开场合

很多人以为微信是私人的。

不是。在工作群里，你面对的是三十个同事和一条永远删不掉的记录；在朋友圈里，你面对的是领导、同事、亲戚、客户混在一起的一锅粥。

这一节讲三个字：别留痕。

3.4.1

工作群只回事实，不回情绪

● 必做可靠 乙代价 无
代价
可能显得"不够热情"。
一句话
群里的每句话都会被截图，而你控制不了截图去哪儿。
怎么做
只回具体动作和时间——"材料我十点前发您""这个我下午核实"。不回"好的""收到""辛苦了"之外的任何评价性内容。
为什么
群聊是书面记录，但它被当成口头交流在用。人在群里说话会放松，而放松的代价是留下证据。你写下的每句话，将来都可能被引用、被断章取义、被拿去做"态度问题"的证明。
失效条件
纯通知群、无关工作的生活群，不必这么紧。
翻车
有人在群里回了句"这个真没必要"，被截图转发到领导那里，成了"对工作安排有抵触情绪"。
可靠度
乙
备注
这一条和 5.2 的"群是公开法庭"是同一件事的两种说法。
3.4.2

朋友圈分三层：领导能看的、同事能看的、自己的

● 必做可靠 乙代价 无
代价
要花十分钟设置分组。
一句话
不是所有人都有资格看你的生活。
怎么做
分三组——公开组（领导、客户、不熟的人）：只发转发、工作、正能量；同事组：可以发一点生活，但不发情绪、不发言论；自己人：家人、老友，随便发。
为什么
朋友圈是"人设的公开档案"。领导刷到你在旅游，会想"他最近挺闲"；同事刷到你在抱怨，会想"他是不是有情绪"。这些判断都不公平，但它们真实发生。
失效条件
无。
翻车
有人发了一条"周末加班到凌晨，值吗"的感慨，第二天被领导叫去谈话，问他"是不是对工作有想法"。
可靠度
乙
备注
这一条不是让你虚伪。是让你把生活留给该看的人。
3.4.3

别在单位群里聊政治、聊待遇、聊领导

● 必做可靠 甲代价 无
代价
要忍住。
一句话
这三样，是体制内群聊的三个雷区。
怎么做
看到有人聊，不接话、不点赞、不转发。有人 @ 你问看法，回"我不太了解"。
为什么
政治言论有纪律风险，待遇话题会引发集体情绪（组织最忌讳），评价领导会直接得罪人。这三样只要沾一样，聊天记录就是证据。
失效条件
无。这一条没有例外。
翻车
有人在群里转发了一篇时评，配了句"说得挺对"。半年后单位做网络言行排查，这条被翻了出来。
可靠度
甲（政治纪律、网络言行规范有明文要求）
备注
这一条是全书少数"绝对"级别的建议。别试探。
3.4.4

有人截图你的话，比你说得对不对更重要

● 必做可靠 乙代价 无
代价
要养成"假设会被截图"的习惯。
一句话
你说的每句话，都要能经得起被单独截出来看。
怎么做
发之前想一遍——这句话单独截出来，会不会让人误会？会，就换个说法或者当面说。
为什么
文字脱离语境之后，语气、表情、前后文全部消失，剩下的只有字面。而字面最容易被做文章。
失效条件
无。
翻车
有人私聊同事说"这个方案我持保留意见"，被截图发给了方案作者，变成了"他反对这个方案"。
可靠度
乙
备注
这一条不是让你不敢说话。是让你说话时留一点余地。
3.4.5

投票、点赞、转发任务：分清哪些是真诚，哪些是工作

◎ 建议可靠 乙代价 无
代价
要花一点时间判断。
一句话
单位让你转发的，不是内容，是态度。
怎么做
工作要求的转发，照做，别加评论；私人的点赞，看你跟对方的关系；投票类的，投了就行，别拉票也别公开说"我投了谁"。
为什么
转发和点赞在体制内是"表态行为"。你不转发，可能被理解为不支持；你转发了还加评论，可能被理解为"有自己的想法"。最安全的做法是：动作到位，话不多说。
失效条件
纯私人社交场合，不必如此。
翻车
有人在转发单位宣传稿时加了句"其实我觉得还有改进空间"，被截图发到了工作群。
可靠度
乙
备注
这一条有点荒诞，但它是现实。

本节小结

这一节五条，其实只有一句：在体制内，没有真正的"私下"。

群、朋友圈、私聊，都是半公开场合。你写的每个字，都可能被截图、被转发、被引用。

所以最省心的活法是：话少一点，分组清一点，情绪留给自己。

卷三完。下一卷讲最容易被忽略的一笔账：情绪。

3.5汇报与请示：你不是在汇报，你是在给领导送回数据包

你以为汇报是"把干了什么告诉他"。

不是。汇报是向指挥中心发回数据包。目的不是让他知道你干了什么，是让他敢用你。

这两句话差在哪里？差在：汇报不是"交功课"，是维系信任链。领导对你的信任不来自你能力有多强，来自他能不能看见你在干什么。他看不见你，你就等于不存在。

这一节讲三件事：汇报到底在传什么，三种汇报分别怎么用，以及为什么你必须带着本子去见领导。

一、汇报到底在传什么

3.5.1

汇报不是交功课，是发数据包

● 必做可靠 乙代价 时间少 · 心理低
代价
要从"干完活就行"切换到"干完活要让人知道"，一开始会觉得别扭。
一句话
领导对你的信任，不来自你能力多强，来自他能不能看见你在干什么。
怎么做
每周给领导发一次"数据包"。不用长，三行就够——本周做了什么、下周做什么、有什么事需要他知道。
为什么
领导的信息是残缺的。他看不见你的过程，只看得见结果；看不见你的辛苦，只看得见结果出没出。数据包的作用是填补这段空白，让他知道你处在他系统里的哪个位置。航天器每隔几分钟向指挥中心报一次状态，不是为了证明自己能飞，是为了让指挥中心敢继续让它飞。
失效条件
极小团队、领导坐在你旁边，你的状态他天然可见，不需要数据包。
翻车
某人一年干了很多事，从没主动汇报过。年底评优，领导说"他今年好像没做什么"。
可靠度
乙
备注
这一条是整节的地基。把汇报当"汇报工作"，你会觉得麻烦；把它当"发数据包"，你会觉得这是刚需。
3.5.2

"机灵点"是废话，"送礼"是犯罪，剩下的只有汇报

可靠 乙代价 时间少 · 心理中
代价
要承认那些长辈建议其实都不管用。
一句话
好领导不会因为你送礼提拔你；能打动坏领导的礼物，一定也能触犯刑法。
怎么做
把"怎么跟领导拉近关系"这个问题，换成"我每天跟他接触的机会有几次"。多数人一天只有一次——汇报。抓住那一次。
为什么
父母那辈给的三条建议，全是废话："机灵点"永远正确、永远不可操作；"眼里有活"指望大力出奇迹；"送点礼"关系不到位送不出去。 剩下真正可用的，只有你正常工作的接触面。汇报是唯一一个"次数固定、内容由你定、没有法律风险"的通道。
失效条件
你从事的是纯技术、纯执行、不需要协作的岗位，接触面本身就不重要。
翻车
某人学着别人给领导送礼，领导当场退回来，还说了一句"这样不好"。两个人的关系从"普通"变成了"尴尬"。
可靠度
乙
备注
这一条不是道德说教，是成本计算。送礼的收益率最低、风险最高，汇报的收益率最高、风险最低。
3.5.3

数据包只发三个信号，别的都不用发

● 必做可靠 乙代价 时间少 · 心理中
代价
汇报前要过滤一遍该说什么。
一句话
每一次跟领导接触，都在重复同一句话：我在干活、我听你的、我是你的人。
怎么做
每次汇报前问自己一句——这段话，落在三个信号里的哪一个？三个都不占，就别说了。日常抱怨、同事八卦、对安排的牢骚，一律不带进汇报。
为什么
领导的注意力极短。你一次汇报里塞五件事，他记不住任何一件。只发三个信号，发一百次，他记住的就是这三件事。人对他人的印象不是由"信息量"决定的，是由"重复度"决定的。
失效条件
确实有需要领导决策的具体事项，那是第四个信号，必须发，而且要单独发清楚。
翻车
某人汇报时顺口提了一句"最近有点累"，领导记住了，年底谈话时说"你状态不太好啊"。他想说的其实是另外五件功劳。
可靠度
乙
备注
这三个信号听起来很功利，其实是所有组织里上下级关系的底层协议。你办砸任何一件，人设都立不住。

二、三种汇报，三种用法

3.5.4

日常汇报：一周一次，别多也别少

● 必做可靠 乙代价 时间少 · 心理低
代价
要固定花十五分钟。
一句话
日常汇报是刷存在感，频率决定信息量。
怎么做
每周挑一个领导不忙的时点，去一次。汇报内容提前写好，三句话说完就走。太频繁领导烦，太少领导忘，一周一次是多数单位的舒适区。你手上担着最重的活，可以加到每天一次。
为什么
人对另一个人的印象，是被"接触频率"冲刷出来的。一周出现一次的人，领导永远知道他在干嘛；一个月出现一次的人，领导只记得他上次来好像有事。
失效条件
领导明确表示"有事直接说，不用定期来"，那就按他的习惯，但重要节点仍要主动报告。
翻车
某人迷信"少说多做"，三个月没单独汇报。一次调整分工，领导第一个想到把他手里的活分出去。
可靠度
乙
备注
形式上的书面汇报，很多单位都有，别敷衍。领导哪天想了解你，翻的就是那些记录。
3.5.5

当面的日常汇报，有一种救命的用法

可靠 乙代价 时间中 · 心理高 · 人情欠一个
代价
要拉下脸，主动去解释。
一句话
单位里谣言四起、领导开始怀疑你的时候，日常汇报是你唯一合法的解释通道。
怎么做
找一个由头——"想跟您汇报一下 XX 的进度"——坐下来，把误会的部分当面说清楚。不说"您是不是听到了什么"，只说事实和时间线。
为什么
谣言在私域流动，解释也必须在一对一里完成。你越不解释，默认值越高。领导对一个下属起疑后，会本能地找证据印证，而不是找你本人确认。你主动去一次，他脑子里那套自洽的怀疑故事就断一环。
失效条件
事情已经捅到他面前、且有书面材料，那要走正式程序，不是聊一次能解决的。
翻车
某人被传"跟合作方走得近"，他没理会，觉得"清者自清"。半年后一次审计，领导第一个抽调的就是他的项目。
可靠度
乙
备注
这一条的关键是"合法"。当面汇报是职务行为，不涉及私下串联，说破了天也不越界。
3.5.6

多领导在场的汇报，必须彩排

● 必做可靠 乙代价 时间中 · 心理中 · 人情欠一个
代价
提前占领导十分钟。
一句话
给大领导汇报之前，先跟直属领导过一遍。你不是在麻烦他，你是在给他面子。
怎么做
正式场合之前，带着提纲找直属领导过思路。他说"就这样"，你再上去。他改了方向，你按他的改。
为什么
汇报效果差，最疼的不是你，是坐在旁边的直属领导——因为那意味着他没把关。提前沟通，传递的信息是"我在乎您的权威和体面"。而且他掌握的共识边界比你大，他一句话能省掉你三个跟头。
失效条件
直属领导本人就是你要反映的问题，那就不能彩排，按程序走。
翻车
某人在有分管领导的会上即兴发挥，提出了一个新想法，大领导很感兴趣，问了一句"这事你们科室知道吗"。他直属领导当场说不出来，会后一句话："以后这种事先跟我说。"
可靠度
乙
备注
多领导汇报里，"惊喜"永远是负资产。共识才是资产。
3.5.7

请示不是问"怎么办"，是把决策权交回去

● 必做可靠 乙代价 时间中 · 心理低
代价
要多想两个方案。
一句话
请示不是"我不会"，是"这个决定得您做"。前者暴露无能，后者厘清权责。
怎么做
书面请示永远写三件事——事由、方案（两三个，各带代价）、倾向哪个。结尾加一句"如无不当，我按第二套方案推进"。
为什么
请示在制度上的意义不是"求教"，是把决策责任正式转移到决策人身上。你写"请领导批示"，领导签了字，这件事的决策责任就有了归属。这才是请示的真正用途——不是效率，是责任划分。
失效条件
明显在你职权范围内的事还去请示，叫没担当。判断标准：这个决定做错了，会不会追到你头上。不会，就自己定。
翻车
某人遇事就问"怎么办"，被领导在会上点名："如果所有事都要我定，要你干什么？"
可靠度
乙
备注
这一条和 3.0.10 的"三选一"是同一件事的两面。那边讲话术，这边讲制度。
3.5.8

领导的问话分三种，第三种是给你机会

可靠 乙代价 时间少 · 心理中
代价
要当场判断他问的是哪一种。
一句话
领导问"这个数字对吗"不一定是怀疑你，也可能是想听你展开。
怎么做
三种问法三种接法。重复型——他没听清，再说一遍就行；质疑型——他觉得数字有问题，平心静气解释，别觉得被质问了，这是他的职责；索取型——他想知道得更多，这是给你的展示机会，把你知道的都说出来。
为什么
同样一句"这个数据怎么来的"，走神时是第一种，怀疑时是第二种，做判断前是第三种。你把它当第二种应对，会显得防御；当第一种，会显得敷衍。
失效条件
领导已经拿到书面材料、且是正式质询场合，那就是出了问题，按程序说明，不在这个分类里。
翻车
某人把领导的"索取型"提问当成了质疑，紧张地辩解半天。领导后来跟人说"他就这点肚量"。
可靠度
乙
备注
共同点是实事求是。不会就说不会，别硬编。编一次，前面积累的信任清零。

三、为什么你必须带着本子去见领导

3.5.9

准备出效率，记录出尊重

● 必做可靠 乙代价 时间少 · 心理低
代价
随身多带一个本子。
一句话
领导允许大臣上朝带笏板，你凭什么空着手去汇报？
怎么做
去之前列好要点；他说的时候记；他发火的时候，低头记他提的要求。三件事都用同一个本子完成。
为什么
从汉到明，大臣上朝都要捧一块笏板，写的就是自己的汇报要点。皇帝都允许打小抄，你以为"全记在脑子里"是本事，其实只是没准备。记录还有第二个功能：领导发火时，你低头写字，是双方都能下的台阶。
失效条件
只有一两句话的即兴汇报，掏本子反而显得做作。
翻车
某人凭记忆汇报，中途被问到一个数字答不上，回去翻了半小时，再回来领导已经散了。
可靠度
乙
备注
本子不是给领导看的，是给你自己的。但它会让领导觉得你"郑重其事"。
3.5.10

会干不会说，等于没干

可靠 乙代价 时间少 · 心理中
代价
要承认"干得好"和"被看见"是两件事。
一句话
诸葛亮能留名，靠的不是鞠躬尽瘁，是《出师表》。
怎么做
一件重要的事做完，问自己一句："这件事，有几个人知道？"只你自己知道，就等于没做。至少要让三个人知道：领导、相关科室、能替你说一句的人。
为什么
组织只承认"被记录的成绩"。不是组织阴暗，是人的记忆不可靠——年底评优时，领导能调取的只是他印象里的东西。你的活儿没有进入他的印象，就是白干。三国那么多忠臣，只有诸葛亮写得出"临表涕零，不知所言"，所以只有他千古。
失效条件
保密性质、敏感岗位的工作，知道的人越少越好，这时"被看见"是负资产。
翻车
某人两年做了三个没人愿意碰的专项，全部"已经处理好了"。换领导时，交接材料里一项都没有。
可靠度
乙
备注
这句话肯定会得罪人，因为它把"踏实肯干"从唯一标准降级成了必要条件。但你想想：单位里干得最多的，往往不是提拔最快的。
3.5.11

第三条：思想汇报，用求助语态

可靠 乙代价 时间中 · 心理高 · 人情欠一个
代价
要暴露一部分真实困惑。
一句话
领导工资里包含一项，叫"掌握下属思想动态"——这是制度给你的通道，别浪费。
怎么做
心里有疙瘩影响工作，找一个非正式的场合，用"想请教您一下"开头，把困扰说给他听。姿态是学生，不是谈判对手。别哭诉，别抱怨，就事论事。
为什么
年长的人在分享经验时会有快感，你用了这个快感，就能低成本建立"思想上亲近"的关系。而且是制度允许的——掌握下属思想动态，写在各级党组织的职责里。这是唯一一条明写在制度里的"私下沟通"通道。
失效条件
领导本人作风粗暴、传话极快，那这条通道就变成了公开处刑，别用。
翻车
某人把跟领导的私聊当成情绪垃圾桶，说了很多对同事的不满。三个月后，全单位都知道了。
可靠度
乙
备注
这一条风险不低。判断标准：他以前有没有替你保过密。没有，别说。
3.5.12

非正式渠道说的话，比正式汇报更管用

▲ 慎用可靠 丙代价 时间中 · 心理中 · 人情欠一个
代价
分寸难拿，用错会显得轻浮。
一句话
有些话只能在走廊上说，不能写在报告里。
怎么做
需要预警的风险、不好落纸的苗头、涉及具体人的隐忧，用"顺便提一句"的方式当面说。说完不加书面材料。
为什么
正式渠道的信息会被归档、被引用、被翻出来。预警类的话一旦落了纸，事情没发生，你就是"造谣"；事情发生了，你就是"早有预谋"。口头说，是尽到了告知义务，又没有留下可以被反向解释的文句。
失效条件
涉及安全、违法、重大风险，必须书面报告——这是《中国共产党纪律处分条例》和安全生产责任的硬性要求，不能图省事。
翻车
某人担心合作方不靠谱，写了份书面提醒。项目没事，领导反而问他"你对这个单位是不是有看法"。
可靠度
丙（依赖领导风格，且边界敏感）
备注
这一条全书风险最高的几条之一。红线只有一条：安全、违法、重大风险，一律书面。 其余才谈得上"口头预警"。

本节小结

这一节的核心只有一句话：领导对你的评价，不是你做了什么，是他看见你做了什么。

汇报不是讨好，是让系统里有你的位置。三个信号、三种汇报、一个本子，都是为了让"看见"这件事稳定发生。

最后一句话：汇报的质量，取决于你准备的质量；关系的质量，取决于汇报的质量。

下一节讲怎么把活干得又快又看不见辛苦——干活的节奏，比干活的量更决定别人怎么看你。

3.6求人办事：怎么开口，怎么还

体制内最难的一课，不是拒绝，是开口。

很多人宁可自己扛三个月，也不愿意跟人说一句"能不能帮我一下"。而真正会办事的人，恰恰相反——他们开口很自然，还人情也很自然。

这一节讲这门手艺。

3.6.1

求人之前，先问自己三个问题

● 必做可靠 乙代价 无
代价
要诚实面对自己。
一句话
不是所有事都值得求人，也不是所有事都求得动。
怎么做
三问——这件事他办得到吗？（能力）他为什么要帮我？（理由）我拿什么还？（成本）
为什么
求人被拒，多数不是对方不近人情，是这三个问题里有一个没答案。你带着一个"三问都有答案"的请求去，成功率会高很多。
失效条件
极亲近的关系（家人、老友），不必这么算计。
翻车
有人找一个不太熟的科长办事，对方客气地说"我问问"，然后就没有然后了。他后来才知道，那件事超出对方的权限。
可靠度
乙
备注
这一条是全节的地基：求人不是开口，是设计。
3.6.2

开口的时机：找他心情好、且不忙的时候

◎ 建议可靠 乙代价 无
代价
要等。
一句话
同一件事，在错误的时间说，成功率差一半。
怎么做
观察三个信号——他最近有没有刚办成事、有没有刚被表扬、手头是不是没有急活。三个都有，就是好时机。
为什么
人做决定时，情绪状态和认知负荷会显著影响结果。他心情好、脑子空的时候，更容易答应；他焦头烂额的时候，任何额外请求都是负担。
失效条件
事情很急，等不了，那就直接说，但要说清"我知道您忙"。
翻车
有人在领导刚被上级批评完的当天去提请求，被一句"你先把手上的事做好"打发了。
可靠度
乙
备注
这一条不用刻意打听，看他走路的速度和说话的语气就知道。
3.6.3

开口的话术：把请求切成三步

● 必做可靠 乙代价 无
代价
要练。
一句话
先给背景，再给请求，最后给退路。
怎么做

1. 背景："X 局，有个事想跟您请教一下……"（不是"求您"，是"请教"）

2. 请求："这个材料卡在 Y 那里，您看能不能帮着说一句？"（具体、可执行）

3. 退路："要是不方便就算了，我再想别的办法。"（给他拒绝的空间）

为什么
三步的结构，让对方知道"这是什么、要我做什么、不做也没关系"。而"不做也没关系"这句话，反而会让答应率上升——因为它消除了压力。
失效条件
对方是你很熟的人，太客气反而生分。
翻车
有人一开口就是"您一定得帮我"，对方当场答应，事后拖着不办——因为被架住了。
可靠度
乙
备注
这一条的核心是"给对方留退路"。留了退路，他才敢答应。
3.6.4

被拒绝了，怎么收场

● 必做可靠 乙代价 无
代价
要忍住失落。
一句话
被拒不是关系的终点，是关系的测试。
怎么做
一句话收场——"理解，我再想想办法，麻烦您了。"不追问原因，不表现出情绪，不当场找替代方案。
为什么
对方拒绝，通常有他的难处（权限、风险、关系）。你追问，等于逼他解释，关系就僵了。而你干脆地收场，他会记住你的分寸，下次可能主动帮你。
失效条件
无。
翻车
有人被拒后说"那算了吧"，语气很冲。对方后来跟别人说"这个人不懂事"。
可靠度
乙
备注
这一条决定的是"下次还帮不帮你"，比这一次的结果更重要。
3.6.5

还人情：三种方式，按关系深浅选

● 必做可靠 乙代价 无
代价
要记着。
一句话
人情不是"还清"，是"接着"。
怎么做
浅关系
还礼（价值相当，别超）、请一顿饭。
中关系
帮他办一件事（哪怕小）、在他需要的时候出现。
深关系
不用还，但要让他知道"我记着"。长期互惠，不算细账。
为什么
人情的本质是"关系的持续"，不是"债务的清偿"。你还得太清，等于告诉对方"我们两清了"，关系反而断了。
失效条件
无。
翻车
有人收了别人的帮忙，立刻送了一份大礼，对方觉得"被划清界限了"。
可靠度
乙
备注
这一条有点反直觉：还人情要留一点尾巴。
3.6.6

别求超出关系的事

● 必做可靠 乙代价 无
代价
要克制。
一句话
关系的额度是有限的，一次用超，就归零。
怎么做
判断标准——这件事如果被拒绝，你会不会觉得"这人不行"？会，说明你求超了。
为什么
每段关系都有一个"可承受的请求上限"，超过这个上限，对方会觉得你不懂事，甚至觉得你在利用他。而这个上限，往往比你以为的低。
失效条件
救命、急难，可以破例，但要用一次，且要记一辈子。
翻车
有人跟一个普通同事借了五万块，对方借了，但从此再没来往。
可靠度
乙
备注
这一条是求人办事的边界：关系是存款，不是信用卡。

本节小结

这一节六条，讲的是一门手艺：怎么把"求人"这件事，做得体面、有效、不伤关系。

三问定方向，时机定成败，话术定感受，收场定下次，还法定长久，边界定生死。

会求人的人，不是脸皮厚，是分寸准。

3.7老同志、边缘人与编外人员

单位里有一批人，职位不高、不显眼、也不在核心圈。

但他们往往比领导更不能得罪，也往往比你以为的更有用。

这一节讲这三种人。

3.7.1

老同志的权力不在职位，在"单位史"

● 必做可靠 乙代价 无
代价
要花时间听他们讲过去。
一句话
他知道这个单位以前发生过什么，而你不知道。
怎么做
见面打招呼，逢年过节问一句好。他讲往事的时候，认真听——那些"当年某某怎么怎么样"里，藏着这个单位的潜规则。
为什么
老同志的价值在于"历史信息"。哪个人是怎么上来的、哪个部门为什么不能碰、哪件事当年闹到什么程度——这些不进文件，只在人嘴里。

单位成立不久、人员流动大的，老同志的价值会打折。
翻车
有人对老同志爱答不理，后来才知道，那位老同志是现任一把手的师父。
可靠度
乙
备注
这一条的成本极低，收益很高。
3.7.2

别得罪三类没职位的人：司机、门卫、食堂

代价
要客气。

他们不决定你能上去，但能决定你上不去。

这三类人掌握着单位的"毛细血管"——谁能进哪个门、谁的车停哪、谁什么时候在单位。他们的评价不写进考核，但会以"某某这个人"的形式，传到该听的人耳朵里。
失效条件
无。
翻车
有人对门卫态度差，后来一次上级暗访，门卫没给他开门，也没提醒他。

乙
备注

3.7.3

编外人员知道的比你多，并且愿意说

◎ 建议可靠 丙代价 无
代价
要放下身份感。

他们不在编制里，所以说话没那么多顾忌。
怎么做

编外人员（临聘、劳务派遣、公益岗）处在"信息流通的中间层"——他们听到的多，约束少，而且往往愿意跟态度好的人说。

涉及人事、敏感事项，他们知道的也有限，别指望。

3.7.4

那个"不合群"的人，往往是信息洼地

◎ 建议可靠 丙代价 无
代价
要主动接触。

所有人都愿意跟他吐槽，因为他不会传出去。

3.7.5

空降领导带的人，和你不是一条起跑线

这一节六条，讲的是单位里的"非权力影响力"。

老同志有历史，编外人员有信息，边缘人有耳朵，空降的人有靠山。

下一节换到情绪：嫉妒与比较。

卷四

情绪账

别让单位给你打分

最贵的剥削不是加班，是让你用情绪给它打工。这一卷讲怎么不被评价、不被比较、不被「前途」两个字吊着。

4.1别让单位给你打分

单位有一套完整的评价体系：考核、评优、民主测评、领导印象。

这套体系看起来很客观，实际上它是用一套标准，把一群不一样的人排成队。

问题不在体系本身，在于很多人把这套分数，当成了自己人生的分数。

这一节讲怎么把它放回原位。

4.1.1

领导的评价不是你的价值，只是他的用人偏好

● 必做可靠 乙代价 无
代价
要接受"他不喜欢我"这件事。
一句话
他说你行，说明你好用；他说你不行，说明你不好用。这两种都不是在评价你这个人。
怎么做
听到评价，翻译成"他需要什么"——他说你"不够主动"，可能是要你多汇报；他说你"太有个性"，可能是要你少说话。
为什么
领导看人，看的是"这个人能不能用、好不好用、会不会出事"。这是一套功能评价，不是人格评价。你把它当人格评价，就会为了一个"好用"的标签，改掉自己所有不必要改的东西。
失效条件
同一个人、多年、多场合给出同样的评价，那可能是真的，值得听。
翻车
有人因为领导一句"你这个人太内向，不适合干这行"，硬逼着自己变成了一个爱社交的人。五年后他说："我变得不像我了，位置也没上去。"
可靠度
乙
备注
这一条不是让你不听意见。是让你分清"意见"和"判决"。
4.1.2

评优、先进、称号：多数是平衡工具

可靠 乙代价 无
代价
会有点失落。
一句话
名额是有限的，分配是要平衡的，你干得好只是其中一个变量。
怎么做
该争的争，但别把它当成"我值不值"的证明。评上了，说明今年轮到你；没评上，说明今年需要给别人。
为什么
评优的本质是资源分配，要平衡部门、年龄、资历、关系。一个人在评优上的表现，跟他的实际贡献相关性远低于想象。理解这一点，你就不会为了一个称号耗掉半年情绪。
失效条件
连续多年评优，在提拔时确实有加分，该重视还得重视。
翻车
有人连续三年没评上，从此一蹶不振，觉得"我这辈子就这样了"。第四年评上了，他发现除了多发两千块，什么都没变。
可靠度
乙
备注

4.1.3

被当众表扬，先想三秒他要你干什么

4.1.4

被批评不一定是你的错——有时只是需要有人被批评

乙

4.1.5

"年轻人多担待"是最好用的借口，别接得太顺

● 必做可靠 乙代价 无

确实是学习机会、且有人带，那值得担待。

可靠度
乙
备注

4.1.6

单位对你的评价是有期限的，你的人生没有

● 必做可靠 乙代价 无
代价
要重新定义"成功"。
一句话
今年的考核结果，明年就没人记得；你今年错过的东西，可能永远补不回来。
怎么做
每年年底做一次"两栏清单"——左边写单位给了你什么，右边写你为它放弃了什么。看完自己判断值不值。

单位的评价体系是按年结算的，它只对"这一年"负责。而你的人生是连续的，错过孩子三岁那一年，不会因为你考核优秀而补回来。
失效条件
如果你正处在关键上升期，短期牺牲是投资，不算亏损。
翻车

可靠度
乙
备注
这一条是整卷的起点：先把评价体系放回它该在的位置。

本节小结

这一节六条，讲的是同一件事：单位给你打的分，只在这个单位、这一年、这套标准下有效。

出了这个门，它一文不值。

别用一个临时评分，去定义一件长期的事。

下一节讲更难的：不站队。

4.2不站队，也不当枪

单位里最危险的两件事：站错队，和被当枪使。

而它们的共同点是——你往往是最后一个知道自己已经被卷进去的人。

这一节讲怎么在派系之间活下来，用的是最笨也最有效的办法：不押注，不参与，但也不得罪。

4.2.1

不押注人，押注位置

● 必做可靠 乙代价 无
代价
要放弃"跟对人一步登天"的幻想。
一句话
人走茶凉，位置还在。
怎么做
维护关系时想"这个岗位需要什么"，不是"这个人喜欢什么"。岗位需求是稳定的，个人喜好会随人走。
为什么
体制内人员流动是常态，三年一轮岗。你花三年经营的一段私人关系，可能因为一纸调令归零；而你对"办公室怎么运转""财务怎么审"的理解，会跟你一辈子。
失效条件
极少数长期稳定、人与位置高度绑定的搭档关系，可以押人。
翻车
有人把宝全押在一位提拔在望的领导身上。对方调去了外地，新领导到任，他成了"上一朝的人"。
可靠度
乙
备注
这一条和"跟对人"不矛盾。跟人是策略，押位置是底线。
4.2.2

谁的人都不要当，谁都清楚自己人不够用

● 必做可靠 乙代价 无
代价
会失去一些"内部照顾"。
一句话
你不属于任何人，才不会被任何人牺牲。
怎么做
对每位领导都保持同样的距离和配合度。不单独表忠心，不传谁的私话，不参加谁的私下聚会。
为什么
派系需要的是"可用的人"，不是"忠诚的人"。当派系需要牺牲一个人来换取平衡时，被牺牲的一定是最边缘的那个"自己人"。
失效条件
你已经处在必须选边的位置（比如两个副职明争，你在中间），那就得选，但要选得更早、更隐蔽。
翻车
有人被一位领导视为心腹，那位领导出事后，他第一个被调离。
可靠度
乙
备注
这一条不是清高。是算清了"当自己人"的收益和风险。
4.2.3

冷眼观是一种能力：看清但不参与

● 必做可靠 乙代价 无
代价
会被人说"滑"。
一句话
看戏的人不下场，下场的人不看戏。
怎么做
听得懂、看得清，但不表态、不评价、不传播。有人问你"你觉得呢"，回"我不太了解情况"。
为什么
在派系斗争里，信息是最有价值的资产，而表态是最昂贵的成本。你只要不表态，就始终是"可以被争取的人"；一表态，就变成"必须被清理的人"。
失效条件
涉及原则、违法、侵害的事，不能只当看客，要走程序。
翻车
有人在两派之间传话，以为自己是"中间人"，最后两边都认为他是对方的人。
可靠度
乙
备注
这一条的关键是"不说"。多数人栽在嘴上。
4.2.4

有人试探你立场，装听不懂是标准答案

可靠 乙代价 无
代价
要装傻，心里不舒服。
一句话
试探你的人，要的不是你的答案，是你的把柄。
怎么做
三句话轮换——"这个我真不清楚""我级别不够，接触不到""您比我了解得多"。
为什么
试探是筛选。对方在找"可以拉的人"和"需要防的人"。你一回答，无论站哪边，都完成了分类。不回答，你就还留在"待定"里，而待定是最安全的位置。
失效条件
对方是你的直属领导、且明确要求你表态，那就得给一个模糊但不伤人的答案。
翻车
有人在饭桌上被问"你觉得 X 和 Y 谁更适合"，他认真分析了一通。三个月后这段话被完整复述给了 Y。
可靠度
乙
备注
这一条和 3.3.5 是同一件事：饭桌上不表态。
4.2.5

别当枪：冲锋的人功劳最少，挨的骂最多

● 必做可靠 乙代价 无
代价
会错过一些"表现机会"。

有人让你去"反映情况"，多半是他自己不想去。

枪的价值在于"可以牺牲"。真出了事，扣扳机的人不会承认，子弹也不会被记住。而你在单位的名声，会因为这一次冲锋被永久标记为"刺头"。
失效条件
这件事本身就是你的职责（比如你是纪检、是工会），那必须做，但要按程序做。
翻车
有人被同事鼓动着去跟领导提待遇问题，提完之后同事都躲了，他一个人被叫去谈话。
可靠度
乙
备注
这一条不是让你当缩头乌龟。是提醒你：别人推你上前的时候，先看他站在哪。
4.2.6

中立者的生存空间，比你以为的大

◎ 建议可靠 乙代价 无
代价
要忍受"没立场"的评价。

组织需要能干活的人，不需要每个人都站队。

为什么
派系斗争的结果往往是两败俱伤，最后上位的是那个"谁都能接受"的人。而"谁都能接受"，前提就是你从来没得罪过谁。
失效条件
单位小、派系强、斗争激烈到"不站队就出局"，那中立确实没有空间。
翻车

可靠度
乙
备注

本节小结

这一节六条，讲的是一个姿态：站在场边，但不离开场地。

不押注人，不当枪，不表态，但活照干、人照应。这样你在任何一次洗牌里，都不是第一个被清掉的。

在体制内，活得久比站得高更重要。

下一节讲最难的一关：接受平凡。

4.3接受平凡，但不接受消耗

体制内最大的心理危机，不是穷，是"我这辈子是不是就这样了"。

这个问题会在某个下午突然砸下来：同学升了、同事调走了、比自己晚来的人成了领导。

这一节不讲"如何重燃斗志"，讲的是怎么跟这个念头和解，同时不让自己废掉。

4.3.1

天花板这事，越早接受越早解脱

● 必做可靠 乙代价 无
代价
要放弃一种可能性。
一句话
你的天花板不由你努力决定，由你的起点、年龄、专业和运气共同决定。
怎么做
算一次账——你所在的层级，理论上最高能到哪；你现在的年龄，还剩几个窗口；你的专业，是不是"进得来但上不去"的那种。算完，你就知道自己大概在哪个位置。
为什么
不接受天花板的人，会把全部精力投在一个可能根本不存在的位置上，然后年年失望。而接受它的人，可以把同样的精力分一部分给生活，反而过得更好。
失效条件
三十五岁前、且在核心岗位、且有人明确提携，那还有空间，别过早放弃。
翻车
有人四十岁才想明白自己上不去，回头一看，前面十五年全在为一个不存在的目标焦虑，家庭和生活全是空白。
可靠度
乙
备注
接受天花板不是躺平。是把手里的牌看清楚，再决定怎么打。
4.3.2

见过太多"当年最能干的"，现在都在等退休

● 必做可靠 乙代价 无
一句话
单位里最拼的那个人，往往不是最后上去的那个。
怎么做
找一个比你大十岁、当年很能干的同事，观察他现在过得怎么样。这个样本比任何道理都有说服力。
为什么
体制内的上升，是资源、关系、时机、平衡的综合结果，能力只是入场券。那些把所有筹码押在"我能干"上的人，多数在四十岁后进入平台期，然后开始漫长的下坡。
失效条件
专业性强、以技术立身的单位（医院、高校、科研院所），能干确实能走得更远。
翻车
有人年轻时是"单位第一支笔"，四十岁后写不动了，位置也没上去，成了科室里最沉默的人。
可靠度
乙
备注
这一条不是让你不努力。是让你别把"努力"当成唯一的变量。
4.3.3

平庸的自由：不被指望，也就不被消耗

可靠 乙代价 无
代价
会失去一些机会。
一句话
你越是被当成"顶梁柱"，越没有自己的生活。
怎么做
保持"可靠但不突出"的位置——活交得出去，但不当那个"非他不可"的人。这个位置最舒服，也最安全。
为什么
组织对"能人"的使用是不计成本的。你越能干，压给你的越多；你越不可替代，越走不开。而"平庸"的人，反而拥有完整的周末和下班时间。
失效条件
你确实想往上走，那这条不适用——代价和收益是你自己选的。
翻车
有人是科室里唯一会做某项业务的人，十年没休过一个完整的年假，因为"离了他不行"。
可靠度
丙（这是一种价值选择，不是普适规律）
备注
这一条容易被误读成"教人躺平"。它真正说的是：别让自己成为那个走不开的人。
4.3.4

跟别人比工资，是所有内耗的起点

● 必做可靠 乙代价 无
代价
要忍住打听的冲动。
一句话
体制内的工资差，多数时候跟能力无关，跟单位、编制、入职时间有关。
怎么做
不比横向，只比自己——今年比去年多了什么？技能、时间、健康、关系，哪一项在增值？
为什么
同城不同单位、同单位不同编制、同编制不同入职年份，收入能差一倍。这个差距不是你努力能填的，比了只会让自己难受。
失效条件
同一个单位、同一个岗位、同一年入职，那比一比是合理的，能发现问题。
翻车
有人发现自己比同事少两千，追问了半年，最后发现是因为入职时间差了一年，政策变了。这半年他什么都没干成。
可靠度
乙
备注
这一条不是让你认命。是让你把注意力放回"能改变的部分"。
4.3.5

把"我要上去"换成"我要过好"，是体制内最重要的一次换轨

● 必做可靠 乙代价 无
代价
要承认自己不是主角。
一句话
目标从"位置"换成"生活"，你会发现很多焦虑自动消失。
怎么做
把年度目标从"今年能不能提"改成"今年我想做成哪三件事"——学一样东西、去一个地方、陪家人多少天。这三件事你自己就能控制。
为什么
以"位置"为目标，成败由别人决定，你会长期处在无力感里；以"生活"为目标，成败由自己决定，掌控感会回来。而掌控感，是心理健康最核心的变量之一。
失效条件
正在关键窗口期（有明确机会、有人推），那还是要争，争完再换轨。
翻车
有人四十岁才换轨，之前二十年一直在等一个位置，等到最后发现，等的过程本身把生活耗光了。
可靠度
乙
备注
这一条是整卷的核心：不是放弃，是换一个记分牌。
4.3.6

长期主义：二十年后你还在，他们都走了

◎ 建议可靠 乙代价 无
代价
要熬。
一句话
体制内是一场超长跑，跑赢的人往往不是跑得快的，是没退赛的。
怎么做
把身体、家庭、心态当成三条腿的凳子，哪条腿断了都站不住。每年检查一次这三条腿。
为什么
单位里的人员流动比想象中快——调走、下海、出事、退休。二十年后你回头看，当年那些风头最劲的人，多数已经不在了。而你还在，还在就意味着有机会。
失效条件
单位整体在收缩、撤并，那"还在"的意义会打折。
翻车
有人为了短期竞争透支身体，四十岁病退，前面所有的积累清零。
可靠度
乙
备注
这一条不是鸡汤。它是一句大实话：体制内最大的优势就是时间，别把它浪费在急上。

本节小结

这一节六条，讲的是一个转身：从"我要赢"转到"我要过好"。

不是认输，是换了一个更长的赛道。在这个赛道上，比的是谁活得久、谁身体好、谁家里安稳、谁到六十岁还能笑得出来。

这些，单位不给你打分，但生活给你打。

下一节讲最后一件事：怎么处理每天的情绪垃圾。

4.4情绪卫生

前面三节讲的是"大事"：评价、站队、天花板。

这一节讲"小事"：那些每天发生、看起来不值一提、但会慢慢把人磨坏的东西。

心理学上有个说法：压垮人的不是重大事件，是日常摩擦的累积。 这一节就是清扫这些摩擦。

4.4.1

下班进门前那三分钟，决定你家今晚的气氛

● 必做可靠 乙代价 无
代价
要停一下。
一句话
你在门口的三分钟，值一晚上的安宁。
怎么做
到楼下先不急着上楼，在车里、在楼下、在楼道里坐三分钟。什么都不想，或者深呼吸十次。然后上楼。
为什么
人的情绪有惯性，从单位到家里需要一个缓冲。没有这个缓冲，单位那口气会直接喷在开门第一句话上。而家人接住的，往往不是你，是你白天攒下的东西。
失效条件
无。
翻车
有人每天进门第一句话是抱怨，孩子后来一听到钥匙声就躲进房间。
可靠度
乙
备注
这一条和 2.4.4 是同一件事：一个讲道理，一个讲操作。
4.4.2

生气的当天，不要发任何消息

● 必做可靠 乙代价 无
代价
要忍一晚。
一句话
气头上写的东西，第二天你会想删，但删不掉。
怎么做
想发的消息先写在备忘录里，不加发送。第二天早上再看一遍，八成会删掉，或者改得温和很多。
为什么
愤怒状态下，人的表达会极端化、绝对化，而文字会把这个瞬间永久固定。你在气头上写的一句"这活我不干了"，可能会被当成"这个人有情绪问题"的证据。
失效条件
涉及安全、违法、侵害，必须当场报告，不能等。
翻车
有人在群里被指责，当晚发了一大段辩解，第二天发现那句话被截图转了三个人。
可靠度
乙
备注
这一条能救你很多次。真的很多次。
4.4.3

别在深夜做任何职业决定

● 必做可靠 乙代价 无
代价
要熬到第二天。
一句话
夜里想的事，天亮再看，多半是另一回事。
怎么做
想辞职、想找领导摊牌、想举报，全部留到第二天上午十点以后再决定。
为什么
夜间的情绪调节能力下降，负面信息会被放大，这叫"情绪昼夜节律"。很多冲动决定都是在这个时段做的，第二天就后悔。
失效条件
无。
翻车
有人在凌晨两点写了一份辞职信，早上发出去，中午就后悔了。但话已经说出口，回不去了。
可靠度
乙
备注
这一条特别适合那种"半夜越想越气"的人。
4.4.4

有些气当时要出，出完就忘；有些气永远别出

可靠 乙代价 无
代价
要当场判断。
一句话
能当场解决的气，出；解决不了的气，咽。
怎么做
判断标准是"这件事明天还会不会影响我"。会，就当场说清楚；不会，就当没发生。
为什么
情绪需要出口，但出口要选对。当场能解决的事，憋着会变成心结；当场解决不了的事，发作只会留下把柄。分清这两类，能省掉一半的麻烦。
失效条件
涉及尊严、原则、被侵害，不能"当没发生"。
翻车
有人对一件第二天就没人记得的小事当场发火，被记了三年"脾气不好"。
可靠度
乙
备注
这一条难在判断。多数人的问题是：小事上发火，大事上忍着——正好反了。
4.4.5

找朋友、找家人、找运动，别找同事

● 必做可靠 乙代价 无
代价
要建立单位之外的生活。
一句话
同事可以共事，不能共情。
怎么做
给自己准备三个出口——一个能说话的朋友（不在同单位）、一个能出汗的运动、一个能投入的爱好。三样有一两样，就够撑住。
为什么
跟同事倾诉，等于把软肋交给一个可能跟你竞争的人。而单位之外的出口，不会把你的话变成把柄。
失效条件
极少数已经验证过、且无利益冲突的同事，可以例外。
翻车
有人把同事当树洞，说了三年心里话。后来一次竞争上岗，那些话全成了"他心态不稳定"的证据。
可靠度
乙
备注
这一条是整卷的兜底：你必须有一个单位之外的世界。
4.4.6

单位里的委屈，八成放一周就不算委屈了

◎ 建议可靠 乙代价 无
代价
要等。
一句话
时间是最便宜的情绪处理器。
怎么做
遇到委屈，先标记一下日期，一周后再看。如果那时候还难受，再处理；如果已经淡了，就说明它不值得你花力气。
为什么
人对负面事件的记忆强度会随时间快速衰减。一周后还在意的，才是真问题；一周后就忘了的，只是当时的情绪。
失效条件
涉及原则、名誉、实际损失的事，不能等。
翻车
有人为一次会上被批评的事难受了半年，半年后他想不起当时被批评的是什么。
可靠度
乙
备注
这一条不是让你忍。是让你把力气花在"一周后还在意的事"上。

本节小结

这一节六条，都是很小的事：门口三分钟、不当场发消息、不半夜做决定、找对出口。

但正是这些小事，决定了你是在单位里"上班"，还是在单位里"耗着"。

情绪卫生的核心不是控制情绪，是别让情绪有机会发酵。

卷四完。下一卷讲底线：怎么不翻车。

4.5嫉妒与比较

单位是一个天然的"比较场"。

同一个办公室、同一批入职、同一套考核，谁上谁下，一目了然。这种透明度，让嫉妒变得不可避免。

这一节不讲"要豁达"，讲怎么处理这种情绪，以及被别人嫉妒时怎么办。

4.5.1

嫉妒不是道德问题，是信息问题

● 必做可靠 乙代价 无
代价
要承认自己也会嫉妒。
一句话
你嫉妒的往往不是那个人，是你想象中他的生活。
怎么做
嫉妒上来的时候，问自己一句——"我具体嫉妒他什么？"多数时候答不出来，或者答出来的是"他好像很轻松"这种想象。
为什么
嫉妒的燃料是"信息不对称"。你只看见他升了，看不见他付出了什么、失去了什么、背后有什么关系。你嫉妒的是一个剪辑过的版本。
失效条件
无。
翻车
有人嫉妒同事提拔，郁闷了两年。后来才知道，那位同事为了这个位置，付出了他绝对不愿意付的代价。
可靠度
乙
备注
这一条不是让你自我安慰。是让你把"情绪"换成"信息"。
4.5.2

被嫉妒的时候，最好的做法是"不解释"

● 必做可靠 乙代价 无
代价
要背一点闲话。
一句话
你越解释，越像在炫耀。
怎么做
不主动提自己的成绩，不在被嫉妒的人面前谈"机会""资源""领导看重"。该干什么干什么，低调三个月，风头自然过去。
为什么
嫉妒者要的不是真相，是"你也没那么厉害"的确认。你一解释，等于反复提醒他"我确实上去了"，只会加重。
失效条件
涉及名誉的造谣（说你靠关系、靠送礼），那要澄清，但要通过正式渠道。
翻车
有人升职后到处说"其实我也不想去，太累了"，被解读为"得了便宜还卖乖"。
可靠度
乙
备注
这一条的关键是"闭嘴"。多数麻烦都是解释出来的。
4.5.3

别在同事面前谈"我最近在忙什么大项目"

◎ 建议可靠 乙代价 无
代价
要忍住分享欲。
一句话
你说的每一句"我在做什么重要的事"，都会变成别人的压力。
怎么做
工作进展只说必要的部分，不主动渲染重要性。尤其是"领导很重视""这个要报省里"这类话，一个字都别多说。
为什么
单位里的资源是零和的——你被重视，就意味着别人被冷落。你越强调自己的重要性，越容易成为靶子。
失效条件
团队协作需要同步信息时，该说还得说。
翻车
有人在办公室说"这个项目是局长亲自抓的"，三个月后项目出问题，全科室都在看他的笑话。
可靠度
乙
备注
这一条和 1.2.5"看起来很忙"不矛盾：看起来忙，但不说得重要。
4.5.4

比较是偷走快乐的贼，但你可以选择比什么

● 必做可靠 乙代价 无
代价
要换一个记分牌。
一句话
跟人比工资、比位置，永远有人比你强；比睡眠、比体检报告、比孩子跟你亲不亲，你会赢很多。
怎么做
给自己定三个"不比"和三个"要比"——不比职位、不比收入、不比谁更被领导看重；比睡眠质量、比体检指标、比陪家人的时间。
为什么
比较本身没错，错的是比错了维度。职位和收入由太多不可控因素决定，比了只会内耗；而健康、家庭、心态是自己能控制的，比了会有正反馈。
失效条件
无。
翻车
有人一辈子跟人比位置，退休后突然没了坐标系，整个人垮了。
可靠度
乙
备注
这一条和 4.3.5"把我要上去换成我要过好"是同一件事。
4.5.5

什么时候该显，什么时候该藏

可靠 乙代价 无
代价
要判断场合。
一句话
该露脸的时候别缩，该低调的时候别显。
怎么做
该显——领导在场、有外部单位、涉及评优考核；该藏——同级别竞争期、有人刚失意、涉及利益分配。
为什么
能力和锋芒是两件事。能力要有，锋芒要看场合。你在错误的时点显，会给自己树敌；在正确的时点藏，会失去机会。
失效条件
无。
翻车
有人在同事刚被否掉提拔的当口，兴奋地讲自己接了新项目，从此被孤立。
可靠度
乙
备注
这一条的分寸感，是体制内最难练的。

本节小结

这一节五条，讲的是：嫉妒是单位里的常态，不必羞耻，但要会处理。

被嫉妒时闭嘴，嫉妒别人时换维度，比较时换记分牌。

你控制不了别人怎么看你，但你能控制自己跟谁比。

下一节讲一种更常见的状态：职业倦怠。

4.6职业倦怠：不是懒，是烧完了

有一种状态，很多人都有，但说不出名字：

不想上班，但也不是想辞职；活照干，但心里没劲；早上醒来第一件事是算"还有几天到周末"。

这不是懒。这是职业倦怠（burnout），世界卫生组织把它列为一种"职业现象"，三个特征：情绪耗竭、去人格化、成就感降低。

这一节讲怎么认它、怎么缓它。

4.6.1

三个信号，对上两个就是倦怠

● 必做可靠 甲代价 无
代价
要承认自己状态不好。
一句话
倦怠不是"不够努力"，是"努力太久没有回报"。
怎么做
自查三条——情绪耗竭（下班像被抽空，睡不回来）、去人格化（对服务对象、对同事变得冷漠、爱讽刺）、成就感降低（干了很多，觉得毫无意义）。对上两条，基本可以确认。
为什么
倦怠的核心机制是"长期高投入 + 低回报 + 低控制感"。体制内恰好三样都占：活多、回报慢、改不了。
失效条件
短期（一两周）的状态低落，是疲劳不是倦怠。
翻车
有人以为自己是"变懒了"，自责了两年，其实是倦怠，越自责越重。
可靠度
甲（Maslach 倦怠量表是学术界通用工具）
备注
给它起个名字，本身就是一种缓解。
4.6.2

倦怠的解药不是休假，是"控制感"

● 必做可靠 乙代价 无
代价
要主动做点改变。
一句话
休假只能缓解耗竭，缓解不了"我说了不算"。
怎么做
在自己的工作里，找一件"完全由你决定"的事——怎么排版、什么时候做、用什么方法。哪怕很小，也要保住这一块。
为什么
倦怠的三个成因里，"低控制感"是最伤人的一个。休假解决的是"累"，解决不了"无力"。而重新获得一点控制权，哪怕只在很小的事上，就能显著改善状态。
失效条件
岗位完全没有自主空间（如窗口受理），那要在工作之外找控制感。
翻车
有人休了一个月长假，回来第一周就恢复原样，因为什么都没变。
可靠度
乙
备注
这一条是整节的核心：倦怠不是休息不够，是自主不够。
4.6.3

把"意义"从工作里挪出来

● 必做可靠 乙代价 无
代价
要接受这份工作不提供意义。
一句话
不是每份工作都要有意义，工作可以只是工作。
怎么做
把意义感放到工作之外——家庭、爱好、副业、公益。工作只负责"养活你"，别让它负责"证明你"。
为什么
倦怠的第三个特征是"成就感降低"。如果你把全部成就感押在工作上，而工作又给不了，就会陷入持续的失落。挪出来，反而轻松。
失效条件
你的工作确实有强烈的意义感（医生、教师、救援），那不必挪。
翻车
有人一直在工作里找意义，找了十年，越找越空。
可靠度
乙
备注
这一条不是消极。是重新分配"意义"的来源。
4.6.4

倦怠期别做重大决定

● 必做可靠 乙代价 无
代价
要等。
一句话
倦怠的时候看什么都是灰的，包括你的选择。
怎么做
倦怠期（通常是几个月）不做辞职、不吵架、不摊牌。等状态回升到"能平静地讨论这件事"，再做决定。
为什么
倦怠会扭曲判断——你会高估工作的坏，低估离开的成本。很多"冲动辞职"都发生在倦怠最重的时候。
失效条件
涉及健康、被侵害，不能等。
翻车
有人在最崩溃的时候递了辞职信，半年后后悔，但回不去了。
可靠度
乙
备注
这一条和 4.4.3"别在深夜做职业决定"是一回事，只是时间尺度更长。
4.6.5

三个具体动作，比"调整心态"有用

◎ 建议可靠 乙代价 无
代价
要动起来。
一句话
倦怠不是想通的，是做出来的。
怎么做

1. 划边界：定一个"绝对不工作"的时段，每天两小时。

2. 做一件小事并完成它：整理一个抽屉、写完一篇小文——完成感能修复成就感。

3. 找人说话：不是同事，是单位之外的人，每周一次。

为什么
倦怠是一种"习得性无力"，而无力感只能靠"做成事"来打破，不能靠"想开"。
失效条件
重度倦怠（伴随抑郁症状），需要专业帮助。
翻车
有人天天看"如何调整心态"的文章，看了半年，一点没变。
可靠度
乙
备注
这一条的关键是"小"。别定大目标，定能完成的小事。
4.6.6

什么时候该求助，而不是硬撑

● 必做可靠 甲代价 钱少
代价
要开口。
一句话
倦怠和抑郁的边界，比你想的模糊。
怎么做
出现以下情况，去看精神心理科——持续两周以上情绪低落、对什么都提不起兴趣、睡眠和食欲明显改变、有"活着没意思"的念头。
为什么
倦怠是职业现象，抑郁是疾病。前者可以调整，后者需要治疗。而两者症状高度重叠，自己分不清。
失效条件
无。
翻车
有人把抑郁当倦怠，硬撑了一年，最后住院。
可靠度
甲
备注
这一条不丢人。体制内看心理科的人，比你以为的多得多。

本节小结

这一节六条，讲的是：倦怠不是你的错，但恢复是你的责任。

认它、给它名字、找回一点控制感、把意义挪出去、别在谷底做决定、该求助就求助。

烧完了，不是加柴，是先灭火。

清闲是有前提的

5.1红线：一张让人睡得着觉的地图

前面四卷讲怎么活得舒服。这一卷讲怎么不出事。

因为舒服是有前提的：不碰红线、不背黑锅。碰了红线，前面所有的账都清零；背了黑锅，你连算账的资格都没有。

这一节讲边界在哪。

先说清楚：这一节只写"线在哪"，不写"怎么绕"。 每一条都对应公开通报里的真实案例，都是别人用前途换来的坐标。

5.1.1

一顿饭的边界：谁付钱、什么标准、有谁在

● 必做可靠 甲代价 无
代价
要问清楚。
一句话
饭本身不是问题，"谁付钱"和"为什么吃"才是问题。
怎么做
接受宴请前问三句——谁请？为什么请？有没有管理服务对象？答不清就不去。自己单位内部的公务接待，按标准来，超了就是超了。
为什么
纪律管的是"可能影响公正执行公务"的宴请，不是所有饭。管理服务对象请客、下属单位请客、有请托事项的请客，这三类是明确的高危场景。而"标准"是硬杠杠，超标就是超标，没有"差不多"。
失效条件
纯私人朋友聚会、AA 制、亲属聚餐，不在此列。
翻车
某干部接受管理服务对象宴请，一顿饭消费数千元，事后被党内警告。通报里写的不是"吃了多少钱"，是"接受可能影响公正执行公务的宴请"。
可靠度
甲（中央八项规定及实施细则、纪律处分条例均有明确规定）
备注
这一条的关键不在"吃"，在"关系"。你跟谁吃，比吃什么重要。
5.1.2

礼品那条线：多少钱算数、怎么退、怎么留痕

● 必做可靠 甲代价 无
代价
要当面拒绝，会尴尬。
一句话
收下再退，和被当场拒收，性质不一样。
怎么做
能当场拒就当场拒，说"我们有纪律"。拒不掉的上交组织，并且留下书面记录——什么时候、谁送的、什么东西、怎么处理的。
为什么
纪律规定的是"收受可能影响公正执行公务的礼品礼金"。数额是一个维度，"可能影响"是另一个维度。而"收了再退"在很多案例里仍被认定为收受，因为你已经接受了这个行为。
失效条件
正常人情往来（红白喜事按当地风俗、价值相当的礼尚往来），不在纪律禁止范围内，但要注意对象和场合。
翻车
某干部收受礼金后主动退还，仍被处分。通报里的表述是"收受后又退还，不影响违纪认定"。
可靠度
甲
备注
这一条和 5.2 的"留痕"是配套的：拒收也要留痕。
5.1.3

酒驾：这不是纪律问题，是人生问题

● 必做可靠 甲代价 无
代价
一顿酒钱，或者一次代驾。
一句话
一次酒驾，可能同时丢掉工作、党籍和自由。
怎么做
喝酒不开车，这句话没有例外。开车去的场合，一滴不喝；喝了酒的场合，车放那儿，打车回家。
为什么
醉驾入刑，判了刑就开除公职、开除党籍。而酒驾（未达醉驾标准）也要给予党纪政务处分。这不是"注意一下"能解决的，是一次就到底的线。
失效条件
无。这一条没有任何例外。
翻车
某干部酒后驾车被查，血液酒精含量达到醉驾标准，被判处拘役，随后被开除党籍、开除公职。
可靠度
甲
备注
这一条是全书最不该讲道理的一条。不讲道理，只讲后果。
5.1.4

男女关系：单位里最容易出事、也最说不清的一件事

● 必做可靠 甲代价 无
代价
要保持距离。
一句话
在单位，任何一段说不清的关系，最后都会被说成最难听的那个版本。
怎么做
不与异性下属单独在封闭空间长时间相处；不出差同住一层；不深夜私聊非工作内容；不单独接送。
为什么
纪律对"生活纪律"有明确要求，而单位是熟人社会，任何风吹草动都会被放大。更麻烦的是，即使你清白，解释的成本也极高——而多数人没有能力承担这个成本。
失效条件
正常工作接触、公开场合、有第三人在场，不必过度紧张。
翻车
某干部因生活作风问题被举报，虽然部分情节未能查实，但仍因"造成不良影响"受到处分。
可靠度
甲
备注
这一条不是让你疑神疑鬼。是提醒你：在单位，避嫌本身就是一种能力。
5.1.5

你打的每个字都在留痕：群、朋友圈、私人微信

● 必做可靠 甲代价 无
代价
要少说话。
一句话
网络不是法外之地，这句话对体制内的人尤其成立。
怎么做
不在任何平台发表涉政、涉密、涉单位的言论；不转发未经证实的信息；不在群里评价领导和同事；朋友圈分组。
为什么
政治纪律、组织纪律、工作纪律对言行都有约束。而网络言论是可检索、可截图、可追溯的——它比任何口头表达都更容易成为证据。
失效条件
无。
翻车
某干部在微信群转发不当言论，被给予党内警告处分。通报里写的是"违反政治纪律"。
可靠度
甲
备注
这一条和 3.4 是同一件事，但性质不同：那边讲"别惹麻烦"，这边讲"别违纪"。
5.1.6

兼职、副业、讲课费：哪些能干，哪些一碰就是雷

● 必做可靠 甲代价 无
代价
要放弃一些收入。
一句话
能不能干，看三条——是否经过批准、是否利用职权、是否影响本职。
怎么做
写作、出版、讲课、咨询，多数需要报批；不得在管辖范围内的企业兼职；不得领取职务相关的报酬。拿不准的，先问组织，别先干。
为什么
纪律禁止的是"违反有关规定从事营利活动"和"利用职权或职务影响谋取私利"。不是所有副业都禁止，但"未经批准"和"利用影响"这两条，踩一条就够。
失效条件
纯稿酬、专利、艺术创作等，按各单位具体规定执行，有的允许有的需报备。
翻车
某干部在管辖企业兼职取酬，被给予党内严重警告处分，违纪所得被收缴。
可靠度
甲
备注
这一条最容易被误解成"什么都不能干"。实际是"该报批的报批，该回避的回避"。
5.1.7

被叫去谈话时：能说什么，不能说什么

● 必做可靠 甲代价 无
代价
要诚实，也要懂程序。
一句话
如实说明是义务，但不是让你猜着说。
怎么做
知道的说知道，不知道的说不知道，记不清的说记不清。不猜测、不推断、不替别人回答。有书面材料就提供材料。
为什么
纪律审查最看重的是态度和真实性。编造、隐瞒、对抗，本身就是独立的违纪行为，而且会加重处理。而"记不清"是可以被接受的——人确实会忘。
失效条件
无。
翻车
某干部在谈话中为掩饰一个小问题编了一个说法，后来被查实，性质从"工作失误"变成"对抗组织审查"。
可靠度
甲
备注
这一条不是法律建议。真遇到这种情况，应当咨询专业律师或按规定申请帮助。

本节小结

这一节七条，全部指向一句话：这些线，一次都不能试。

不是因为试了会被抓，是因为试了之后，你前面所有的账都白算了——你省下的时间、养好的身体、处好的关系，全部清零。

红线的作用不是限制你，是保护你算过的那些账。

下一节讲另一半：不碰红线，也别被人当垫背。

5.2别当那个容器

责任不会消失，它只会找一个容器。

这句话是本书最重要的一句。因为体制内所有的"背锅"，本质都是同一个过程：责任在寻找一个能装下它的人，而你正好离得最近、最没有防御、最说不清。

这一节讲怎么不成为那个容器。

5.2.1

锅不找做错的人，找说不清的人

● 必做可靠 乙代价 无
代价
要接受一个不太好听的真相。
一句话
追责的本质不是还原真相，是在有限时间里得出一个"说得清"的结论。
怎么做
每经手一件事，问自己一句——"如果明天出事，我拿什么证明我做了什么、没做什么？"答不上来，这件事对你就还没结束。
为什么
追责有时间和成本的约束。谁的材料最全、时间线最清，谁就最不像责任人；谁的记录最乱、记忆最模糊，谁就成了那个结论。举证失败的人，替真正犯错的人背锅。
失效条件
有完整系统留痕的场景（OA 全流程、电子签批、监控覆盖），"说不清"的空间被压缩。
翻车
某次数据出错，两个人都有责任。一个能拿出当天的微信记录和修改稿，一个只能说"我记不清了"。最后通报里只有后一个人的名字。
可靠度
乙
备注
这一条解释了为什么"老实人"总背锅——不是他们错得多，是他们留得少。
5.2.2

口头指示不是命令，是可撤回的意向

● 必做可靠 乙代价 无
代价
每次多花一分钟。
一句话
领导嘴上说的，出事时不算数；你记下来发给他确认的，才算。
怎么做
口头交办后，回座位发一条消息："X 局，刚才您说的三件事我记一下：一……二……三……，我按这个办，有出入您纠正。"不要求他回"确认"，只要他不否认，这条就是记录。
为什么
口头指示没有痕迹，事后无法举证。这不是领导想赖账，是人的记忆会自我修正——半年后他记得的，和他当时说的，很可能不是一回事。留痕不是防人，是防记忆。
失效条件
日常琐事不必如此。判断标准只有一条：这事出错会不会有人被追责。
翻车
某人按领导口头要求调整了报销科目，事后审计发现问题，领导说"我没让他这么改"。没有记录，他无法自证。
可靠度
乙
备注
措辞要平，别写"以免以后说不清"这类带暗示的话。
5.2.3

只在四个地方留痕：利益、金钱、工作安排、领导指示

● 必做可靠 乙代价 无
代价
要判断哪些事值得留。
一句话
留痕不是处处留，是四处留。留错了地方叫"留刺"，漏了这四处叫"裸奔"。
怎么做
只在这四类事上留——利益分配（评优、奖金、职级）、金钱往来（报销、接待、礼品）、工作安排（谁干什么、什么时候交）、领导指示（尤其口头交办）。其余日常协作，一个字都不必留。
为什么
这四类是追责的高发区，也是唯一能靠文字还原事实的领域。其余地方留痕，传递的信号是"我不信任你"，伤的是关系，换不来安全。
失效条件
紧急处置、抢险救灾，先办事后补记录，但补的时候要写"因紧急情况先行处置"。
翻车
某人只在群里留痕，关键的口头指示一句没记。出事时他拿出三百条群消息，没有一条能证明"这事是领导定的"。
可靠度
乙
备注
这一条来自实战，比任何理论都管用。
5.2.4

出事第一个小时：固定证据，不要解释

● 必做可靠 乙代价 无
代价
要压住解释的冲动。
一句话
你越急着解释，越像在掩饰。
怎么做
四件事——保存原始文件（别改、别删）、导出聊天记录、找到在场的人、写一份当天的时间线（自己留着，不急着交）。
为什么
证据会消失。文件会被覆盖，群消息会被撤回，人的记忆会跟着立场走。而解释会污染证据——你一边说一边改，改过的版本就成了新的嫌疑。
失效条件
涉及安全事故、人员伤亡，第一反应是救人、报警、报告。
翻车
某人出事当天急着解释，把原始表格"整理"了一遍。后来核对时，整理过的版本和系统记录对不上，反而成了"篡改"的嫌疑。
可靠度
乙
备注
时间线只写事实，不写评价。"9:20 收到通知""10:05 电话请示 X 局"，就这样。
5.2.5

三步止损：还原、划界、给方案

● 必做可靠 乙代价 无
代价
要咽下委屈，先干活。
一句话
组织最想知道的不是"谁错了"，是"现在怎么办"。
怎么做
第一步，书面还原事实；第二步，明确职责边界；第三步，提出补救方案。
为什么
追责是流程，处置也是流程。两个流程同时在跑，谁先占据"处置"的位置，谁就自动退出了"追责"的靶心。能解决问题的人，暂时不会被处理。
失效条件
涉及违纪违法，第一步应该是向组织说明情况。
翻车
某人被追责后到处解释"这不是我的错"，半年没人理他。另一个同样被追责的人，第二天交了整改方案，后来成了整改负责人。
可靠度
乙
备注
喊冤解决的是情绪，止损解决的是处境。
5.2.6

别在群里认错，也别在群里甩锅

● 必做可靠 乙代价 无
代价
要忍住不回嘴。
一句话
群是公开法庭，不是沟通工具。
怎么做
群里只回事实和动作；涉及责任的话，一律私聊或当面；已被 @ 问责，回"我马上核实，稍后向您汇报"，然后私聊。
为什么
公开认错，等于把责任固定下来；公开甩锅，等于把矛盾公开化。而群消息会被截图、转发、断章取义——你控制不了它的去向。
失效条件
确实是你错了，且错误已经公开，那就公开认，但只认自己那部分。
翻车
某人在群里回"是 X 科给我的数据有问题"，X 科的人截图发给了分管领导，事情从"数据错误"变成"科室不和"。
可靠度
乙
备注
群里的文字没有语气。你写的是解释，别人读的是推卸。
5.2.7

代签是把名字借给别人用，风险全在你

● 必做可靠 甲代价 无
代价
可能得罪让你代签的人。
一句话
代签的人承担签字人的责任，享受不到签字人的权力。
怎么做
一律不代签。领导不在，就说"等 X 局回来我第一时间送过去"；实在急，走"电话请示 + 事后补签 + 附情况说明"。
为什么
笔迹可以鉴定。代签一旦被认定，轻则违反工作纪律，重则涉嫌伪造。而且代签时你并不掌握签字人掌握的信息，等于闭着眼睛替他担保。
失效条件
极少数制度允许的"授权代签"，必须有书面授权，且在授权范围内。
翻车
某单位经办人替休假的科长签"审核"，票据出问题后，性质从"把关不严"变成"伪造他人签名"。
可靠度
甲
备注
别人让你代签，说"我签了也不算数，还是得本人签"——把问题推给制度，不推给人。
5.2.8

锅守恒：责任不会消失，只会找下一个容器

● 必做可靠 乙代价 无
代价
承认这一点，心里不太舒服。
一句话
责任不会因为没人承认而消失，它只会去找下一个能装下它的人。
怎么做
碰到任何可能出问题的事，先问一句"这事最后谁签字"。找不到签字的人，就是没有责任人——也就是所有人都可能被算作责任人。
为什么
组织需要一个答案。追责不是哲学问题，是行政流程：一份通报里必须有"责任人：某某"。这个位置空着，流程就走不完。所以"大家一起负责"在出事时必然坍缩成"找一个人负责"。
失效条件
明确规定集体担责、且留有完整会议记录的事项，责任确实分摊。但执行环节仍会落到经办人。
翻车
某单位一笔采购出问题，经办、审核、审批三个人都说"当时是大家一起定的"。最后经办人承担主要责任——因为只有他的手，具体落在单据上。
可靠度
乙
备注
这是本节的第一定律。理解它，后面才有意义。
5.2.9

责任黏度 = 你留下的痕迹 ÷ 你掌握的证据

● 必做可靠 乙代价 无
代价
要养成一个新习惯。
一句话
痕迹越多、证据越少，你越容易被粘住。
怎么做
每件事结束前做一次三秒自检——我留了什么痕迹？我手上有什么证据？ 痕迹多证据少，就补证据；两样都没有，说明这事根本不该你碰。
为什么
痕迹是"你参与过"的证明，证据是"你只参与了这一段"的证明。前者让你进入嫌疑名单，后者让你从名单上下来。多数人只顾着干活，从不检查这两个数。
失效条件
纯粹的体力活、无责任的执行性工作，不需要算这个。
翻车
某人干了三年杂活，什么都会一点。出事时所有人都说"这个他经手过"，他翻遍电脑，找不到一份能证明"这事不归我"的材料。
可靠度
乙
备注
这个公式不精确，但它能让你每次动手前多问一句"值不值"。

本节小结

这一节七条，讲的是同一件事：让责任落在它该落的地方。

不是推卸，是精确。你扛你该扛的那一段，别扛别人那一段。这不是自私，这是让整个系统还能正常运转的前提。

下一节讲最凶险的一种情况：你的领导出事了。

5.3领导出事的时候

单位里最凶险的时刻，不是领导批评你，是领导被查了。

那一刻，所有人的第一反应都是"我会不会被牵连"，第二反应是"我该怎么表现"。而这两个反应，往往会让人做出最糟的选择。

这一节讲怎么在这个时刻保住自己——不落井下石，也不陪葬。

5.3.1

第一件事是划清工作边界，不是表态

● 必做可靠 乙代价 无
代价
要冷静，不能慌。
一句话
你跟他是什么关系，用文件说话，不用态度说话。
怎么做
把手上的项目过一遍——哪些是他直接交办的、哪些经过他签批、哪些是你独立完成的。列一张表，自己心里有数。不要主动去找组织"汇报思想"，也不要四处打听。
为什么
组织调查看的是事实和证据，不是态度。你越急着表态，越像心里有鬼；你越沉默，反而越安全。而"划清边界"这件事，靠的是材料，不是嘴。
失效条件
如果组织明确找你谈话，那就如实说，不要回避。
翻车
有人在领导被查后到处说"我早就觉得他不对劲"，结果被认定为"政治上不成熟"，反而被调查组重点关注。
可靠度
乙
备注
这一条的核心是"不要表演"。这个时刻，所有表演都是负分。
5.3.2

你签过字的东西，自己心里要有数

● 必做可靠 甲代价 无
代价
要提前整理。
一句话
签字是你的，不是领导的。
怎么做
把近三年你签过字的文件翻一遍，重点看金额、事项、审批链。有疑问的，把当时的依据材料找出来——谁交办的、为什么这么办、有没有会议记录。
为什么
领导出事，牵连的往往是"经手人"。而经手人的自保，靠的不是"我不知道"，是"我当时依据的是这个"。有依据，就是执行；没依据，就是共谋。
失效条件
纯粹的例行签字（如日常报销），且完全符合制度，不必紧张。
翻车
某人签过一份"情况说明"，当时没细看。事后查出内容不实，他无法说明为什么签。
可靠度
甲
备注

无。
翻车
某人替领导隐瞒了一笔账外支出，最后领导被从轻处理，他被从重处理。

甲

5.3.4

曾经的"心腹"，出事时是最危险的身份

◎ 建议可靠 乙代价 无
代价
要接受自己被重新审视。

你跟得越近，越需要证明自己只是"工作关系"。

为什么
调查的逻辑是"顺着关系找人"。走得越近的人，越先被排查。而这个时候，任何"我跟他很熟"的表态，都会变成"我需要重点核查"的理由。

你确实参与了他的违纪行为，那只能如实交代，争取从轻。
翻车
某人自称是领导的"左膀右臂"，领导出事后，他被第一个谈话，谈了七次。
可靠度
乙
备注
这一条不是让你背叛。是让你明白：关系近，不等于要陪着一起沉。
5.3.5

主动说和被动查，是两种完全不同的结局

● 必做可靠 甲代价 无
代价
要主动开口，很难。

同样一件事，主动说明是"配合"，被动查出是"隐瞒"。

为什么

失效条件
无。
翻车
某人抱着"应该查不到我"的侥幸，等了半年。最后被查出时，从轻情节全部丧失。
可靠度
甲
备注
这一条是最难的一条，也是最值钱的一条。真到了那一步，早说永远比晚说好。

本节小结

这一节五条，讲的是一个姿态：不落井下石，也不陪着一起沉。

前者是品格，后者是理性。

领导出事，对你是一次考验——考验的不是忠诚，是分寸。分寸对了，你还能继续干下去；分寸错了，你会成为这件事的一部分。

5.4被举报了怎么办

体制内最让人睡不着的三个字：有人举报。

多数人第一反应是慌，第二反应是猜"是谁"，第三反应是到处解释。这三个反应，全是错的。

这一节讲怎么处理这件事——不慌、不乱、不自己先把自己办倒。

5.4.1

举报的四种来源，先分清是哪一种

● 必做可靠 乙代价 无
代价
要冷静分析。
一句话
不同来源的举报，处理方式完全不同。
怎么做
先判断——利益冲突型（竞争、分房、评优）、情绪型（得罪过人、吵过架）、误解型（信息不全）、恶意型（有人要整你）。四类的应对不一样。
为什么
利益型和情绪型，多数查无实据，走完程序就结束了；误解型需要你提供材料澄清；恶意型往往反复举报，要有长期准备。
失效条件
涉及实质问题的举报，无论来源，都要认真对待。
翻车
有人把一封情绪型举报当成"有人要整我"，四处打听、找人施压，反而把小事闹大。
可靠度
乙
备注
这一条的目的是让你先"定性"，别先"反应"。
5.4.2

接到通知后的第一件事：整理材料，不是找人

● 必做可靠 乙代价 无
代价
要坐下来干活。
一句话
能救你的只有材料，不是关系。
怎么做
按举报的内容，逐条整理证据——时间、地点、文件、记录、在场的人。做成一份时间线，自己先看清楚。
为什么
组织核查看的是证据链。你找人说情，等于给自己加一条"干扰核查"；你把材料准备好，才是在配合。
失效条件
无。
翻车
有人第一时间打电话给所有认识的人"解释一下"，结果被认定为"串通"。
可靠度
乙
备注
这一条和 5.2.4"出事第一个小时固定证据"是同一件事。
5.4.3

别自己先慌：多数举报，查完就结束了

● 必做可靠 乙代价 无
代价
要压住恐惧。
一句话
举报是"线索"，不是"结论"。
怎么做
正常上班、正常工作、正常汇报。不主动提这件事，也不刻意回避。有人问起，说"组织在核实，我配合"。
为什么
纪检监查机关对举报有初核程序，多数举报在初核阶段就了结（不属实或达不到立案标准）。你一慌，反而会让周围人觉得"他心里有鬼"。
失效条件
如果确实有问题，那要早说，别拖。
翻车
有人被举报后请了半个月假，回来后全单位都在传"他出事了"。
可靠度
乙
备注
这一条不是让你侥幸。是让你别在没结论的时候先把自己办了。
5.4.4

配合核查的边界：如实说，但不猜

● 必做可靠 甲代价 无
代价
要克制。
一句话
知道的说知道，不知道的说不知道，记不清的说记不清。
怎么做
不推断、不猜测、不替别人回答、不评价他人。有材料就提供材料。每次谈话后，自己记一份要点（时间、问了什么、你答了什么）。
为什么
编造和隐瞒本身就是违纪。而"记不清"是可以被接受的——人确实会忘。你越是想"说得圆满"，越容易前后矛盾。
失效条件
无。
翻车
有人为了"显得清白"，把一件记不清的事说得非常详细，后来被查出细节对不上。
可靠度
甲
备注
这一条和 5.1.7 是同一件事，只是场景更具体。
5.4.5

别去猜"是谁举报的"

● 必做可靠 乙代价 无
代价
要忍住。
一句话
猜错了，你会得罪一个无辜的人；猜对了，你会多一个敌人。
怎么做
不打听、不试探、不在同事面前表现"我知道是谁"。真要防，就防所有人——保持距离，规范做事。
为什么
举报渠道是保密的，你几乎不可能查实。而你的猜测一旦传出去，会制造新的矛盾，还会被认定为"打击报复"。
失效条件
无。
翻车
有人认定是某个同事举报的，处处针对，后来查明是另一个人，但关系已经毁了。
可靠度
乙
备注
这一条是保护你自己，也是保护无辜的人。
5.4.6

事过之后，别急着"证明自己"

◎ 建议可靠 乙代价 无
代价
要忍一段时间。
一句话
清白不需要证明，需要时间。
怎么做
不主动提这件事，不逢人便解释，不在朋友圈发"清者自清"。正常干活，半年后自然淡了。
为什么
你越急着证明，越像在辩解。而单位里的记忆很短——三个月后，大家关心的是新的事。
失效条件
涉及名誉的公开造谣，那要正式澄清。
翻车
有人在群里发了一段长文自证清白，被截图传成了"他心里有气"。
可靠度
乙
备注
这一条和 4.4.6"委屈放一周"是一个道理。

本节小结

这一节六条，讲的是一件事：被举报不等于出事。

先定性，再备料，别慌、别猜、别自证。

真正能保护你的，是你平时的规范，不是事发后的反应。

该拿的，一分别让

6.1该拿的，一分别让

清高不能当饭吃。

体制内有个奇怪的现象：很多人对"该拿的钱"特别不好意思——不敢问、不敢要、不敢争，好像多拿一分就是"计较"。

结果是自己吃亏，单位也不会因此高看你一眼。

这一节讲：哪些钱是你该拿的，怎么拿，以及为什么不必不好意思。

6.1.1

工资条上每一项是什么，多数人没看过

● 必做可靠 甲代价 无
代价
要花十分钟。
一句话
你连自己的钱怎么算的都不知道，就没法发现算错了。
怎么做
找一个月的工资条，逐项看：基本工资、津贴补贴、绩效、扣款（社保、公积金、个税、职业年金）。每一项问一句"这是什么、怎么算的"。
为什么
工资构成决定了你以后能拿多少——比如绩效基数、津贴项目，都会影响退休待遇。而且工资算错是真实存在的，尤其是调入调出、职级变动、政策调整的那几个月。
失效条件
无。
翻车
有人三年后发现自己的某项津贴一直按旧标准发，补发时已经跨了两个年度，手续麻烦了一倍。
可靠度
甲（工资构成有明确的政策依据）
备注
这一条不涉及任何灰色地带，纯粹是"看清楚自己的钱"。
6.1.2

未休年假的补偿，多数人从没领过

● 必做可靠 甲代价 无
代价
要开口问。
一句话
年假不是"福利"，是法定权利，不休要补钱。
怎么做
年底前查一下自己还剩几天年假。单位安排不了的，按规定应支付未休年休假工资报酬（通常按日工资的 300% 计算，其中包含正常工资）。问人事，别问同事。
为什么
《职工带薪年休假条例》明确规定，单位确因工作需要不能安排职工休年休假的，经职工本人同意，可以不安排；对职工应休未休的年休假天数，单位应当按照该职工日工资收入的 300% 支付年休假工资报酬。
失效条件
你自己书面提出不休的，通常只支付正常工资。所以别随便签"自愿放弃"。
翻车
有人连续五年没休完年假，也从没问过补偿。离职时才知道有这笔钱，但已经过了追溯期。
可靠度
甲
备注
这一条是全书"最该拿却最少人拿"的一笔。
6.1.3

加班费和值班费，不是一回事

● 必做可靠 甲代价 无
代价
要分清自己算哪种。
一句话
加班是"延长工作时间"，值班是"非生产性值守"，两者的报酬标准不同。
怎么做
看排班表怎么写的。写"值班"的，按值班补贴；写"加班"的，按加班费（工作日 150%、休息日 200%、法定节假日 300%）。如果单位把加班写成值班，可以提出。
为什么
这不是文字游戏，是钱。而且很多单位确实存在"以值班之名行加班之实"的情况，因为值班补贴远低于加班费。
失效条件
公务员适用《公务员法》，不直接适用《劳动法》的加班费条款，具体按单位规定和当地政策执行。
翻车
有人一个月加了八十小时班，全部按"值班"发了每天五十块。
可靠度
甲（但公务员与事业单位、企业适用规则不同，需按身份确认）
备注
这一条要按自己的身份查对应规定，别拿企业的标准套公务员。
6.1.4

公积金符合条件就能提，不提就是死钱

● 必做可靠 甲代价 无
代价
要跑一次手续。
一句话
账户里的钱不是你的存款，是"有条件才能用的钱"。
怎么做
查当地公积金提取条件——购房、租房、还贷、大病、离职（部分地区）、退休。多数城市现在可以线上办理。
为什么
公积金账户利率很低，长期不用等于贬值。而提取条件是明确的，符合就能提，不需要"找关系"。
失效条件
各地政策差异大，以当地公积金中心的规定为准。
翻车
有人账户里躺了二十万，一直以为"退休才能取"，其实租房就能提。
可靠度
甲
备注
这一条是"信息差"最典型的一类：不是不给你，是你不知道能拿。
6.1.5

工会的疗休养、互助金，不去就白白作废

◎ 建议可靠 乙代价 无
代价
要主动报名。
一句话
工会的钱是全体会员的，你不用，它就用在别人身上。
怎么做
问工会今年的疗休养名额、困难补助、互助保障、节日福利。该报名的报名，该申请的申请。
为什么
工会经费按规定用于服务职工，包括疗休养、慰问、互助保障等。这些资源多数是"按名额分配"，不主动申请就轮不到。
失效条件
各单位工会经费和项目差异很大，有的单位确实没有这些。
翻车
有人在单位干了十五年，从没参加过疗休养，因为"以为轮不到自己"。
可靠度
乙
备注
这一条的关键是"问一句"。问了没有，也不损失什么。
6.1.6

医疗期工资怎么发，不是单位说了算

● 必做可靠 甲代价 无
代价
要了解自己的权利。
一句话
生病期间不是"想发多少发多少"，有法定下限。
怎么做
查当地关于病假工资/疾病救济费的规定。多数地区规定不低于当地最低工资标准的 80%，具体按当地政策。
为什么
医疗期是法定的保护期，期间单位不能随意解除合同，工资也有下限。这条对长期生病的人尤其重要。
失效条件
公务员、事业单位人员的病假待遇按各自的规定执行，与企业职工不同。
翻车
有人住院三个月，单位只发了基本工资的一半，他不知道可以主张，就这么算了。
可靠度
甲（但需按身份和地区确认具体标准）
备注
这一条最好在健康的时候了解，别等生病了再查。

本节小结

这一节六条，讲的都是"该拿的钱"。

不是教你钻空子，是提醒你：制度给你的东西，你不拿，它不会自动到你手上。

问一句，查一下，跑一趟。这些动作的成本很低，收益很实在。

6.2能休的假，都休完

体制内的人，最不会用的一样东西，是假期。

年假不敢休、病假不好意思请、探亲假从来没听过、调休攒着攒着就没了。

结果一年下来，假期作废，身体垮了，家里人也没见着。

这一节讲：你有哪些假，怎么休，怎么不被"工作忙"绑住。

6.2.1

年休假：天数怎么算、能不能跨年、能不能折钱

● 必做可靠 甲代价 无
代价
要主动安排。
一句话
年假是法定权利，不是领导的恩赐。
怎么做
工作满 1 年不满 10 年的，年休假 5 天；满 10 年不满 20 年的，10 天；满 20 年的，15 天。国家法定休假日、休息日不计入年休假。可以分段休，一般不跨年安排；确有必要跨年的，可以跨 1 个年度。
为什么
这三档是《职工带薪年休假条例》明确规定的，不是单位自己定的。很多人以为自己只有 5 天，其实按工龄算早就该是 10 天或 15 天。
失效条件
公务员、事业单位人员按各自规定执行，天数口径基本一致，但审批流程不同。
翻车
有人工作了十八年，一直按 5 天休，因为"单位一直这么执行"。
可靠度
甲
备注
工龄是累计工作年限，包括在其他单位的工作时间，不是只算本单位。
6.2.2

病假和医疗期：关键在"医疗期"这三个字

● 必做可靠 甲代价 无
代价
要区分两个概念。
一句话
病假是"你请假"，医疗期是"单位不能动你"。
怎么做
医疗期长短按实际工作年限和本单位工作年限确定，一般为 3 个月到 24 个月。医疗期内，单位不能以"不能胜任工作"为由解除合同。
为什么
很多人只知道"请病假要开证明"，不知道"医疗期"是一层法律保护。真遇到长期生病、单位想"劝退"的时候，这三个字能救命。
失效条件
医疗期内严重违纪的，仍可解除。
翻车
有人生病半年，单位劝他"主动辞职"，他签了。后来才知道医疗期内不能解除。
可靠度
甲
备注
这一条对企业职工最有用；公务员和事业单位按各自规定执行。
6.2.3

探亲假：跨省工作的人，有一个几乎失传的假期

◎ 建议可靠 甲代价 无
代价
要符合条件。
一句话
这是给"异地工作"的人的政策补偿，很多人从来没听说过。
怎么做
国家机关、人民团体和全民所有制企业事业单位工作满一年的固定职工，与配偶不住在一起、又不能在公休假日团聚的，每年可享受一次 30 天探亲假（探望配偶）；未婚职工探望父母每年 20 天，或两年一次 45 天。
为什么
这是 1981 年《国务院关于职工探亲待遇的规定》确立的制度，至今有效。它覆盖的人很多，但知道的人极少，因为很多单位不主动提。
失效条件
企业职工是否适用，取决于本单位制度；民营、外资企业通常不适用。
翻车
有人夫妻两地分居八年，从没休过探亲假，因为"不知道有这个假"。
可靠度
甲
备注
这一条是全书"信息差"最典型的一条。知道的人少，但它是真的。
6.2.4

产假、育儿假、陪产假：各地在法定之外还有加码

● 必做可靠 甲代价 无
代价
要查本地政策。
一句话
国家规定的是底线，各省普遍往上加了。
怎么做
产假国家规定 98 天，各省普遍延长至 128–158 天，部分地区更长；陪产假（护理假）7–30 天不等；育儿假多数省份规定子女 3 岁前每年 5–15 天。
为什么
这些是地方性法规规定的，同一件事在不同省份差别很大。而单位人事未必主动告知，尤其是育儿假这种新政策。
失效条件
具体天数以本省《人口与计划生育条例》为准。
翻车
有人不知道有育儿假，孩子三岁前一天没休。
可靠度
甲
备注
查"XX 省人口与计划生育条例"，比自己猜准。
6.2.5

调休和补休，写错一个字少三天

● 必做可靠 乙代价 无
代价
要留记录。
一句话
调休是"先上班后休息"，补休是"先休息后补班"，两者不能混。
怎么做
加班后要补休的，当场确认是"补休"还是"调休"，并留下书面记录。休息日加班可以安排补休，法定节假日加班不能以补休代替加班费。
为什么
这三个字的差别，直接决定你有没有钱、有没有假。而很多单位在口头安排时是混着说的。
失效条件
公务员的加班与补休按《公务员法》和本单位规定执行。
翻车
有人法定节假日上了三天班，单位安排了三天补休，他以为正常。实际上法定节假日加班应支付 300% 工资，不能以补休替代。
可靠度
乙
备注
这一条的关键是"当场确认"，事后说不清。
6.2.6

值班之后的补休，怎么要才不尴尬

◎ 建议可靠 乙代价 无
代价
要开口。
一句话
补休不是请假，是你已经付过的时间。
怎么做
值班表出来时就问一句"这个值班后面怎么补"，把规则问在前面。事后要的时候，说"上次值了 X 天，按咱们的规矩想补两天"。
为什么
补休是已经发生的时间交换，不是新的请求。你把它当"请假"去要，就会觉得不好意思；你把它当"结算"去要，就理直气壮。
失效条件
单位有明确规定"值班不补休、只发补贴"的，按那个来。
翻车
有人三年值了上百个夜班，一次补休没要过，因为"不好意思开口"。
可靠度
乙
备注
这一条的心理关比制度关难过。

本节小结

这一节六条，讲的都是"你本来就有的时间"。

年假、病假、探亲假、产假、育儿假、补休——这些不是福利，是权利。

权利不用，就会消失。而消失的权利，不会有人替你惋惜。

下一节讲最后一个问题：编制到底是为了什么。

6.3编制最后是为了什么

算了一路的账，最后要回答一个问题：

你守着这份工作，到底是为了什么？

如果答案只是"稳定""旱涝保收"，那这份稳定买来的时间，你打算怎么用？如果答案只是"习惯了""不敢走"，那这份账其实是亏的。

这一节讲的是这本书的落点。

6.3.1

编制的真正价值，是"不用怕"

● 必做可靠 乙代价 无
代价
要承认自己需要安全感。
一句话
编制买不到富贵，但它买得到一样很贵的东西——不怕。
怎么做
把"不怕"具体化：不怕生病（有医保）、不怕失业（有工资）、不怕老了（有退休金）、不怕得罪人（大不了不升）。这四样加起来，是多少钱都换不来的底气。
为什么
市场里的高收入，很多时候是用"随时可能失去"换来的。而编制的价值恰恰在于"不会突然没有"。这份确定性，让你可以做一些"不划算但想做"的事——陪孩子、写东西、照顾父母。
失效条件
如果你追求的是财富上限，编制是错的选择，别硬耗。
翻车
有人一辈子嫌工资低，却从来没算过"稳定"值多少钱。
可靠度
乙
备注
这一条是全书的价值基础：稳定不是目的，稳定是让你能过别的日子的条件。
6.3.2

家属问"累不累"，标准答案是"还行"

● 必做可靠 乙代价 无
代价
要忍住倒苦水。
一句话
"还行"不是撒谎，是不把单位的账转给家里。
怎么做
回家第一句话别说单位的糟心事。想说就等吃完饭、孩子睡了，用十分钟说完，别复盘。
为什么
你倒一次苦水，家人要担心一整晚，而你第二天就忘了。这种转移的代价，是家人替你承担了你本该自己消化的东西。
失效条件
真的遇到大事（被处分、想辞职），必须说，而且要好好说。
翻车
有人每天回家讲一遍单位的破事，讲了五年。妻子后来说："你只有在骂单位的时候话最多。"
可靠度
乙
备注
这一条和 2.4.1 重复，但在这里再讲一次，因为它是整本书的出口。
6.3.3

孩子的那几年，错过就是错过了

● 必做可靠 乙代价 无
代价
要放弃一些加班。
一句话
孩子只在你身边这几年，工作会一直在。
怎么做
把"陪孩子"写进日程表，当成会议一样不可取消。每天至少半小时不看手机，周末至少半天全家出门。
为什么
亲子关系是有窗口期的。三岁前建立依恋，六岁前建立规则，十二岁前建立信任。错过窗口，后面花十倍力气也补不回来。
失效条件
无。
翻车
有人孩子上初中后基本不跟他说话，他以为是叛逆。妻子说："你从他五岁起就一直在看手机。"
可靠度
乙
备注
这一条没有补救方案，只有"现在就做"。
6.3.4

单位离了谁都转，你家离了你转不动

● 必做可靠 乙代价 无
代价
要接受自己没那么重要。
一句话
你请一周假，单位照常运转；你缺席一年，家里天翻地覆。
怎么做
下次觉得"这事离了我不行"的时候，试着请三天假，看看会不会塌。多数时候不会。
为什么
组织有冗余设计，个人没有。你在单位是一个可替换的零件，在家里是不可替换的人。这个不对称，决定了你的优先级该怎么排。
失效条件
极少数关键岗位、关键时期，确实离不开，但那应该是暂时的。
翻车
有人十年没休过一个完整年假，因为"离不开"。他退休那天，单位三天就找到了接替的人。
可靠度
乙
备注
这一条是全书最想让你记住的一句。
6.3.5

你守着的不是一份工作，是一种活法

◎ 建议可靠 乙代价 无
代价
要自己想清楚。
一句话
编制不是身份，是你选择的一种生活方式。
怎么做
写下三件"因为有这份工作才能做的事"——比如按时接孩子、周末能陪父母、生病敢请假。写完你就知道这份工作的真实价值。
为什么
人容易把"工作"和"人生"混在一起，用工作的成败评价自己。但工作只是支撑生活的一个工具，工具好不好，要看它能不能撑起你想要的那种日子。
失效条件
如果你把工作本身当成人生意义，那另当别论，那也是一种活法。
翻车
有人退休后突然不知道该干什么，因为过去三十年，他的全部身份就是"某单位的某某"。
可靠度
乙
备注
这一条是整卷的收尾，也是全书七卷的收尾。

本节小结

这一节五条，讲的是一件事：编制是手段，生活是目的。

如果你把手段当成了目的，就会一辈子在一个不重要的地方用力，然后在一个重要的地方缺席。

算清这笔账的人，不会再把加班当成荣誉，也不会再把清闲当成罪过。

下一节讲最后一种情况：什么时候该走，怎么走。

6.4什么时候该走，怎么走

这本书从头到尾都在讲"怎么在体制内过好"。

但有一种情况，是"过不好"的——那时候，走比留划算。

这一节讲三件事：什么时候该走，走了会损失什么，以及怎么走得干净。

6.4.1

辞职、辞退、开除，三者的账完全不一样

● 必做可靠 甲代价 无
代价
要弄清概念。
一句话
同样是不干了，这三种的后果差着一个量级。
怎么做
辞职
你主动提出，一般没有补偿，但记录干净，可以再考、再进。
辞退
单位解除，通常有辞退费，但记录上会写明原因，影响再就业。
开除
纪律处分，最重，五年内不得重新录用，且影响一系列资格。
为什么
这三者在档案、社保、再就业资格上的待遇完全不同。很多人以为"不干了就是不干了"，其实走的方式决定了你以后还能不能回来。
失效条件
无。
翻车
有人被"劝退"，签了"自愿辞职"，后来才知道如果走辞退程序，能拿一笔辞退费。
可靠度
甲（《公务员法》《事业单位人事管理条例》均有明确规定）
备注
这一条是"走之前必须搞清"的第一件事。
6.4.2

服务期内能不能走，违约金怎么算

● 必做可靠 甲代价 无
代价
要看合同。
一句话
违约金不是单位说多少就多少，有法定上限。
怎么做
翻出当年的聘用合同/服务协议，看服务期年限和违约金条款。按规定，违约金不得超过单位为你提供的培训费用，且按服务期未履行部分分摊。
为什么
很多单位的违约金条款是"拍脑袋"定的，远超法定上限。而这类条款在争议中未必被支持。
失效条件
涉及特殊岗位、涉密岗位的，另有规定。
翻车
有人被要求赔十万违约金，实际培训费用只有两万，最后按两万结算。
可靠度
甲（《劳动合同法》第二十二条对违约金有明确限制）
备注
这一条建议在签合同时就看清楚，别等到要走才翻。
6.4.3

档案、社保、公积金，走之前必须办清的几件事

● 必做可靠 甲代价 无
代价
要跑几个窗口。
一句话
走的时候没人提醒你，走了之后再办就麻烦了。
怎么做
一张清单——档案转递（必须有接收单位或人才中心）、社保关系转移（跨省要办转移接续）、公积金封存或提取、组织关系转接（党员）、职业年金处理。
为什么
这五样东西都跟着"人"走，不跟着"单位"走。你走了没办，它们就卡在原地，而补办的成本是当初的十倍。
失效条件
无。
翻车
有人辞职五年后想考公，发现档案还在原单位，且已经"死档"，跑了大半年才激活。
可靠度
甲
备注
这一条最好在提辞职之前就开始办，别等最后一天。
6.4.4

体制内跳国企，是很多人没算过的一条路

◎ 建议可靠 乙代价 无
代价
要重新适应。
一句话
如果你想要的是"稳定 + 收入高一点"，国企是中间选项。
怎么做
关注本地国企的公开招聘，尤其是你专业对口的。公务员、事业编转国企，通常走"调动"或"辞职再入职"，前者保留部分待遇衔接。
为什么
国企的稳定性接近体制内，收入上限高于机关，而且对"体制内背景"的人有需求（尤其是党务、行政、合规岗）。这条路很多人没想过，因为默认只有"留"和"走"两个选项。
失效条件
国企也分好坏，效益差的国企不如留在机关。
翻车
有人辞职去了国企，发现是"名义国企、实际外包"，稳定性还不如原来。
可靠度
乙
备注
这一条要具体考察目标企业的性质和效益，别只看"国企"两个字。
6.4.5

什么时候该走：身体、家庭、心气，三者缺二就动

● 必做可靠 乙代价 无
代价
要做决定。
一句话
不是"混不下去才走"，是"三条腿断了两条就该走"。
怎么做
每年给自己打三个分——身体（是否长期失眠、体检异常）、家庭（是否长期缺席、关系紧张）、心气（是否每天起床就烦）。三项里有两项持续变差，就该认真考虑动了。
为什么
人容易把"再忍忍"当成理性，其实是沉没成本在作祟。而身体、家庭、心气这三样，恰恰是"忍"最消耗的东西——你越忍，它们掉得越快。
失效条件
短期内（一年内）有明确的机会（提拔、调动），可以再等一等。
翻车
有人忍到身体出问题才走，走的时候已经四十多岁，重新开始很难。
可靠度
乙
备注
这一条不是劝你走。是给你一个判断标准，别靠感觉。

本节小结

这一节五条，讲的是"退路"。

不是所有人都要走，但每个人都该知道怎么走。

知道退路在哪的人，反而更能安心留下——因为他不是被困住，是选择留下。

卷六完。最后一卷，给还想再搏一次的人。

6.5副业：什么能干，什么不能干

体制内最常被问、也最容易答错的一个问题：我能干点副业吗？

答案不是"能"或"不能"，是"看三条"。

这一节把这三条讲清楚，也把最容易踩的雷标出来。

6.5.1

三条判断标准：报批、职权、本职

● 必做可靠 甲代价 无
代价
要逐条对。
一句话
能不能干，看三件事——经过批准了吗？利用职权了吗？影响本职了吗？
怎么做
三条全过，基本安全；踩任意一条，就别干。
报批
按规定需要报备、报批的（兼职、讲课、咨询、持股），走完程序。
职权
不能利用职务影响、不能在你管辖的范围内。
本职
不能占用工作时间、不能影响履职。
为什么
纪律禁止的不是"有副业"，是"违反有关规定从事营利活动"和"利用职权或职务影响谋取私利"。所以关键在"规定"和"影响"，不在"有没有"。
失效条件
纯稿酬、专利、艺术创作，各地各单位规定不同，以本单位制度为准。
翻车
某干部在管辖企业兼职取酬，被党内严重警告，违纪所得被收缴。
可靠度
甲（《中国共产党纪律处分条例》对违规从事营利活动有明确规定）
备注
这一条是全节的骨架。三条里有一条含糊，就先别动。
6.5.2

写作、出版：最安全的一类

◎ 建议可靠 乙代价 无
代价
要报备（部分地区）。
一句话
稿酬是"劳动所得"，不是"职务所得"。
怎么做
不写涉密内容、不写本单位的人和事、不利用工作时间。按规定需要报备的报备，稿酬照章纳税。
为什么
写作和出版属于个人创作，只要不涉及职务、不涉密、不影响本职，通常是被允许的。这也是体制内最常见的合规副业。
失效条件
宣传、意识形态等特殊岗位，可能有额外限制。
翻车
有人在书里写了单位的人和事，虽然用了化名，还是被对号入座，闹得很难看。
可靠度
乙
备注
这一条最实用：能写就写，但别写单位。
6.5.3

讲课、评审、咨询：最需要报批的一类

● 必做可靠 甲代价 无
代价
要走程序。
一句话
拿"专家费"之前，先问一句"这个要不要报批"。
怎么做
向本单位人事或纪检部门报备，说明时间、地点、内容、报酬。涉及管辖范围、管理服务对象的，一律不接。
为什么
讲课费、评审费、咨询费是最容易被认定为"违规取酬"的三类。而"是否报批"和"是否涉及管辖对象"，是认定的关键。
失效条件
单位内部组织的培训、公益讲座，通常不算。
翻车
某干部多次接受管辖企业邀请讲课并取酬，被认定为违规，受到处分。
可靠度
甲
备注
这一条的红线很清楚：管辖范围内的，一分钱都不能拿。
6.5.4

开店、入股、投资：风险最高的一类

● 必做可靠 甲代价 无
代价
要放弃很多"看起来正常"的投资。
一句话
经商办企业是明确的禁区，投资要分清"理财"和"入股"。
怎么做
不注册公司、不担任企业职务、不持有非上市公司股份（除按规定可持有的）；买卖上市公司股票一般允许，但不得利用内幕信息、不得在管辖范围内。
为什么
纪律明确禁止"经商办企业"和"拥有非上市公司（企业）的股份或者证券"。而"借他人名义"也一样算。
失效条件
证券投资基金、银行理财等标准化产品，通常不在此列。
翻车
某人以亲属名义入股一家公司，被查出实际出资和分红，认定为违规经商。
可靠度
甲
备注
这一条没有模糊地带。别用别人的名字，那只是多一条"隐瞒"。
6.5.5

收入要能说清楚

● 必做可靠 甲代价 无
代价
要留凭证。
一句话
合法的收入，也要能证明它合法。
怎么做
稿酬、讲课费的合同、发票、纳税记录都留着。个人有关事项报告里该填的填全。
为什么
核查的时候，问的不是"你有没有这笔钱"，是"这笔钱哪来的"。你能拿出合同和税单，就是合法收入；拿不出来，就是"来源不明"。
失效条件
无。
翻车
有人收了几笔稿费，没留凭证，核查时说不清来源，被反复谈话。
可靠度
甲
备注
这一条是所有副业的地基：合法 + 可证 = 安全。
6.5.6

别让副业影响本职，这条比什么都重要

● 必做可靠 乙代价 无
代价
要控制投入。
一句话
本职出问题，副业再合规也保不住你。
怎么做
副业只用业余时间；不在单位做；不因为副业推掉工作；不因为副业影响状态。
为什么
组织对副业的容忍度，取决于"你有没有把本职干好"。你本职出色，副业是"个人爱好"；你本职拉胯，副业就是"不务正业"。
失效条件
无。
翻车
有人副业做得风生水起，本职连续两年考核靠后，最后被约谈"注意影响"。
可靠度
乙
备注
这一条的顺序很重要：先做好本职，再谈副业。

本节小结

这一节六条，讲的是一句话：副业不是不能干，是要"合规地干"。

三条标准：报批、职权、本职。三类风险：讲课取酬、经商入股、收入说不清。

最安全的是写作，最危险的是入股，最容易被忽略的是"收入要能说清楚"。

6.6家庭：孩子、老人能用的那些政策

体制内的福利，不只在你身上。

孩子上学、老人看病、配偶调动——这些事看起来是"家事"，但很多政策是跟"单位"和"身份"绑定的。

这一节把能用的列出来。多数人不知道，知道了就能用。

6.6.1

孩子的入学：单位共建与政策照顾

◎ 建议可靠 丙代价 无
代价
要提前问。
一句话
有些单位的"共建学校"，是一个从不写在文件里的福利。
怎么做
问人事或工会——本单位有没有共建学校？有没有入学照顾名额？条件是什么？什么时候报？
为什么
部分机关、事业单位、国企与当地学校有共建关系，职工子女可按规定入学。这类政策通常不公开宣传，靠内部通知。

多数地方已经取消了共建政策，改为就近入学。以当地实际为准。
翻车
有人孩子上学前一个月才问，发现名额早在半年前就报完了。
可靠度
丙（政策差异极大，且逐年收紧）
备注
这一条要早问，最好孩子三岁就问。
6.6.2

老人看病：长期护理保险与家庭病床

● 必做可靠 乙代价 无
代价
要了解当地政策。
一句话
失能老人最贵的不是药，是照护。
怎么做
查当地有没有"长期护理保险"（多数试点城市已建立），符合条件的失能人员可以申请护理服务或补贴。另外了解"家庭病床"——符合条件的老人可以在家接受医保支付的医疗服务。
为什么
这两项政策能显著降低长期照护的成本，但宣传少、申请流程复杂，很多人不知道。
失效条件
各地政策差异大，需以当地医保局规定为准。
翻车
有人照顾失能父母五年，全靠自己扛，后来才知道可以申请长护险。
可靠度
乙
备注
这一条对有老人的家庭价值极大。
6.6.3

医保家庭共济：你的账户余额，家人能用

● 必做可靠 甲代价 无
代价
要绑一次。
一句话
职工医保个人账户的钱，可以给配偶、父母、子女用。

为什么
这是近几年全国推开的政策，很多人账户里躺着几千块，却不知道家人能用。
失效条件
各地开通时间不同，以当地医保局为准。
翻车
有人账户里存了三万，父母看病全是自费，因为"不知道能共济"。
可靠度
甲
备注
这一条是典型的"信息差福利"。
6.6.4

子女教育：专项计划的边界

◎ 建议可靠 甲代价 无
代价
要提前三年了解。
一句话
高考的专项计划，是给"特定地区户籍"的，不是给"特定职业"的。
怎么做
了解三大专项——国家专项、地方专项、高校专项，看自己的户籍和学籍是否符合。别信"单位有加分"这类传言。
为什么
专项计划针对的是农村和贫困地区学生，与父母职业无关。而"体制内子女加分"在多数省份早已取消。
失效条件
极少数地区有侨眷、台属等特定身份照顾政策，需具体查。
翻车
有人听信"单位能加分"，没给孩子准备其他路径，最后落空。
可靠度
甲
备注
这一条是"辟谣"：别把传言当政策。
6.6.5

两地分居：探亲假是政策给的补偿

● 必做可靠 甲代价 无
代价
要符合条件。
一句话
夫妻分居两地的，每年有一次探亲假。
怎么做
国家机关、人民团体和全民所有制企事业单位工作满一年的固定职工，与配偶不住在一起、又不能在公休假日团聚的，每年可享受一次 30 天探亲假。
为什么
这是 1981 年确立的制度，至今有效，但知道的人极少。
失效条件
企业职工是否适用取决于本单位制度。
翻车
有人两地分居十年，从没休过探亲假。
可靠度
甲
备注
这一条和 6.2.3 重复，但在"家庭"这一节再提一次，因为它是最实用的家庭政策。
6.6.6

配偶工作：调动与随迁

◎ 建议可靠 丙代价 无
代价
要走程序。
一句话
配偶随调、随迁，是有政策通道的，但越来越窄。
怎么做
了解本地"配偶随调"政策——通常要求夫妻分居一定年限、且接收单位有空编。走人事部门，不走私人关系。
为什么
部分地区的机关事业单位有配偶随调政策，但需要接收单位有编制空缺，实际操作难度大。
失效条件
多数地区已收紧或取消，以当地为准。
翻车
有人为了配偶调动跑了三年，最后因为"没有空编"没办成。
可靠度
丙
备注

本节小结

这一节六条，讲的是：你的身份，能给家里带来一些东西。

孩子的入学、老人的照护、医保的共济、探亲的假期——这些政策都在，只是没人告诉你。

问一句，查一下，可能就省下几万块，或者多出一个月。

最后一卷，给还想往上走的人。用的是同一套算法：先算清哪些努力值得，再看懂升迁的真实规则。

7.1哪些努力值得

前面六卷都在讲"少消耗"。

这一卷反过来，讲"多投入"——但不是所有的投入都值得。

体制内最残酷的一个真相是：很多人不是不努力，是把力气花在了不产生回报的地方。

这一节讲怎么分辨。

7.1.1

值得押的三种努力：能带走的、能积累的、能换轨的

● 必做可靠 乙代价 无
代价
要放弃一些"看起来很努力"的事。
一句话
判断标准只有一个——离开这个单位，它还在不在。
怎么做
能带走的
写作、表达、专业能力、证书、人脉（真朋友那种）。
能积累的
资历、项目经验、行业口碑、可查的作品。
能换轨的
学历、职业资格、跨领域的技能。
为什么
体制内的很多努力是"位置绑定的"——你在这个位置上才有价值，位置一换就清零。而上面这三类，跟着你走。
失效条件
短期内要争一个具体位置，那该按那个位置的规则努力。
翻车
有人在单位做了十年"内部协调"，协调能力极强。调走后发现，这个能力离开了具体的人和事，一文不值。
可靠度
乙
备注
这一条是全卷的地基：先分清哪些是你的，哪些是位置的。
7.1.2

不值得押的三种：评比、口号、领导的情绪

● 必做可靠 乙代价 无
代价
要忍住"被认可"的渴望。
一句话
这三样都不可控，且有效期极短。
怎么做
评比参加但不执着；口号喊但不信；领导的情绪看但不入心。
为什么
评比是平衡工具，口号是组织语言，情绪是即时反应——它们都不产生积累。你为它们投入的情绪和时间，第二年就归零。
失效条件
评比在提拔时确有加分，该重视还得重视。
翻车
有人为了一个"先进个人"，连续三个月每天加班到十点。拿到奖状那天很开心，第二年发现，除了那张纸，什么都没变。
可靠度
乙
备注
这一条不是让你消极。是让你把情绪从"不可控的事"上撤回来。
7.1.3

写材料这件事：适可而止，别成为"那支笔"

◎ 建议可靠 乙代价 无
代价
要放弃"笔杆子"的光环。
一句话
单位需要一支笔，但不需要一个笔杆子当领导。
怎么做
能写是优势，但要控制在"能写"而不是"只能写"。主动争取一些"要露脸、要协调"的活，别让自己被固定在电脑前。
为什么
写材料的人往往最了解情况、最辛苦、最被依赖，但也最难提拔——因为领导离不开他。这个位置的价值在"笔"上，不在"位"上。
失效条件
政策研究室、办公室等以文辅政的岗位，写材料本身就是上升通道。
翻车
有人在办公室写了八年材料，全单位都说他"水平高"，但三次提拔都没他，因为"他走了谁写"。
可靠度
乙
备注
这一条很反常识，但在很多单位是事实。
7.1.4

不可替代，是体制内最危险的处境

● 必做可靠 乙代价 无
代价
要主动培养接手的人。
一句话
你越不可替代，越走不开；越走不开，越上不去。
怎么做
把手上的活整理成流程，教会至少一个人。让自己"可替代但难替代"——别人能接，但接得不如你熟。
为什么
提拔的前提是"你走了，这块有人接"。你把自己做成唯一节点，等于把自己钉死在原地。而"可替代"反而给了你自由。
失效条件
核心技术岗、涉密岗位，客观上就是不可替代，那要另找路径。
翻车
有人是科室里唯一会某项业务的人，十年没动过位置。领导说得很直白："你走了，这块就塌了。"
可靠度
乙
备注
这一条和 4.3.3 是一对：一个讲"别被消耗"，一个讲"别被钉死"。
7.1.5

把活干得漂亮，但别让领导觉得你只能干这个

● 必做可靠 乙代价 无
代价
要主动争取"不像你"的活。
一句话
标签一旦贴上，就很难撕下来。
怎么做
在做好本职的前提下，主动接一两件"跨类型"的事——写材料的去跑一次协调，搞业务的去做一次汇报。让领导看到你的另一面。
为什么
组织对人的认知是"标签化"的：他是写材料的、他是跑腿的、他是搞技术的。标签决定了机会，而机会决定了你能不能突破。
失效条件
专业分工极细的单位，跨类型反而不专业，那要深耕。
翻车
有人被贴上"会务专家"的标签，十年里所有大会都是他办，一次业务岗的机会都没有。
可靠度
乙
备注
这一条的关键是"一次"，不用多，让人看见就行。
7.1.6

值得押的还有一样：身体

● 必做可靠 乙代价 无
代价
每天半小时。
一句话
所有努力的前提，是你还活着、还能干。
怎么做
每周三次、每次三十分钟的运动，比任何"职场技巧"都更能延长你的职业生涯。
为什么
体制内是一场长跑，跑赢的人不是跑得快的，是没退赛的。而四十岁以后的竞争力，很大程度取决于身体。
失效条件
无。
翻车
有人三十五岁做到科室负责人，三十八岁查出重病，之后所有的规划都作废了。
可靠度
乙
备注
这一条放在"努力"这一节，是想说：身体也是一种投资，而且回报率最高。

本节小结

这一节六条，讲的是一件事：努力要挑地方。

能带走的、能积累的、能换轨的，值得押。评比、口号、领导的情绪，不值得。而身体，是所有努力的地基。

下一节讲最后一件事：升迁的真实规则。

7.2升迁的真实规则

最后一节，讲一件很多人一辈子没搞明白的事：升迁到底是怎么发生的。

不是论资排辈，也不是论功行赏。

它是一把手用位置换忠诚的一笔交易——你不是在争取一个岗位，你是在争取被纳入某个人的班底。

这一节讲清楚三件事：名单在会前怎么形成，一把手拿什么挑人，以及几个普遍的误判。

7.2.1

常委会是呈现结果的地方，不是产生结果的地方

● 必做可靠 乙代价 无
代价
要接受"程序"和"结果"是两件事。
一句话
会议只是把已经定好的事念一遍，真正的决定早在会议室外面做完了。
怎么做
关心一件事，不要只看它上没上会，要看它上会之前有没有人替你"说话"。会上说什么都是记录，会前说什么才是决定。
为什么
常委会是集体决策的形式载体，功能是确认共识，不是制造共识。共识在小范围沟通里达成，会上只是走完程序。
失效条件
重大否决、争议极大的议题，会上确实可能翻盘，因为小范围没谈拢。
翻车
某人以为会上发言出彩就能推动方案，讲得头头是道。散会后没人接话——因为这事三天前就定了。
可靠度
乙
备注
程序是真的，记录是真的，责任是真的。只是"决定"发生在别处。
7.2.2

酝酿不是讨论，是交换

● 必做可靠 乙代价 无
代价
要重新理解这个词。
一句话
酝酿包含试探、还价和互相兜底。
怎么做
听到"还在酝酿"，就该知道两件事——方向没定；能影响方向的人正在一个个谈。这时候要做的不是催，是让你的名字出现在那些谈话里。
为什么
干部任免涉及人事、纪律、稳定的交叉，不可能在一次会议上从零开始。必须先在小范围把分歧磨平。会议是结果，酝酿是过程。
失效条件
程序性、事务性事项，不需要酝酿。
翻车
某人在酝酿阶段到处打听"我有没有戏"，问了七八个人。最后所有人都知道他很想上——而"很想上"本身就是减分项。
可靠度
乙
备注
这一条最容易被误用。它不是教你钻营，是告诉你别用"等通知"的心态对付一件需要提前三个月布局的事。
7.2.3

提拔的本质：搭班底，不是评先进

● 必做可靠 乙代价 无
代价
要接受"我很优秀"和"我想用你"是两回事。
一句话
领导提拔一个人，是在给自己搭一套可靠的班子。
怎么做
把自己从"好员工"切换到"可信的人"。好员工看业绩，可信的人看三件事——听话、好用、不添乱。
为什么
位置是领导手里最硬的资源，给出去换回来的必须是他能调动的力量。聪明但不受控的人，对领导是风险，不是资产。
失效条件
纯技术岗位、职称序列，能力权重远高于忠诚权重。
翻车
某人业务最强、证书最多，但开会经常提不同意见。连续两次都没他，评语是"能力有，就是不太成熟"。
可靠度
乙
备注
站队是选边，搭班底是被选。你控制不了被不被选，但能控制自己像不像一个"能被用"的人。
7.2.4

好用的排序：听话 > 能扛 > 聪明

◎ 建议可靠 丙代价 无
代价
要接受聪明不是优势。
一句话
人事决策里最不值钱的是聪明，最值钱的是可控。

7.2.7

7.3借调、挂职、遴选：哪些是机会，哪些是坑

体制内换轨的三条主要通道：借调、挂职、遴选。

它们看起来都是"往上走的机会"，但性质完全不同——一个是试用，一个是镀金，一个是考试。

这一节讲怎么分清。

7.3.1

借调：免费劳动力陷阱，也是唯一的"留用"通道

◎ 建议可靠 丙代价 无
代价
可能要白干两三年。
一句话
借调不给你身份，只给你"被看见"的机会。
怎么做
接受前问清三件事——借调期限多长？有没有留用的可能？原单位的位置保不保？三个答案含糊，就别去。
为什么
借调的人事关系还在原单位，工资原单位发，干活新单位用。多数借调最后是"用完退回"，但如果新单位有编制空缺且领导认可，就是唯一能绕开考试的通道。
失效条件
上级机关"以借代调"的情况，留用概率会高一些。
翻车
有人借调三年，活干了、人累垮了，最后因为"没有编制"被打回原单位，原单位的位置也没了。
可靠度
丙（各单位差异极大）
备注
这一条的核心是"问清期限和可能"。
7.3.2

挂职：有期限、有岗位、有文件的，才叫挂职

● 必做可靠 乙代价 无
代价
要离开熟悉的环境。
一句话
挂职是"带着任命去的"，不是"去帮忙的"。
怎么做
看有没有正式的挂职文件、明确的职务、确定的期限。三者齐全，是镀金；缺一样，就是借调的变种。
为什么
挂职是干部培养制度的一部分，有文件、有职务、有考核，回来通常有安排。而"没有文件的挂职"，本质上就是借调。
失效条件
无。
翻车
有人被"挂职"了两年，没有任命文件，回来时原岗位已经有人了。
可靠度
乙
备注
这一条的判断标准很硬：看文件。
7.3.3

遴选：相对最公平的一条路

● 必做可靠 乙代价 无
代价
要考试。
一句话
遴选是面向体制内的公开考试，比"找人"靠谱得多。
怎么做
关注本地组织部门发布的遴选公告，看清报名条件（工作年限、身份、专业）。提前半年准备，笔试考的是政策理论、公文写作、案例分析。
为什么
遴选有明确的程序和分数线，虽然也有"萝卜岗"，但整体透明度高于其他通道。而且它是"换单位"最正当的方式。
失效条件
极少数岗位确实为特定人设置，那要提前打听。
翻车
有人笔试第一，面试被刷，后来才知道那个岗位早就有人了。
可靠度
乙
备注
这一条值得投入：它是普通人最可能走通的路。
7.3.4

代价

7.3.5

○ 可选可靠 丙代价 无
代价
时间、精力、关系。
一句话
跨省调动涉及两地编制、两地审批，难度是省内的数倍。

可靠度
丙
备注

● 必做可靠 乙代价 无
代价

本节小结

这一节六条，讲的是三条通道的区别：

借调是试用，可能留用，也可能白干；挂职是镀金，看文件；遴选是考试，最公平。

而所有"暂时离开"的安排，都要先问一句：什么时候、以什么身份回来。
